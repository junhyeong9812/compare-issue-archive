# issue/glsync/unbalanced-journal-silent-skip — 정리 (힌트)

태그: `silent-failure` · `accounting`

## 전체 흐름

```
정산 원장 → 분개 생성 (차변: 미수금 / 대변: 매출·부가세예수금)
      │  부가세 원 단위 끝수 처리로 대변 합이 1원 큼
      ▼
glsync push
      │  차대 불일치 전표 → WARN "unbalanced, skipped" 후 다음 전표
      │  요약 출력 "pushed 4,210", exit 0     ← 건너뛴 수 없음
      ▼
ERP: 19건 없음 → 마감 대사 차액
```

## 핵심 문장

- `glsync push`는 차대 불일치 전표를 **오류 없이 건너뛴다** — 요약 출력에 건너뛴 수가 없다.
- 불일치의 원인은 분개 생성의 **끝수 처리**였다: 공급가·부가세를 각각 반올림해 합이 총액과 1원 어긋났다.
- 끝수가 생기는 금액 조합에서만 생겨 "일부 날"로 보였다.
- 교정: 부가세 = 총액 − 공급가(나머지 몰기)로 분개하고, 건너뛰기를 실패로 바꾼다.
