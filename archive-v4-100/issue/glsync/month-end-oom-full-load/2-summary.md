# issue/glsync/month-end-oom-full-load — 정리 (힌트)

태그: `performance` · `resource-exhaustion`

## 전체 흐름

```
평일: 전표 라인 약 6만 → findAll() → 메모리 여유
월말: 월 결산 분개 포함 약 210만 라인 → findAll()
      │  힙 4GB, 라인 객체 + 연관 엔티티 → 5GB 이상
      ▼
OutOfMemoryError → 파드 재시작 → 처음부터 다시 → 같은 지점에서 OOM
```

## 핵심 문장

- 평일 데이터량으로 검증된 코드가 **월말 결산 분개**에서만 수십 배로 커졌다.
- 재시작하면 처음부터 다시 읽어 같은 곳에서 죽는다 — 체크포인트가 없었다.
- 교정: 키셋 페이지(5,000줄) 스트리밍 + 페이지 단위 전송·체크포인트.
