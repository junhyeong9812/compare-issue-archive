# issue/bnkfirm/ipsec-rekey-lifetime-mismatch — 정리 (힌트)

태그: `network` · `environment-drift`

## 전체 흐름

```
사내 VPN 장비 교체: IPsec SA lifetime 기본값 8h (28,800s)
은행 장비: 1h (3,600s)
      │  은행 측 재협상 시도 시 사내 장비가 응답 지연 → 터널 재수립 3~5분
      ▼
그 사이 bnkfirm 전문 전송 실패 → 재시도 → 대부분 회복, 일부 타임아웃
```

## 핵심 문장

- VPN 장비 교체 때 **SA 수명이 기본값**으로 들어갔고 은행 설정과 달랐다.
- 끊김이 몇 분이라 재시도로 대부분 메워져 원인 파악이 2주 걸렸다.
- 교정: 은행 설정과 수명·암호 제안을 일치시키고, 터널 상태 감시를 추가.
