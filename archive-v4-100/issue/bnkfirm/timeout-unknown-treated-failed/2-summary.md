# issue/bnkfirm/timeout-unknown-treated-failed — 정리 (힌트)

태그: `idempotency` · `async-status`

## 전체 흐름

```
bnkfirm transfer (전문 고유번호 T1) → 은행 처리 완료, 응답 지연 (전용선 혼잡)
사내 타임아웃 10s → 실패 처리 → 다음 회차 새 고유번호 T2 로 재이체
      │  은행: T1·T2 모두 정상 이체
      ▼
수취인 이중 입금, 모계좌 출금 > 사내 기록
```

## 핵심 문장

- 타임아웃은 **실패가 아니라 결과 모름**이다 — 은행은 처리했을 수 있다.
- 재이체할 때 **새 고유번호**를 써서 은행의 중복 방지가 작동하지 않았다.
- 교정: 타임아웃 건은 UNKNOWN으로 두고 `bnkfirm inquire T1`(결과 조회 전문)로 확정한 뒤에만 재이체한다. 재이체는 같은 고유번호.
