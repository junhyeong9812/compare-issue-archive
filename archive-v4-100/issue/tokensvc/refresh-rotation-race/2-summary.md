# issue/tokensvc/refresh-rotation-race — 정리 (힌트)

태그: `concurrency` · `session`

## 전체 흐름

```
요청 a: refresh(R1) → R2 발급, R1 사용됨
요청 b: refresh(R1) → R1 재사용 탐지 → 토큰 묶음(R1 계열) 전체 폐기 → R2 도 무효
앱: 로그아웃 화면
교정(앱): 갱신을 단일 비행으로 — 하나만 보내고 나머지는 결과 대기
교정(서버): 재사용이 직전 회전 후 10초 이내면 같은 R2 반환(유예)
```

## 핵심 문장

- 회전 방식에서 **이미 쓴 리프레시 토큰이 다시 오면 묶음 전체를 폐기**한다 — 탈취 대비.
- 앱이 **동시에 두 번 갱신**해 두 번째가 재사용으로 판정됐다.
- 액세스 토큰이 만료될 만큼 오래 두었다 열 때만 동시 401이 났다.
- 앱은 **갱신을 한 번만**, 서버는 **짧은 유예**로 같은 결과를 돌려준다.
