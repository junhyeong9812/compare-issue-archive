# issue/sagaorc/lock-order-inversion-deadlock — 정리 (힌트)

태그: `concurrency` · `performance`

## 전체 흐름

```
정방향:  재고 행 잠금 → 포인트 행 잠금
보상(결제 실패 시): 포인트 행 잠금 → 재고 행 잠금
같은 회원·같은 상품에서 정방향과 보상이 겹침 → 교착 → DB 교착 감지(1s) 후 한쪽 롤백 → 재시도 → 반복
```

## 핵심 문장

- 두 경로가 같은 자원을 **다른 순서로** 잠그면 동시 실행 시 교착이 생긴다.
- 평소에는 같은 회원의 정방향·보상이 겹칠 일이 없었고, 한정판 오픈에서 결제 실패·재주문이 몰렸다.
- 대처: 모든 경로의 잠금 순서를 (재고 → 포인트)로 고정, 보상 경로에도 같은 순서 적용.
