# issue/stockpush/openmall-token-refresh-cron-missing — 정답

태그: `credential` · `deployment` · `silent-failure`

## 정답
<!-- 질문 1:1 대응 -->

1. **마켓 접근 토큰(7일 유효)이 만료됐다.**\
인증 실패로 재고 연동 전 건이 반영되지 않았다.

2. **월요일 서버 이전 때 토큰 갱신 크론이 옮겨지지 않았다.**\
이전 체크리스트가 "재고 연동 잡"만 적고 있었다.

3. **마지막으로 갱신된 토큰이 7일 동안 유효했기 때문이다.**\
이전 직후엔 기존 토큰으로 정상 동작했다.

4. **인증 실패 경보가 업무 시간에만 울리는 채널에 연결돼 있었다.**\
재고 연동 "마지막 성공 시각" 경보가 없었다.

5. **반영 자체가 일어났는지 본다.**\
이 사건은 모든 SKU의 갱신 시각이 금요일에 멈춰 있었다. 일부 SKU만 값이 안 바뀌면 입력 줄 단위 원인을 본다.

## 문제 구조 (추상화 코드)

### 변형 A — 연동 성공 여부를 시각으로 감시하지 않음
① 문제 코드
```python
if sync_failed:
    log.error("stockpush auth failed")     # 업무 시간 채널
```
② 고친 코드
```python
if now() - last_sync_success() > timedelta(hours=2):
    page_oncall("stock sync stalled")      # 주말 포함 당직
if token_expires_in() < timedelta(days=2):
    alert("openmall token expiring")
```
무엇이 깨졌나: 서버 이전이라는 변경과 7일 뒤 만료라는 결과 사이에 감시가 없었다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
