# issue/sanctlist/version-string-compare — 정리 (힌트)

태그: `silent-failure` · `data-semantics`

## 전체 흐름

```
current = "2024.9"   new = "2024.10"
문자열 비교: "2024.10" < "2024.9"  ('1' < '9')  → 새 버전 아님 → 적재 건너뜀, exit 0
2024.1 ~ 2024.9 : 한 자리 → 순서 맞음
2025.1 vs 2024.10 : "2025" > "2024" → 적재됨 (연도 바뀌면 저절로 복구)
교정: 숫자 튜플 비교 (2024,10) > (2024,9) · 적재 후 명단 버전 = 받은 파일 버전 확인
```

## 핵심 문장

- 버전을 **문자열로 비교**해 `2024.10`이 `2024.9`보다 작다고 판단했다.
- 9월까지는 한 자리 월이라 우연히 맞았다 — **10월에 처음 터졌다**.
- '새 버전 아님 → 건너뜀'은 정상 경로라 **exit 0**이다.
- 비교는 숫자 단위로, 적재 확인은 **적재 후 현재 버전 = 받은 파일 버전**으로 한다.
