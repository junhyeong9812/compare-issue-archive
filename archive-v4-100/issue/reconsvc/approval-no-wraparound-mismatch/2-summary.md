# issue/reconsvc/approval-no-wraparound-mismatch — 정리 (힌트)

태그: `data-meaning` · `identity`

## 전체 흐름

```
카드사 D 승인번호 8자리, 약 9개월 주기로 순환
reconsvc: JOIN ON approval_no  (기간 조건 없음, 미대사 잔류분 포함)
      │  남아 있던 지난해 미대사 건과 올해 새 거래가 같은 번호
      ▼
오매칭 → 한쪽은 '금액 불일치', 다른 쪽은 '미대사'
```

## 핵심 문장

- 승인번호는 **카드사 안에서, 일정 기간 안에서만** 유일하다.
- 미대사 잔류분이 쌓이며 대사 대상 기간이 길어져 순환 주기와 겹쳤다.
- 교정: 조인 키 = 카드사 + 승인번호 + 승인일(±1일), 잔류분은 90일 넘으면 별도 처리.
