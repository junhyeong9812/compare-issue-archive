# issue/cartsvc/ttl-set-on-create-active-cart-expire — 정리 (힌트)

태그: `data-loss` · `cache` · `partial-failure`

## 전체 흐름

```
이전 전: 장바구니 수정 시마다 만료 7일 재설정 (옛 클라이언트 라이브러리가 자동 처리)
5/13 이전: 새 저장소 + 새 클라이언트 → 만료는 "장바구니 생성 시" 한 번만 설정
5/20~  생성 후 7일 지난 장바구니 → 수정 여부와 무관하게 통째 만료
        매일 7일 전에 처음 담은 고객만큼 소실
```

## 핵심 문장

- 원인은 **만료 시간을 생성 시점에만 설정**한 것 — 수정해도 만료가 연장되지 않았다.
- 옛 클라이언트 라이브러리는 **쓰기마다 만료를 자동 재설정**했고, 새 클라이언트는 그러지 않았다 — 이전 때 놓친 암묵 동작이다.
- 피해는 **7일 전에 장바구니를 처음 만든 고객**에게 매일 조금씩 나타났다.
- 대처는 쓰기마다 만료 재설정, 만료를 "마지막 수정 후 30일"로, 이전 체크리스트에 만료 동작 비교.
