# issue/ptsctl/nat-gateway-egress-ip-allowlist — 정리 (힌트)

태그: `environment-drift` · `network` · `vendor-notice`

## 전체 흐름

```
3/02 23:00  NAT 게이트웨이 교체 (고정 IP 재할당 실패 → 새 공인 IP)
3/03 08:00  ptsctl → 포인트 벤더: 출발지 IP 허용 목록에 없음 → 403
            환율·본인확인 벤더: IP 제한 없음 → 정상
08:30  원인 파악 → 벤더에 새 IP 등록 요청 (영업일 처리, 담당자 확인 필요)
12:10  등록 완료 → 정상화, 그 사이 적립 요청은 재처리
```

## 핵심 문장

- 원인은 **NAT 게이트웨이 교체로 출발지 공인 IP가 바뀐 것** — 포인트 벤더는 IP 허용 목록으로 접근을 제한한다.
- 인프라팀 점검 목록에 **외부 벤더의 IP 허용 목록 의존**이 없었다.
- 다른 벤더는 IP 제한이 없어 영향이 없었다 — **벤더마다 접근 제어 방식이 다르다**.
- 대처는 IP 허용 목록 의존 벤더 대장, NAT 교체 시 고정 IP 이전을 필수 단계로, 벤더에 예비 IP를 미리 등록.
