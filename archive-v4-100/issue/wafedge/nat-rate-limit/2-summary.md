# issue/wafedge/nat-rate-limit — 정리 (힌트)

태그: `capacity` · `rate-limit`

## 전체 흐름

```
가맹점 G 서버 20대 ──NAT 1개 IP──▶ wafedge: IP당 600/분
  피크 3,000/분 → 2,400/분 429
12월 이전: 서버마다 공인 IP → IP당 150/분 → 제한 아래
교정: 키 = 가맹점 API 키, 한도 = 계약 한도 (G: 6,000/분)
```

## 핵심 문장

- 속도 제한 키가 **IP**라 NAT 뒤 서버 20대가 한 고객으로 묶였다.
- 가맹점이 12월에 **출구를 NAT 하나로 통합**하면서 시작됐다.
- 429는 WAF에서 끝나 **우리 결제 서버 지표에는 안 보인다**.
- 인증된 API는 **API 키 단위 한도**로 제한한다 — IP 제한은 인증 전 경로에만.
