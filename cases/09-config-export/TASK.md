# 설정 내보내기 파일을 다시 불러올 수 없음

장비 설정을 `.cfg` 텍스트 파일로 내보내고(`writer.ts`의 `writeConfig`) 다른 장비에서 불러옵니다(`reader.ts`의 `readConfig`).

## 파일 형식 규약
- 한 줄에 `key = value`. 값은 문자열(`"..."`), `true`/`false`, 십진 숫자(지수 표기 허용), 또는 `[a, b, ...]` 목록.
- 숫자로 적을 수 없는 특수값은 상수 이름으로 기록한다: `Float.NaN`, `Float.POSITIVE_INFINITY`, `Float.NEGATIVE_INFINITY`.
- `reader.ts`는 다른 장비 팀도 같이 쓰는 기준 리더라서 바꿀 수 없습니다. 규약 밖의 표기는 거부하는 게 맞는 동작입니다.

## 기대한 것
내보낸 파일은 언제나 그대로 다시 불러와져서 같은 값이 나와야 한다.

## 실제로 일어난 것
- 일반 설정, 상·하한이 없는(무한대) 설정은 잘 왕복된다.
- 그런데 센서 측정이 실패해 보정값이 계산 불가로 남은 장비의 설정을 내보냈더니, 불러올 때 `line 2: unexpected token ...` 오류로 파일 전체를 읽지 못했다.
