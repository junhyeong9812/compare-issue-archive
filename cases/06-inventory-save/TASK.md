# 재고 저장이 거절된 뒤 재고 파일이 반쯤 사라져 있습니다

`inventory.py`의 `StockFile`은 창고 재고를 `stock.csv` 한 파일에 저장/로드합니다.
`save()`는 잘못된 항목(음수 수량 등)이 있으면 `InvalidItem` 예외로 저장을 거절합니다.

## 기대한 것
- 저장이 거절되면 파일은 **직전에 저장된 재고 그대로** 남아 있어야 합니다.

## 실제로 일어난 것
- 수량이 음수로 들어간 업데이트가 거절된 뒤 앱을 다시 열자, 재고 목록이 앞쪽 일부 SKU만 남고 나머지가 사라져 있었습니다.
- 지난달에는 서버 디스크가 꽉 찼던 날 저장이 실패한 뒤에도 비슷하게 재고 파일 뒷부분이 없어진 적이 있습니다.

## 재현
```
bash test.sh
```
