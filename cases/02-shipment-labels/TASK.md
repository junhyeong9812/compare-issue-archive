# 운영자가 붙인 배송 태그가 가끔 사라집니다

## 기대
운영 화면에서 배송 건에 태그(`fragile`, `VIP` 등)를 붙이면, 택배사 상태가 계속 갱신되더라도 태그는 운영자가 바꾸기 전까지 그대로 남아 있어야 합니다. 택배사 상태(`IN_TRANSIT`, `DELIVERED` …)도 최신으로 보여야 합니다.

## 실제
대부분은 잘 되는데, 하루에 몇 건씩 "분명히 태그를 저장했는데 몇 초 뒤 새로고침하니 없어졌다"는 문의가 옵니다. 저장 API는 성공을 반환했고 에러 로그도 없습니다. 드물게 반대로 배송 상태가 잠깐 이전 상태로 되돌아가 보였다는 제보도 있습니다. 개발 환경에서 순서대로 눌러 보면 재현되지 않습니다.

택배사 상태 동기화는 스케줄러 스레드에서 몇 초마다 돌고, 태그 저장은 운영 화면 요청 스레드에서 실행됩니다.

## 재현
```
bash test.sh
```
테스트는 상태 동기화가 진행 중일 때 태그를 저장하는 타이밍을 고정해서 재현합니다. 저장한 태그가 사라지는 것이 확인됩니다.
