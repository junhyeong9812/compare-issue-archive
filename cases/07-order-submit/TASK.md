# 주문 서버 장애 시 화면이 깨짐

주문 화면은 `OrderService.submit()`/`cancel()`의 결과(`{ ok, id?, error? }`)를 보고 성공/실패 메시지를 띄웁니다. 실패는 `failures` 목록에도 남아 운영 대시보드에 집계됩니다.

## 기대한 것
- 입력이 잘못됐든, 주문 서버가 오류를 돌려줬든 `submit()`은 예외를 던지지 않고 `{ ok: false, error: <메시지> }`를 돌려준다.
- 그 실패가 `failures`에 `"submit: <메시지>"` 형태로 한 줄 남는다.

## 실제로 일어난 것
- 수량이 0인 주문처럼 입력이 잘못된 경우에는 기대대로 동작한다.
- 그런데 주문 서버가 503을 돌려준 날에는 `submit()`이 결과 대신 예외로 끝나서 화면에 처리되지 않은 오류가 떴고, 대시보드의 실패 집계에도 아무것도 잡히지 않았다.
- 주문 취소(`cancel()`)에서도 서버 장애 때 비슷한 일이 있었다는 제보가 있다.
