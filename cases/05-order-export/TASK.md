# 주문 내보내기가 일부 주문을 빠뜨린 채 "완료"로 끝납니다

`orders.py`의 `export_all`은 `list_orders`를 페이지 단위로 반복 호출해 살아 있는(삭제되지 않은) 주문을 모두 모읍니다.
회계팀은 이 결과를 월말 정산에 그대로 씁니다.

## 기대한 것
- 삭제되지 않은 주문이 **빠짐없이**, id 순서대로 내보내져야 합니다.

## 실제로 일어난 것
- 지난주 오래된 테스트 주문을 한꺼번에 정리(삭제 처리)한 뒤부터, 내보내기 결과가 앞쪽 몇 건만 담긴 채 오류 없이 정상 종료됩니다.
- 정리 전에는 문제가 없었고, 지금도 삭제된 주문이 없는 환경에서는 잘 됩니다.
- 30건 중 10건을 삭제한 상황을 재현하면 20건이 나와야 하는데 5건만 나옵니다.
