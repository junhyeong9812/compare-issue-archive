# 모바일 앱 사용자 계정이 잠기지 않습니다

## 기대
같은 계정으로 비밀번호를 5번 틀리면 계정이 잠기고(이후 로그인은 423 `account locked`), 실패마다 감사 로그에 기록이 남아야 합니다.

## 실제
웹 클라이언트에서는 정상적으로 잠깁니다. 그런데 모바일 앱에서 들어온 로그인은 비밀번호를 몇 번을 틀려도 계정이 잠기지 않고, 그 뒤 올바른 비밀번호로 바로 로그인됩니다. 보안팀 확인 결과 감사 로그에도 해당 실패 기록이 하나도 없습니다. 모바일 앱의 실패 응답은 401이 아니라 500으로 찍혀 있었습니다.
