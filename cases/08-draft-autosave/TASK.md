# 초안 자동 저장이 마지막 내용을 놓침

메모 편집기는 호스트 루프가 100ms마다 `DraftAutosaver.tick()`을 부릅니다. 변경은 즉시 미리보기(`onChange`)로 나가고, 저장소 쓰기는 디스크 부담 때문에 `saveIntervalMs`(기본 1초)에 한 번 이하로만 합니다.

## 기대한 것
- 사용자가 타이핑을 멈추면, 잠시 뒤 마지막으로 친 내용이 저장소에 남아 있어야 한다.
- 저장소 쓰기가 일시적으로 실패하면(디스크 바쁨 등) 나중에 다시 시도해서 결국 저장돼야 한다.
- 저장 시도는 지금처럼 `saveIntervalMs`보다 자주 일어나면 안 된다.

## 실제로 일어난 것
- "Hello"를 빠르게 치고 손을 뗐는데, 몇 초가 지나도 저장소에는 첫 글자 "H"만 남아 있었다. 앱을 다시 열면 뒷부분이 사라져 있다. 미리보기 화면은 정상적으로 "Hello"까지 보였다.
- 디스크가 잠깐 바빴던 때 쓴 초안은 아예 저장되지 않았다. 오류 표시도 없었다.
