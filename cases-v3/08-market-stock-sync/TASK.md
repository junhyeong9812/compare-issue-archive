# 품절된 상품이 오픈마켓에서 계속 판매 중으로 보입니다

## 상황
포인트몰 재고 서비스(hbstock)는 마켓 동기화(`POST /market/sync`)로 상품별 판매 가능 수량을 오픈마켓에 보냅니다.
어제 판매 마감 후 동기화를 돌렸는데, 창고에서 다 팔린 상품이 마켓에는 여전히 판매 중으로 떠 있습니다.

- 동기화 응답은 200이고 변경된 상품 5개를 모두 보냈다고 나옵니다. 오류 로그는 없습니다.
- 그중 수량이 늘거나 줄어든 상품(GD-102, GD-105)은 마켓 수량이 정상으로 바뀌었습니다.
- 다 팔린 상품(GD-104, VC-2003, FD-303)은 마켓에서 예전 수량 그대로 판매 중이고, 고객 주문이 계속 들어와 취소 처리하고 있습니다.
- 마켓 대사 리포트(`GET /reports/market-drift`)와 상품 상세(`GET /products/<sku>`)에도 같은 상품들이 어긋나게 나옵니다.
- 출고로 소진됐든, 주문 예약으로 묶였든, 실사로 0이 됐든 같은 증상입니다. 동기화를 다시 돌려도 그대로입니다.

환경: Ubuntu 24.04, Python 3.12. 오픈마켓 재고 연동 CLI는 `vendor/bin/stockpush`(벤더 제공 바이너리, 수정 불가)입니다. 샘플 데이터(`tests/fixtures/catalog_2026_10.json`)로 재현됩니다.

## 기대
- 동기화 후 마켓의 상품별 수량은 우리가 판매하려는 수량(재고 − 예약 − CS 보관분)과 같아야 하고, 팔 수 있는 수량이 없는 상품은 마켓에서 판매 중이 아니어야 합니다.
- 지금 정상으로 반영되는 상품의 수량은 그대로여야 합니다.
