# 일부 회원의 포인트가 적립되지 않고, 다른 회원은 이상하게 많이 쌓였습니다

## 상황
10/6 결제분 적립 배치 이후 고객센터에 포인트 문의가 들어왔습니다.

- 김서연 님(GOLD)이 10/6에 두 번 결제했는데 앱 포인트 화면의 잔액이 0P라고 합니다. 기대 적립은 2,068P입니다.
- 반대로 박지훈 님(BASIC)은 본인 결제로는 690P여야 하는데 잔액이 2,758P로 나옵니다.
- 이 밖에도 잔액이 0인 회원과 결제보다 많이 쌓인 회원이 몇 명 더 있고, 나머지 회원은 정확합니다. 매번 같은 회원들입니다.
- 적립 배치는 오류 없이 끝났고 결제 건마다 벤더 적립 번호도 받았습니다. 마케팅의 '이달 적립 상위' 리포트 숫자는 맞아 보입니다.
- 지난달에도 비슷한 문의가 있었는데 수기 조정으로 처리했다고 합니다.

환경: Ubuntu 24.04, JDK 21. 포인트 벤더 연동은 벤더 제공 CLI `vendor/bin/ptsctl`(수정 불가)입니다. 샘플 데이터(`fixtures/`)로 재현됩니다.

## 기대
- 모든 회원의 포인트 잔액이 본인 결제로 적립된 포인트와 같아야 합니다.
- 지금 정확한 회원의 잔액·적립 규칙(등급 적립률, 건당 상한, 취소 제외, 재실행 시 중복 없음)은 그대로여야 합니다.
