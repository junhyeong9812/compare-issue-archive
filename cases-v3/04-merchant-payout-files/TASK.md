# 파트너가 일부 날짜의 정산 파일을 받지 못했다고 합니다

## 상황
가맹 파트너 한빛마트(P001)에서 10월 첫 주 정산 파일 중 10월 2일, 10월 5일 것을 받지 못했다는 연락이 왔습니다.
파트너 담당자는 나머지 날짜(10/1, 10/3, 10/4, 10/6, 10/7) 파일은 정상으로 받아 적재했다고 합니다.

- 우리 쪽 일일 배치(`bin/payout run <날짜>`)는 7일 모두 exit 0으로 끝났고, 로그에 오류나 재시도가 없습니다.
- `bin/payout manifest 20261002`·`20261005`를 보면 해당 날짜도 전송 CLI의 접수 번호(T…)가 다 찍혀 있습니다.
- 같은 날짜의 다른 파트너(P002·P003)는 받았다고 합니다. 금액·건수 문의는 없습니다.
- 운영팀이 수신 확인(`bin/payout receipts P001 20261001 20261007`)을 돌려 보니 10/2·10/5 줄만 `-`로 나옵니다.

환경: Ubuntu 24.04, bash 5.2, GNU coreutils. 파일 전송 벤더 CLI는 `vendor/bin/xferq`(벤더 제공 바이너리, 수정 불가)입니다.
저장소의 샘플 매입 추출(`fixtures/txns-202610.tsv`)로 재현됩니다.

## 기대
- 파트너가 매일의 정산 내역을 빠짐없이 내려받을 수 있어야 합니다.
- 파트너와 합의한 파일 규격(파일명 접두, 파일당 명세 행 수 한도, 본문 형식)은 지켜야 합니다.
- 지금 정상으로 받고 있는 날짜·파트너의 파일은 그대로여야 합니다.
