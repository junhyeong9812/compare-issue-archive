# issue/fxwallet/valuation-rate-once-daily — 이유·대안·결과

태그: `cost` · `vendor-quota` · `cache`

## 이유 상세
1. 2025-02 호출량은 월 한도의 3.2배였고 초과분 과금이 외화지갑 월 운영비의 40%를 차지했다.
2. 평가액은 회계상 의미가 없는 참고 표시다. 환전·결제 금액은 거래 시점 조회값으로 따로 계산한다.
3. 벤더 고시는 영업일 오전 9시 전후 1회가 기준이고 장중 변동분은 고객 문의가 거의 없었다.

## 검토한 대안
| 대안 | 기각 이유 |
|---|---|
| 5분 캐시 | 호출량이 한도 안이지만 여유가 적음, 장애 시 일관성 없음 |
| 벤더 계약 상향 | 단가 대비 효과 없음 |
| **하루 1회 조회 + 기준 시각 표시** | 채택 |

## 결과
- 호출량 월 한도의 18% 수준, 화면 지연 해소.

## 이후 변경 시 지켜야 할 것
- 평가 화면에서 열람마다 벤더를 다시 부르지 않는다. 조회 주기를 늘리려면 호출량 계산을 먼저 한다.

## 바꿔도 되는 것
- 조회 시각, 표시 문구, 지원 통화 목록.
