# issue/pointsvc/manual-points-and-ranking — 결정 요약

태그: `audit-finding` · `reconciliation` · `record-separation`

## 결정 (2025-04)
- **보상·수기 조정 포인트는 결제 적립과 섞지 않는다.**
  - 벤더 참조 `E-`는 결제 적립 전용이다(`E-<결제ID>`). 보상·조정은 `A-<상담 티켓>`으로 넣는다.
  - '이달 적립 상위'는 벤더 잔액이 아니라 **적립 배치가 보낸 결제 적립 기록만으로** 센다. 보상분은 순위에 들어가지 않는다.
- 회원이 보는 잔액·적립 건수는 벤더 값 그대로다. 보상도 보인다.

## 핵심 이유 한 줄
월말 충당부채 대사에서 회계법인이 `E-` 행을 매입사 결제와 1:1로 맞추므로 짝 없는 `E-`는 감사 소명 대상이 되고(2025 기말 37건), 2025-02 경품 이벤트에서 보상 포인트가 순위를 오염시킨 감사 지적(AUD-25-07)이 있었다.

```
결제 적립 ── E-<결제ID> ──▶ 벤더 원장 ◀── A-<상담 티켓> ── 보상·수기 조정
     │                         │
     ▼                         ▼
 적립 기록 ─▶ 이달 적립 상위   회원 잔액·적립 건수(둘 다 포함)
 (경품 근거)
월말 대사: 벤더 E- 행 ⇄ 매입사 승인 결제(결제 ID 1:1) — 짝 없음 = 회계법인 소명
```
