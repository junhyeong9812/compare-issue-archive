# issue/onboarding/signup-age-and-activation — 결정 요약

태그: `regulation` · `inspection-finding` · `defense-in-depth`

## 결정 (2025-06)
- **만 19세 미만은 본인확인을 통과해도 정회원(active)이 되지 않는다.**
- 가입 화면 연령 검사와 **별개로**, 정회원 전환 직전에 본인확인 실행일 기준 연령을 다시 확인한다. 두 검사는 따로 둔다.
- 당시에는 미달 회원을 준법감시 검토(review)로 넘겼다(가입 단계에서 이미 막히므로 예외 경로용).

## 핵심 이유 한 줄
정회원 전환 = 후불결제 한도 자동 개통이고, 혁신금융 지정 조건이 만 19세 미만 후불 이용을 금지한다. 2025-05 점검에서 가입 화면 한 곳만 막다가 만 18세 2명이 정회원이 된 사례가 지적됐다.

```
가입 접수 ──(가입 연령 검사)──▶ pending ──본인확인──▶ 판정 1 ──(전환 직전 연령 재확인)──▶ active ─▶ 후불 한도 자동 개통
                                                          │                 └─ 만 19세 미만 → active 금지
                                                          └ 판정 2 ─▶ rejected
```
