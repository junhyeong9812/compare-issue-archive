# issue/filegw/no-auto-resend-after-ack — 파트너가 수신 확인한 파일은 자동으로 다시 보내지 않는다 — 맥락

## 당시 맥락 (2025-01)
- 파트너 파일 게이트웨이(filegw)는 제휴 은행·보험사에 일일 파일을 SFTP로 보내고, 상대가 `.ack` 파일을 올리면 수신 확인으로 본다.
- 2024-12까지는 원본 파일이 다시 만들어지면(원천 정정 등) 같은 이름으로 자동 재전송했다.
- 2024-12-30 제휴 보험사 A가 이미 적재·처리한 일일 청약 파일이 자동 재전송으로 덮어써졌고, A의 적재기가 같은 파일을 다시 처리해 청약 87건이 중복 등록됐다.

## 질문
1. 같은 이름으로 다시 보내면 상대 쪽에서는 무엇이 일어나나?
2. 수신 확인(ack) 전과 후의 재전송은 무엇이 다른가?
3. 원천 정정이 생기면 이미 수신 확인된 날짜분은 어떻게 전달하나?
