# issue/payout/split-day-receipts-all-parts — 결정 요약

태그: `partner-contract` · `reconciliation` · `ops-report`

## 결정
- 수신 확인 리포트에서 **분할된 정산일은 파트 1..n이 수신함에 모두 있을 때만 건수·금액 칸을 숫자로 채운다.** 하나라도 빠지면 두 칸은 `-`(파일이 없는 날과 같은 표시).

## 핵심 이유
- 파트너 계약(PAY-IF-03 rev.2 부속서 B §5)상 파트너 적재기는 **파트가 다 모인 정산일만 적재·지급**한다. 리포트의 건수·금액 칸은 당직 회신과 정산팀 지급 대사가 "파트너가 적재할 수 있는 날"로 읽는 칸이다.

## 한눈에
```
정산일 D, 파트 3개 중 2개만 수신함에 있음
  파트너 적재기  → D 전체 미적재 → 가맹점 지급 보류
  리포트 건수·금액 칸 → '-'  (숫자를 넣으면 당직·정산팀은 "적재 가능"으로 읽는다)
  일부 도착 사실 → 두 칸 밖에 따로 표시하는 것은 괜찮다
```
