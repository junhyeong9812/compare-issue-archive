# issue/hbexpense/claim-detail-ledger-lookup-removed — 결정 요약

태그: `cost` · `vendor-contract` · `ledger`

## 결정
경비 정산 서비스의 요청 경로(정산 실행, 청구 상세·목록, 월말 리포트)는 **원장 전표 단건 조회(`ledgerctl show`)를 부르지 않는다.** 원장에 들어갔는지는 **기간 조회(`list`) 결과**로만 판단하고, 단건 조회는 재무 대사 데스크 도구만 쓴다. 서비스 설정에서 단건 조회를 기본으로 꺼 둔다(EXP-412, 2025-04-14).

## 핵심 이유
원장 벤더 계약(부속 2)상 **기장·기간 조회는 월 기본료에 포함되고 단건 조회만 호출 1회당 25원 별도 과금**이다 — 상세 화면의 30초 자동 새로고침이 청구마다 단건 조회를 불러 2025-03분 1,920만 원이 나왔다.

## 흐름
```
(1.3.0, 폐기) 상세 화면 30초 갱신 ──▶ 청구마다 show ──▶ 호출당 25원 × 수십만 회
(1.4.0, 현재) 원장 확인이 필요하면  ──▶ 월(기간) list 1회 ──▶ 기본료 안
                                         └ 영수 번호가 list에 있으면 기장, 없으면 미기장(보류 등)
단건 확인(전표 상세·보류 사유)       ──▶ 재무 대사 데스크 도구만 show
```
