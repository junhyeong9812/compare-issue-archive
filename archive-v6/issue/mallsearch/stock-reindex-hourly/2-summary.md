# issue/mallsearch/stock-reindex-hourly — 결정 요약

태그: `decision` · `cost` · `search`

## 결정 (2025-10-20, 포인트몰 검색 연동)

재고 수량 변화는 검색 색인에 **매시 정각 일괄 갱신**으로만 반영한다. 상품명·가격·판매 종료 같은 상품 정보 변경은 지금처럼 즉시 갱신한다. 검색 결과의 품절 표시는 최대 1시간 늦을 수 있고, 상품 상세와 주문 단계는 재고 서비스의 실시간 값을 쓴다.

## 핵심 이유 한 줄

mallsearch는 색인 갱신 요청 건수로 과금하고, 갱신 요청의 94%가 재고 수량 변화였다. 정시 일괄 갱신으로 바꾸면 월 비용이 실시간 대비 약 1/11이 된다.

## 지켜야 할 것 / 바꿔도 되는 것 (요약)

- 지켜야 할 것: 주문 가능 여부는 색인이 아니라 실시간 재고로 판정한다.
- 바꿔도 되는 것: 일괄 주기(비용 한도 안에서), 특정 상품군의 즉시 갱신 예외.
