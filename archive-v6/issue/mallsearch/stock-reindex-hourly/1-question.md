# issue/mallsearch/stock-reindex-hourly — 포인트몰 검색 색인은 재고를 정시에만 반영한다 — 맥락

## 당시 상황 (2025-10)
- 포인트몰 검색은 외부 검색 SaaS(mallsearch)를 쓴다. 상품 정보가 바뀌면 색인 갱신 요청을 보내고, 검색 결과의 품절 여부·정렬은 색인 값으로 정한다.
- 2025-09부터 재고 변화(주문·입고·실사)마다 색인 갱신을 보내기 시작한 뒤, 월 검색 비용이 약 11배로 뛰었다. mallsearch는 색인 갱신 요청 건수로 과금한다.
- 검색 응답 시간도 갱신 폭주 시간대(명절 프로모션)에 2~3초까지 늘었다.

## 당시 질문
1. 비용이 왜 그렇게 늘었나? 어떤 변경이 갱신 요청의 대부분인가?
2. 검색 결과의 품절 표시가 몇 분 늦으면 무엇이 문제인가?
3. 상품 상세·주문 단계에서는 재고를 어디서 읽나?
4. 실시간성이 꼭 필요한 변경은 무엇인가?
