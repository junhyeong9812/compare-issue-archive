# issue/mallsearch/stock-reindex-hourly — 이유·대안·결과

태그: `decision` · `cost` · `search`

## 이유 상세

1. **갱신 요청의 대부분이 재고 수량이었다.** 2025-09 한 달 갱신 요청 410만 건 중 94%가 주문·입고·실사로 인한 수량 변화였다. mallsearch 계약은 월 30만 건까지 정액, 초과분은 건당 과금이다.
2. **검색 결과의 품절 표시가 늦어도 주문은 막힌다.** 검색에서 판매 중으로 보여도 상품 상세는 재고 서비스 값을 쓰므로 "품절"로 보이고 주문 버튼이 꺼진다. 고객 경험은 나빠지지만 없는 재고로 주문이 들어가지는 않는다.
3. **상세·주문은 실시간이다.** 상품 상세 API와 주문 API는 색인을 읽지 않는다.
4. **즉시 갱신이 필요한 것은 상품 정보다.** 가격·판매 종료가 늦으면 잘못된 가격으로 노출된다(표시 광고 문제). 이것은 건수가 적어 즉시 갱신해도 비용이 작다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 실시간 갱신 유지 + 계약 상향 | 연간 비용이 검색 매출 기여를 넘는다 |
| 5분 주기 일괄 | 비용 절감 폭이 1/3 수준. 한도 초과 |
| 품절·재입고 전환만 즉시, 수량은 정시 | 검토 당시 전환 건수 추정이 불확실해 보류(이후 재검토 대상) |
| 수량은 매시 정각 일괄 (채택) | 정액 한도 안. 품절 표시 지연은 상세 단계에서 보완 |

## 결과
- 2025-11 월 갱신 요청 27만 건, 정액 한도 안. 검색 응답 시간 정상화.
- "검색에선 판매 중인데 들어가면 품절" 문의 월 20건 안팎.

## 이후 변경 시
- **지켜야 할 것**: 주문 가능 판정은 실시간 재고로 한다. 수량 갱신 요청이 정액 한도(월 30만 건)를 넘지 않게 한다.
- **바꿔도 되는 것**: 일괄 주기, 품절·재입고 전환만 즉시 반영하는 예외(전환 건수가 한도 안이면).
