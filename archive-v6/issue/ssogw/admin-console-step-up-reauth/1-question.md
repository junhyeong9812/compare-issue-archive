# issue/ssogw/admin-console-step-up-reauth — 운영 콘솔 위험 작업의 재인증 결정 — 맥락

## 당시 맥락 (2024-11)
- 사내 운영 콘솔(가맹점 한도·정산 계좌·수수료율 변경)은 사내 SSO(ssogw) 세션으로 들어간다. 세션은 8시간이었고, 한 번 로그인하면 퇴근까지 재인증이 없었다.
- 2024-10 전자금융 IT 부문 검사에서 "공용 단말에서 로그인된 콘솔로 정산 계좌 변경이 가능한 상태"가 지적됐다(지적 3-2, 개선 기한 2025-01-31). 실제로 콜센터 공용 PC에 운영 콘솔 세션이 남아 있던 사례가 확인됐다.
- 운영팀은 "한도 변경은 하루 수십 건이라 매번 OTP를 넣으면 업무가 멈춘다"고 했다.

## 질문
1. 검사 지적의 요지는 무엇이었고, 개선 계획서에 무엇을 약속했나?
2. 무엇을 정했나 — 어떤 작업에 언제 재인증을 요구하나?
3. 검토했다가 버린 대안은 무엇이고 왜 버렸나?
4. 이후 "재인증이 너무 잦다"는 요청이 오면 무엇을 지키고 무엇은 바꿔도 되나?
