# issue/ssogw/admin-console-step-up-reauth — 결정 요약

태그: `audit` · `auth` · `admin-console`

## 결정
운영 콘솔의 **정산 계좌 변경·수수료율 변경·관리자 권한 부여**는 직전 **10분 안에 OTP 재인증**을 한 세션에서만 실행된다. 가맹점 한도 변경은 재인증 없이 되지만 **두 번째 승인자**가 필요하다. SSO 세션 자체는 8시간 그대로다(SEC-108, 2024-12-09).

## 핵심 이유
2024-10 전자금융 IT 검사 지적 3-2("공용 단말 세션으로 정산 계좌 변경 가능")에 대해 개선 계획서에 **"자금 흐름을 바꾸는 작업은 작업 시점 본인 확인"**을 약속했고, 이행 점검이 매년 있다.

## 흐름
```
콘솔 작업 요청 ─┬ 정산 계좌·수수료율·권한 부여 ─ 최근 OTP ≤ 10분? ─ 아니오 ─▶ OTP 요구
               │                                                └ 예 ─▶ 실행 + 감사 로그(재인증 시각)
               ├ 가맹점 한도 변경 ─▶ 2인 승인 대기 ─▶ 실행 + 감사 로그(승인자 2명)
               └ 조회 ─▶ 8시간 SSO 세션으로 실행
```
