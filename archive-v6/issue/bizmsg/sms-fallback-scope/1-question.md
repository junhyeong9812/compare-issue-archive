# issue/bizmsg/sms-fallback-scope — 알림톡 실패 시 SMS 대체 발송 범위 — 맥락

## 당시 상황
- 메시지 중계(bizmsg)는 알림톡을 먼저 보내고, 실패하면(카카오 미가입·차단·수신 거부) 같은 내용을 SMS·LMS로 대체 발송했다. 모든 템플릿이 대상이었다.
- 2024-12 통신사 중계 계약을 갱신하면서 LMS 단가가 건당 26원에서 39원으로 올랐다. 알림톡은 7원.

## 무엇이 문제였나
- 2025-01 메시지 비용이 월 4,100만 원에서 6,300만 원으로 늘었다. 증가분의 80%가 마케팅·안내성 템플릿의 LMS 대체 발송이었다.
- 대체 발송을 전부 끄면 결제 승인·보안 인증 문자가 카카오 미가입 고객에게 가지 않는다.

## 정해야 했던 것
1. 어떤 템플릿만 대체 발송할 것인가?
2. 대체 발송하지 않는 템플릿의 실패는 어떻게 처리할 것인가?
3. 길이 때문에 SMS가 LMS로 바뀌는 비용은 어떻게 줄일 것인가?
