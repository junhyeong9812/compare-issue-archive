# issue/ovsettle/fxq-b2-values-stay-internal — 이유·대안·결과

태그: `vendor-contract` · `data-export` · `fx`

## 이유 상세
1. **계약 범위.** fxq 기본 계약은 공시분(소스 0) 값의 재배포를 허용한다. 2025-09 체결한 부속 계약 B-2는 비공시 소스(1~3) 값을 추가로 받는 대신, 그 값을 "사내 정산 처리 목적으로만" 쓰도록 제한한다. 사외 제3자(파트너·회계법인 포함)에게 값이 전달되면 위반이다.
2. **휴장일 적용 환율 = B-2 값.** 휴장일에는 기본 조회가 전 영업일 값을 이월해 내고(`~N` 꼬리표), 정산은 같은 날짜를 소스 3으로 다시 조회한 값을 쓴다. 그래서 휴장일 거래의 "원화 환산에 쓴 환율"은 숫자 그대로 B-2 값이다. 영업일에는 소스 3 = 공시값이라 문제가 없다.
3. **실제 지적.** 2025-11-18 점검에서 회계 CSV의 rate 칸(휴장일 행은 B-2 값)이 외부 회계법인 공유 폴더로 나간 것이 지적됐다. 위약 조항은 법무가 협의 중이고, 같은 일이 반복되면 B-2 계약 갱신이 어렵다는 통보를 받았다.

## 검토한 대안
| 대안 | 기각 이유 |
|---|---|
| 회계 CSV를 사내 전용으로 돌리고 rate 칸 유지 | 재무가 외부 회계법인에 그대로 공유하는 흐름을 막을 수 없음 |
| 휴장일에도 정산에 공시(이월) 값 사용 | 파트너 명세(벤더 정산값 기준)와 휴장일마다 어긋남 — B-2 계약을 맺은 이유 자체가 사라짐 |
| 벤더와 재배포 허용 조항 추가 협상 | 비용이 정산 규모 대비 과함(견적 연 단위), 보류 |
| **rate 칸 제거 + 비공시 값 사외 반출 금지 원칙** | 채택 |

## 결과
- OPS-2291: 회계 CSV에서 rate 칸 제거(2025-11-21). 재무는 원화 금액만으로 충분하다고 확인.
- 이후 사외로 나가는 새 산출물을 만들 때는 이 기록을 확인한다.

## 이후 변경 시 지켜야 할 것
- 파트너·외부로 나가는 어떤 텍스트·파일에도 **휴장일 정산값(비공시 소스 값)을 숫자로** 싣지 않는다. 쉼표·자릿수를 바꾼 표기도 같다.
- 정산 금액 자체(원화)는 결과값이므로 내보내도 된다. 환율을 역산할 수 있게 "적용 환율" 칸을 따로 두는 것이 문제다.
- 회계 CSV 형식(칸 구성)은 OPS-2291 이후 그대로 둔다.

## 바꿔도 되는 것
- 공시분(기본 소스) 값은 어디에 보여 줘도 된다 — 영업일 거래의 환율, 앱 환율판, 휴장일의 공시(이월) 값 표기.
- 휴장일 거래는 환율 칸을 비우거나 "휴장일·정산 기준 환율 적용" 같은 안내로 대신해도 된다.
- 사내 리포트·대사·운영 콘솔(사외로 나가지 않는 것)에는 정산값을 보여 줘도 된다.
