# issue/ovsettle/fxq-b2-values-stay-internal — 환율 벤더의 정산 전용 값은 사내 밖으로 내보내지 않는다 — 맥락

## 당시 맥락 (2025-11)
1. 해외카드 파트너 정산은 2025-09부터 환율 벤더(fxq)와 부속 계약 B-2를 맺고, 벤더 휴장일(주말·공휴일)에는 기본 공시값(전 영업일 값 이월) 대신 **비공시 소스(3번)** 값으로 원화를 환산한다. 파트너 명세가 이 값과 맞기 때문이다.
2. 회계 CSV 내보내기에는 일자·파트너별 gross·수수료·순액과 함께 **적용 환율(rate) 칸**이 있었다. 재무는 이 파일을 외부 회계법인 공유 폴더에 매월 올렸다.
3. 2025-11-18 벤더 정기 점검에서 벤더 AM이 "B-2 값이 사외 파일에 실려 나간다"고 지적했다. 위약 조항 적용 여부는 법무와 협의에 들어갔다.
4. 질문: 정산 시스템이 만드는 어떤 산출물에 어떤 환율 값을 실어도 되는가? 이미 나간 파일은 어떻게 하고, 앞으로 새 산출물(파트너 안내, 내역서 등)을 만들 때 무엇을 지켜야 하는가?
