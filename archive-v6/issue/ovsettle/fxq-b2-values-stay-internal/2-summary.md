# issue/ovsettle/fxq-b2-values-stay-internal — 결정 요약

태그: `vendor-contract` · `data-export` · `fx`

## 결정
- 환율 벤더의 **비공시 소스(1~3번) 값은 사내 정산 처리 안에서만** 쓴다. 휴장일 정산에 쓰는 3번 값도 여기에 들어간다.
- 사외로 나가는 메일·첨부·파일(파트너 안내, 외부 회계법인 공유 파일 등)에는 이 값을 싣지 않는다. 회계 CSV의 환율 칸은 뺐다(OPS-2291, 2025-11-21).
- **공시분(기본 소스 0번) 값은 제한 없음** — 앱 환율판, 고객·파트너 안내에 써도 된다. 영업일에는 정산값이 곧 공시값이다.

## 핵심 이유 한 줄
벤더 부속 계약 B-2가 비공시 소스 값을 '사내 정산 처리 전용'으로만 허락하고, 2025-11 점검에서 회계 CSV를 통한 반출이 실제로 지적됐다.

```
            공시분(소스 0)            B-2분(소스 1~3)
앱 환율판        O                        X
파트너·외부 파일  O                        X   ← 휴장일 '적용 환율'이 여기에 해당
사내 정산 계산    O                        O   (원화 금액은 결과값이라 내보내도 됨)
```
