# issue/escrowpay/auto-confirm-delivery-d8 — 이유·대안·결과

태그: `escrow` · `carrier-contract` · `settlement`

## 이유 상세
1. 고객 반품 접수 기한은 실제 수령일 기준 7일이다. 자동 구매확정을 실제 배송일 + 7일로 하면, 연동이 늦은 건은 반품 기한이 끝나기 전에 대금이 판매자에게 나간다.
2. 2025-04 회수 대상 32건 중 29건이 배송완료 이벤트가 1~2영업일 늦게 들어온 건이었다. 회수는 판매자 다음 정산에서 상계하지만, 탈퇴·휴면 판매자는 회수가 안 돼 손실 처리했다.
3. 택배사 연동 계약은 지연 상한(2영업일)만 보장하고 실제 배송 시각을 사후에 고쳐 보내지 않는다.

## 검토한 대안
| 대안 | 기각 이유 |
|---|---|
| 실제 배송일 + 7일 유지, 회수 프로세스 강화 | 탈퇴 판매자 손실이 남음 |
| 이벤트 수신일 + 9일(2영업일 여유) | 판매자 반발이 큼, 1일 여유로 회수 건이 월 2건 이하로 줄어 충분 |
| **이벤트 수신일 + 8일** | 채택 |

## 결과
- 2025-05-20 적용 후 자동 구매확정 뒤 반품 회수 월 1~2건.

## 이후 변경 시 지켜야 할 것
- 자동 구매확정 기준일을 실제 배송일·주문일로 바꾸지 않는다. 날짜 수를 줄이려면 택배사 지연 상한 계약부터 바뀌어야 한다.

## 바꿔도 되는 것
- 고객이 직접 구매확정한 건의 지급 시점, 판매자 화면 문구, 알림 시각.
