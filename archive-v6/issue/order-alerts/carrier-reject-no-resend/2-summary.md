# issue/order-alerts/carrier-reject-no-resend — 결정 요약

태그: `duplicate-send` · `vendor-contract` · `retry`

## 결정
- 2025-07-28(1.9.0): 실패 알림 자동 재발송을 끈다(재발송 대상 사유 목록을 비움).
- 재발송을 다시 켤 때 **`E-CARRIER`(통신사 일시 반려)는 재발송 대상에 넣지 않는다.** `E-THROTTLE`은 넣어도 된다.

## 핵심 이유
- 대행사 계약 부속서 3장: `E-CARRIER` 건은 **대행사가 대기열에 두었다가 30분 안에 스스로 다시 보내고, 그 결과를 알려 주지 않는다.** 우리가 다시 보내면 고객은 같은 문자를 두 통 받는다(INC-0719, 312명).

## 한눈에
```
E-THROTTLE  대행사: 받지 않은 요청        → 우리가 다음 회차에 다시 보내도 1통
E-CARRIER   대행사: 대기열 → 30분 안 재전송(통보 없음) → 우리가 또 보내면 2통
E-SPAM / 번호 오류  다시 보내도 소용없음
```
