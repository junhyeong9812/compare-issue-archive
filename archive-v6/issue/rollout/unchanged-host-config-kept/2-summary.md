# issue/rollout/unchanged-host-config-kept — 결정 요약

태그: `cost` · `deploy` · `db-connections`

## 결정
설정 배포는 **렌더한 설정 값이 이전과 같은 서버의 `app.conf`를 다시 쓰지 않는다 — 헤더까지 바이트 그대로 둔다.** 값이 바뀐 서버만 파일이 바뀐다. 그 결과 헤더의 릴리스는 "그 서버를 마지막으로 바꾼 릴리스"를 뜻한다(OPS-1874, 2025-07-02).

## 핵심 이유
서버 에이전트는 파일 내용 해시가 바뀌면 앱을 재기동하고 재기동 중 DB 커넥션 풀이 잠시 두 배가 되는데, **pay-db 요금은 그 달 최대 동시 커넥션 구간으로 매겨지고 분기 끝까지 유지된다** — 헤더만 바뀐 전 서버 동시 재기동 한 번으로 3분기 내내 상위 구간 요금을 냈다.

## 흐름
```
배포 ─▶ app.conf 내용 변경? ─ 예 ─▶ 에이전트 sha256 변화 ─▶ graceful restart
                │                                       └ 새 풀 연결 → (≈40초 겹침) → 옛 풀 닫기
                │                                         전 서버가 같은 분에 → 커넥션 ×2 → 요금 구간 ↑ (분기 유지)
                └ 아니오(값 동일) ─▶ 파일 그대로(헤더 포함) ─▶ 에이전트 아무것도 안 함
```
