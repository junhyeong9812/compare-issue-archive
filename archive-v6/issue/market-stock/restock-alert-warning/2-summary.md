# issue/market-stock/restock-alert-warning — 결정 요약

태그: `decision` · `incident-recurrence` · `marketplace-policy`

## 결정 (2025-06-30, 재고 서비스 2.4.0)

판매 중이 아니게 내린(품절) 상품은 **10분 증분 동기화에서 판매 재개하지 않고, 매일 06:00 전체 동기화에서만 판매 재개**한다. 품절 처리는 지금처럼 즉시 보낸다.

## 핵심 이유 한 줄

오픈마켓은 상품이 판매 중 아님 → 판매 중으로 바뀔 때마다 **재입고 알림**을 보내고, 같은 상품의 재입고 알림이 **마켓 집계일(06:00~다음 날 06:00) 하루에 두 번 이상**이면 판매자 경고 1건을 준다. 품절↔판매 반복으로 경고 2건을 받았다(MKT-118).

## 흐름

```
06:00 전체 동기화 ─────────────────────────────── 다음 06:00
  │  품절 ─▶ 재개(알림 1) ─▶ 품절 ─▶ 재개(알림 2 = 경고) ─▶ ...
  │
  2.4.0 이후: 증분 동기화의 재개를 모두 막음 → 재개는 06:00 전체 동기화에서 하루 한 번
```

## 지켜야 할 것 / 바꿔도 되는 것 (요약)

- 지켜야 할 것: 집계일 하루(전체 동기화 사이) 같은 상품의 판매 재개는 한 번까지. 품절 처리는 늘 즉시.
- 바꿔도 되는 것: 그날 첫 판매 재개를 06:00까지 미루는 것. 경고는 두 번째 알림부터라, 첫 재개는 증분 동기화에서 바로 해도 된다.
