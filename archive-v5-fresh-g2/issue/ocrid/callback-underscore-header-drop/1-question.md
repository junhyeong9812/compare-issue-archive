# issue/ocrid/callback-underscore-header-drop — 신분증 진위확인 콜백의 서명 헤더가 새 인그레스에서 사라졌다 — 질문

## 질문
1. (예측) 진위확인 벤더 `ocrid`는 검사 결과를 콜백으로 보내며 서명을 `x_ocr_sig` 헤더에 담는다. 인그레스를 nginx 기본 설정으로 옮긴 뒤 콜백 핸들러는 이 헤더를 받는가? 핸들러는 무엇을 응답하는가?
2. (왜) 비대면 계좌 개설 고객 중 약 30%만 "본인 확인 진행 중"에서 멈췄다. 왜 전부가 아니라 일부였나?
3. (경계) 벤더는 콜백이 실패하면 몇 번 재시도하고, 그 뒤에는 무엇을 하는가? 고객 상태는 왜 계속 "진행 중"으로 남았나?
4. (왜) 핸들러 로그에는 `401 signature missing`이 찍혔지만 알림은 없었다. 이 로그를 보고도 바로 원인을 잡지 못한 이유는?
5. (경계) 서명 검증을 끄거나 헤더 이름을 하이픈으로 바꿔 달라고 벤더에 요청하는 것 — 각각 무엇이 문제인가?
6. (연결) "일부 고객의 확인 결과가 반영되지 않음" 증상에서 배치 처리 쪽 원인과 콜백 수신 쪽 원인을 가르는 첫 확인은?
