# issue/filegw/relay-cert-reload-retry-expire — 파트너 파일 게이트웨이는 인증서 만료를 "재시도 중"으로 72시간 숨긴다 — 질문

## 질문
1. (예측) 정산 배치가 `filegw put --partner HNB settle_20260611.dat`를 실행해 `queued F00031822`와 exit 0을 받았다. 파트너 은행의 클라이언트 인증서는 전날 만료됐다. 파트너는 파일을 받는가? `filegw status F00031822`는 시간이 지나며 무엇을 보여 주는가?
2. (왜) 인증서 갱신 담당자는 만료 일주일 전에 새 인증서 파일을 키스토어 경로에 덮어썼다. 그런데 왜 만료일 다음 날부터 전송이 실패했나?
3. (경계) 릴레이 실패 상태 `R`은 언제 `X`로 바뀌는가? `X`가 된 파일은 어디에 남고, 다시 보내려면 무엇을 해야 하는가?
4. (왜) 배치·게이트웨이 모두 오류를 내지 않았는데 사건은 파트너의 "미수신" 문의로 사흘 뒤에야 알려졌다. 왜 그 사이 아무 알림이 없었나?
5. (연결) 이 사건은 이름 조건에 따른 격리와 무엇이 다른가? "파일이 안 갔다"는 같은 증상에서 두 원인을 가르려면 무엇을 먼저 확인하나?
6. (연결) 인증서 교체 절차와 배치 완료 판정에 각각 무엇을 추가해야 같은 일이 재발하지 않는가?
