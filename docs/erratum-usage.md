# 정정: 하위 에이전트를 쓴 실행의 토큰 과소 집계

- 날짜: 2026-10-12
- 발견: 후속 프로젝트 [graph-nav-experiment](https://github.com/junhyeong9812/graph-nav-experiment)를 준비하면서 이 저장소의 원시 로그 1,873개를 다시 점검했다.
- 원 결과 파일(`runs.jsonl`·`summary.md`·`analysis.md`·ADR)은 그대로 두고, 정정값은 이 문서에만 쓴다.

## 무엇이 틀렸나

- **원인:** 러너는 총 토큰을 `claude -p` 결과의 메인 `usage` 4필드(input·output·cache_creation·cache_read) 합으로 집계했다. 에이전트가 하위 에이전트(Task)를 부르면 그 토큰은 메인 `usage`에 들어가지 않는다. result 이벤트의 `modelUsage`에만 합산된다.
- **비용은 맞다:** `total_cost_usd`는 하위 에이전트 비용까지 포함한다. 세 건 모두 마지막 result의 `modelUsage` 비용 합과 정확히 일치했다.

- README 표의 범위는 이렇게 바뀐다.
  - 4차 "÷B 1.08~1.27" → **1.08~1.29**
  - 5차-b "÷B 0.88~1.21" → **0.89~1.21**
- **결론 1~4는 바뀌지 않는다.** 바뀐 값은 모두 원래 방향 그대로다. 4차는 낡은 카드가 토큰을 늘린다는 결론을, 5차-b는 결정 기록이 토큰을 줄이지 않는다는 결론을 그대로 지지한다.
- 원래 점검 메모(graph-nav-experiment 작업 기록)에는 "Sonnet 4회"로 적었다. 다시 확인한 결과 3회가 맞다.
