# 자동이체 출금 알림 푸시를 못 받은 고객이 있습니다

결제운영팀 문의입니다. 자동이체 알림 서비스는 출금일마다 "곧 출금됩니다" 푸시를 예약하고(`POST /reminders/plan`), 출금이 실패하면 재출금 안내 푸시를 예약합니다(`POST /autopays/:id/failures`). 발송 현황은 출금일 리포트(`GET /reports/reminders/:date`)로 운영 화면에 띄웁니다.

## 상황
- 이번 달 들어 "출금 알림 없이 돈이 빠져나갔다", "재출금된다는 안내를 못 받았다"는 문의가 하루 몇 건씩 들어옵니다.
- 해당 날짜 리포트를 보면 예약은 모두 잡혀 있고(티켓 번호도 있음) 몇몇 줄만 "미발송"으로 남습니다. 예) `예약 6 / 발송 3 / 미발송 3`
- 못 받은 고객은 일정하지 않습니다. 같은 가맹점 계약이라도 어떤 고객은 받고 어떤 고객은 못 받습니다. 재출금 안내는 받는 날도 있고 못 받는 날도 있습니다.
- 기기 토큰·수신 동의는 정상이고, 예약 API와 푸시 도구 모두 오류 없이 끝납니다. 서버 로그에도 예외가 없습니다.

환경: Node 18, 푸시 예약 도구 pushq 2.8.0(`vendor/bin/pushq`, 상태 디렉토리는 `PUSHQ_HOME`). 저장소의 E2E 테스트로 재현됩니다.

## 기대
- 수신 동의한 고객은 출금 예정 알림과 재출금 안내를 빠짐없이 받아야 합니다.
- 알림은 고객이 설정한 시점(예: 출금 30분 전)보다 늦게 도착하면 안 됩니다. 지금처럼 그 시점에 맞춰 나가야 하고, 야간에는 지금처럼 전날 저녁으로 당깁니다.
- 리포트의 발송 건수와 고객이 실제로 받은 푸시가 일치해야 하고, 같은 알림이 두 번 나가면 안 됩니다.
