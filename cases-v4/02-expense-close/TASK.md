# 9월 경비 월말 리포트에서 일부 전표가 빠집니다

## 상황
재무팀이 월말 마감 때 경비 정산 서비스(hbexpense)의 월말 리포트(`GET /reports/monthly?month=2026-09`)로 경비 전표를 대사합니다.
9월 마감에서 리포트 건수와 합계가 정산 실행 결과보다 적게 나왔습니다.

- 9월 정산 실행(`POST /settlement/run?month=2026-09`)은 승인된 청구 10건 모두 영수 번호를 받았고 실패 0건으로 끝났습니다.
- 청구 상세(`GET /claims/<id>`)에서도 10건 모두 `posted` 상태이고 영수 번호가 있습니다.
- 그런데 월말 리포트에는 7건만 나오고 합계도 그만큼 모자랍니다. 원장 담당자도 원장 조회에서 같은 3건이 보이지 않는다고 합니다.
- 빠지는 건 매번 같은 청구들이고(예: EX-2609004, EX-2609006, EX-2609010), 금액이나 계정과목, 비용센터에는 공통점이 없습니다.
- 로그에 오류는 없습니다.

환경: Ubuntu 24.04, Python 3.12. 원장 벤더 CLI는 `vendor/bin/ledgerctl`(벤더 제공 바이너리, 수정 불가)입니다. 샘플 데이터(`tests/fixtures/claims_2026_09.json`)로 재현됩니다.

## 기대
- 정산 실행에서 영수 번호를 받은 청구는 모두 원장과 월말 리포트에 나와야 합니다.
- 지금 정상으로 나오는 전표의 내용(금액·적요 등)은 그대로여야 합니다.
