# 부분 환불한 고객에게 환불금이 덜 들어갔다는 문의가 들어옵니다

## 상황
10/7 주문 건을 10/8에 부분 환불한 고객 C-2051 님이 "보조배터리 2개를 반품했는데 1개 값만 환불됐다"고 문의했습니다.

- 주문: 고속충전 보조배터리 10000mAh 2개(각 15,900원) + C타입 케이블 1m 1개(6,900원), 결제 38,700원.
- CS는 배터리 2개를 반품 확인하고 환불을 접수했고, 10/8 밤 환불 실행은 오류 없이 끝났습니다(PG 응답도 정상, 접수 건수 일치).
- 고객 환불 내역에는 환불 15,900원으로 나오고, 배터리 한 줄은 "환불 완료", 다른 한 줄은 계속 "환불 처리 중"입니다.
- 같은 날 환불된 다른 고객들(상품 1개만 반품, 서로 다른 상품 반품, 쿠폰 사용 주문)은 금액이 정확합니다.
- 비슷한 문의가 지난달에도 몇 건 있었는데 소액이라 수기로 처리했다고 합니다. 로그에 오류는 없습니다.

환경: Ubuntu 24.04, JDK 21. PG 연동은 벤더 제공 CLI `vendor/bin/pgsim`(수정 불가)입니다. 저장소의 테스트(`test/RefundE2ETest.java`)로 재현됩니다.

## 기대
- 반품된 상품마다 실결제액이 고객에게 환불되고, 상품마다 PG 환불 번호가 붙어야 합니다.
- 반품하지 않은 상품은 환불되면 안 되고, 지금 맞게 나오는 다른 고객의 환불 금액은 그대로여야 합니다.
