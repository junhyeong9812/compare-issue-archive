# issue/pgsim/upgrade-config-template-test-endpoint — 정리 (힌트)

태그: `deployment` · `environment-drift` · `silent-failure`

## 전체 흐름

```
10/23  운영 배치 서버 패키지 업그레이드
       패키지 설치 스크립트: 설정 파일을 "기본 템플릿"으로 교체, 기존 파일은 .rpmsave 로 보관
       기본 템플릿 엔드포인트 = PG 테스트 환경
10/24  02:00 환불 배치 → 테스트 환경 → 정상 응답 (테스트 환경은 실제 출금 없음)
       고객 계좌: 입금 없음
10/25  PG 정산 대사: 환불 0건 → 발견
개발 서버: 원래 테스트 환경 설정 → 덮어써도 차이 없음
```

## 핵심 문장

- 원인은 **패키지 업그레이드가 설정 파일을 기본 템플릿으로 교체**한 것 — 기본값이 테스트 환경 엔드포인트였다.
- 테스트 환경은 정상 응답을 주므로 **응답만으로는 운영·테스트를 구별할 수 없다**.
- 개발 서버는 원래 테스트 엔드포인트라 덮어써도 결과가 같아 **사전 검증이 무력**했다.
- 대처는 설정 파일을 패키지 밖(별도 경로·구성 관리)으로 분리, 배치 시작 시 엔드포인트가 운영인지 확인, 다음 날 PG 대사를 기다리지 않고 당일 샘플 조회.
