# issue/dnsops/round-robin-stale-ip-no-fallback — 정리 (힌트)

태그: `silent-failure` · `dns`

## 전체 흐름

```
hook-relay → 10.20.1.11, 10.20.1.12, 10.20.1.19(폐기)
발송 서비스: 응답 순서 그대로 첫 주소만 사용 (라운드로빈으로 1/3 확률로 .19)
.19 연결 타임아웃 → 재시도 큐에 넣고 '발송 처리' 기록 → 재시도도 같은 확률
```

## 핵심 문장

- 라운드로빈 DNS는 **살아 있는지 모른다** — 폐기한 IP도 그대로 돌려준다.
- 일부 HTTP 클라이언트는 **첫 주소 하나만** 시도한다 — 실패율이 IP 비율과 같아진다.
- 발송 서비스는 중계 서버 적재를 '발송'으로 기록해, 연결 실패가 재시도 큐 안에 숨었다.
- 서버 폐기 시 DNS 레코드 제거를 먼저 하고, 클라이언트는 다중 주소 폴백을 쓴다.
