# issue/pushq/apns-auth-cert-expiry-ios-only — 정리 (힌트)

태그: `credential` · `partial-failure` · `vendor-notice`

## 전체 흐름

```
2024-12-02 00:00  APNs 인증서(.p12) 만료
                  갱신본: 담당자 PC 에 내려받음, 벤더 콘솔 업로드 누락
pushq 발송 시점: iOS 토큰 → APNs 핸드셰이크 실패 → 벤더 발송 로그 "credential invalid"
                 안드로이드 → FCM → 정상
예약 응답: 정상 (예약 단계는 자격증명 검사 없음)
발견: 12/04 CS 문의 "아이폰만 쿠폰 알림 없음"
```

## 핵심 문장

- 원인은 **APNs 인증서 만료** — 갱신본을 만들었지만 벤더 콘솔에 **업로드하지 않았다**.
- 예약은 정상 응답을 주고, 실패는 **발송 시점**에 벤더 발송 로그에만 남았다.
- 플랫폼별로 갈리는 미수신은 **자격증명·플랫폼 연동**을 먼저 본다 — 메시지 내용·시각과 무관하다.
- 대처는 인증서 대신 만료 없는 토큰 키(.p8) 방식으로 전환, 발송 로그 실패율을 플랫폼별 지표로 수집.
