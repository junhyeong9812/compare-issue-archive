# issue/dlqsweep/fifo-group-poison-head-block — 정리 (힌트)

태그: `ordering` · `availability`

## 전체 흐름

```
FIFO 큐, 메시지 그룹 = 가맹점 id
가맹점 G 의 메시지 m1: 필수 필드 누락(구버전 생산자) → 처리 실패 → 재시도
FIFO 규칙: 그룹의 앞 메시지가 끝나기 전 뒤 메시지 전달 안 함
재시도 한도 무제한(DLQ 미설정 큐) → 6시간 동안 G 그룹 정지
```

## 핵심 문장

- 순서 보장 큐는 **그룹 단위로 직렬**이다 — 앞 메시지가 끝나지 않으면 그 그룹 전체가 멈춘다.
- 이 큐는 DLQ가 설정되지 않아 독 메시지가 무한 재시도됐다 — `dlqsweep`의 감시 대상 목록에도 없었다.
- 다른 가맹점 그룹은 정상이어서 "일부 가맹점만 늦음"으로 보였다.
- 대처: 최대 수신 5회 후 DLQ 이동 설정, 그룹별 가장 오래된 메시지 나이 경보, `dlqsweep` 감시 목록 자동 등록.
