# issue/iamctl/hr-delta-no-catchup — 정리 (힌트)

태그: `silent-failure` · `sync`

## 전체 흐름

```
매일 02:00  iamctl sync-hr  ──GET /changes?date=<오늘>──▶ 인사 시스템
  11-13 ✓  11-14 ✗(점검)  11-15 ✓ (15일 변경분만)
                    └─ 14일 퇴사 9명 → 아무도 다시 묻지 않음

iamctl sync-hr --date 2024-11-14  ← 지정 재수신 가능 (런북에 없음)
주간 전체 대사: 인사 재직자 목록 vs iamctl 활성 계정
```

## 핵심 문장

- 인사 피드는 **요청한 날짜의 변경분만** 준다 — 실패한 날은 다음 날 실행이 메워 주지 않는다.
- `sync-hr`는 실패 다음 날 `--date`로 빠진 날을 다시 받을 수 있지만 자동이 아니다.
- 변경분 연동은 마지막 성공 날짜를 저장해 **그 다음 날부터 오늘까지** 받는 방식으로 바꾼다.
- 주간 전체 대사(재직자 목록 vs 활성 계정)를 안전망으로 둔다.
