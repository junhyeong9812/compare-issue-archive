# issue/amlscan/rule-window-unit — 정리 (힌트)

태그: `contract-drift` · `silent-failure`

## 전체 흐름

```
룰 정의 window: 60      (단위 생략)
  amlscan 룰 엔진 기본 단위 = 초  → 60초 안에 5회
  작성자 의도               = 60분

실제 분할송금 패턴: 3~10분 간격 → 60초 창에는 1~2건 → 경보 0

리플레이 시험 데이터: 공격 시나리오를 초 단위로 압축해 만든 합성 데이터 → 경보 발생
명시 표기: window: 60m  /  window: 3600s
```

## 핵심 문장

- 룰 엔진의 `window` 기본 단위는 **초**다 — 숫자만 쓰면 60초다.
- 시험 데이터가 시간을 압축한 합성 시나리오라 단위 오류를 가렸다.
- 단위는 `60m`처럼 항상 붙인다 — 엔진은 단위 없는 값을 경고 없이 받는다.
- 새 룰은 운영 데이터 지난 30일 리플레이에서 기대 경보 수 범위를 정해 두고 확인한다.
