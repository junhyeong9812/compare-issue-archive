# issue/feecalc/preferential-rate-rep-merchant-only — 정리 (힌트)

태그: `data-meaning` · `partial-update`

## 전체 흐름

```
우대 수수료 대상 파일 (카드사 협회): 사업자번호 → 등급
feecalc rate apply  키: 사업자번호 → merchants.findOne(bizno)   ← 첫 행만
      │  다점포 사업자: 가맹점 여러 개 중 대표(최소 id) 하나만 갱신
      ▼
지점 가맹점: 이전 등급 요율 유지 → 수수료 과다 청구
```

## 핵심 문장

- 우대 수수료는 **사업자 단위**로 정해지지만 요율은 **가맹점 단위**로 저장된다.
- 갱신 코드가 사업자번호로 가맹점 **하나만** 찾았다 — 다점포 사업자의 지점이 빠졌다.
- 단일 점포 사업자는 정상이라 "일부만"이었다.
- 교정: 사업자번호의 모든 가맹점 갱신 + 갱신 건수와 대상 가맹점 수 대조.
