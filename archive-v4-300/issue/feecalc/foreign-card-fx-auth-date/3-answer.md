# issue/feecalc/foreign-card-fx-auth-date — 정답

태그: `data-meaning` · `fx`

## 정답
<!-- 질문 1:1 대응 -->

1. **승인일과 매입일 사이 환율 변동에 따라서다.**

2. **차이가 없다.** 그래서 국내 매입이 빠른 카드사는 차이가 작았다.

3. **누락·중복이 아니라 기준값 차이다.** 누락이면 한쪽 방향으로만 쌓인다.

## 문제 구조 (추상화 코드)

① 문제 코드
```java
BigDecimal krw = feeUsd.multiply(fx.rate(txn.authDate()));
```
② 고친 코드
```java
BigDecimal krw = feeUsd.multiply(fx.rate(acq.purchaseDate()));   // 매입 확정 후
```
무엇이 깨졌나: 계약상 기준일과 구현 기준일이 달랐다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| 매입일 기준 확정 계산 | 작음 | 확정 지연 | 기본 |
| 차이를 월말 조정 | 반복 | 원인 잔존 | 선택하지 않음 |

**결론**: 환산 기준일은 계약서 값을 따른다.
