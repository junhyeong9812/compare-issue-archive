# issue/feecalc/foreign-card-fx-auth-date — 정리 (힌트)

태그: `data-meaning` · `fx`

## 전체 흐름

```
해외카드 승인 (USD) 1/10 → 매입 1/12
feecalc: 수수료(USD) × 1/10 환율
카드사 청구: 수수료(USD) × 1/12 환율 (매입일 기준)
      ▼
환율 변동만큼 건별 차이 → 월 합계 소액 차이, 방향은 환율 추세 따라
```

## 핵심 문장

- 같은 금액이라도 **환산 기준일**이 다르면 다른 원화가 된다.
- 카드사 계약서에는 매입일 기준이 적혀 있었다 — 구현이 승인일을 썼다.
- 차이 방향이 매달 바뀌어 "오차"로 넘겨 왔다.
- 교정: 매입 파일 수신 후 매입일 환율로 확정 계산, 승인 시점 값은 추정치로만 표시.
