# issue/recoeng/model-rollout-cache-key-no-version — 정리 (힌트)

태그: `cache` · `deployment` · `data-integrity`

## 전체 흐름

```
캐시 키 = reco:{고객ID}:{영역}       ← 모델 버전·테스트 군 없음, 6시간 유지
B군 요청 → 캐시에 옛 모델 결과 있으면 그대로 반환
A군 요청 → 다른 경로(공유 영역)에서 B군이 채운 새 모델 결과를 반환하기도
6시간 뒤 대부분 만료 → 혼재 감소
```

## 핵심 문장

- 원인은 **캐시 키에 모델 버전·테스트 군이 없는 것** — 어떤 모델이 만든 결과든 같은 키를 썼다.
- 결과적으로 **양쪽 군에 상대 모델 결과**가 섞여 첫 6시간의 비교 지표가 오염됐다.
- 캐시 유지 시간(6시간)만큼 혼재가 이어졌다.
- 대처는 캐시 키에 모델 버전·테스트 군 포함, 배포 시 해당 영역 캐시 무효화, 오염 구간 지표 제외.
