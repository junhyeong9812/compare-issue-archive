# issue/recoeng/out-of-stock-filter-daily-batch — 정리 (힌트)

태그: `data-freshness` · `ux` · `conversion`

## 전체 흐름

```
품절 제외 목록: 매일 04:00 재고 스냅샷으로 생성 → 추천 결과에서 제외
14:00 타임세일 품절 → 재고 서비스 즉시 반영 → 상세·검색: 품절 표시
추천: 다음 날 04:00 까지 계속 노출 → 클릭 → 품절 페이지
```

## 핵심 문장

- 원인은 **품절 제외 목록이 하루 한 번**만 갱신된 것 — 장중 품절은 다음 날 새벽에야 반영됐다.
- 상세·검색은 재고 서비스를 **실시간 조회**하지만 추천은 **스냅샷**을 썼다.
- 평소에는 장중 품절이 드물어 체감이 없었고 **타임세일**에서 드러났다.
- 대처는 재고 품절 이벤트를 구독해 제외 목록 즉시 갱신, 추천 응답 직전 재고 여부 일괄 조회.
