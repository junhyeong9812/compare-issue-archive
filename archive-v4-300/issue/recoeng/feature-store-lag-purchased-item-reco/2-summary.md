# issue/recoeng/feature-store-lag-purchased-item-reco — 정리 (힌트)

태그: `data-freshness` · `pipeline` · `silent-failure`

## 전체 흐름

```
매일 03:00 구매 이력 피처 적재 → 피처 스토어
11/11~  원천 테이블 파티션 경로 변경 → 적재 작업 "입력 없음" → 성공 종료 (0건 적재)
추천: 피처 스토어 마지막 값(11/10) 사용 → 최근 구매 제외 실패
신규 고객: 구매 이력 없음 → 인기 상품 추천 → 영향 없음
```

## 핵심 문장

- 원인은 **원천 파티션 경로 변경 후 적재 작업이 0건을 적재하고 성공으로 끝난 것**이다.
- 추천은 피처 스토어의 **마지막 값**을 그대로 써 사흘 전 구매 이력 기준이었다.
- "입력 0건"을 성공으로 처리해 **적재 실패가 무음**이었다.
- 대처는 적재 건수 하한 검사(전일 대비 50% 미만이면 실패), 피처 나이 경보, 추천 시 최근 주문을 실시간 제외.
