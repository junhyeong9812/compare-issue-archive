# issue/otpsvc/lock-counter-per-node — 정리 (힌트)

태그: `security` · `distributed-state`

## 전체 흐름

```
LB 라운드로빈 → 노드 A B C D 각자 실패 카운터
노드당 5회 → 잠금은 그 노드에서만 → 실효 한도 최대 20회
노드 재시작 → 카운터 0
교정: 공유 저장소(캐시) 카운터 · 키 = 인증 요청 ID + 사용자
```

## 핵심 문장

- 실패 횟수가 **노드 메모리**에 있어 잠금이 노드별로 따로 걸린다 — 실효 한도는 노드 수 × 5.
- 재시작하면 카운터가 사라진다.
- 6자리 번호 기준 시도 20회는 5회 대비 성공 확률을 4배로 만든다.
- 카운터는 **공유 저장소**에 두고, 키는 인증 요청 단위로 한다.
