# issue/otpsvc/totp-replay-retry-fail — 정리 (힌트)

태그: `idempotency` · `security`

## 전체 흐름

```
앱 ──POST /mfa {code:402913, req_id:R1}──▶ otpsvc: 검증 OK, 사용 기록(창 T)
   ◀── 200 (유실)
앱 자동 재시도 ──같은 요청──▶ otpsvc: 창 T 코드 이미 사용 → 401 "invalid code"
사용자: '틀렸다' → 30초 뒤 새 코드 → 성공

교정: 같은 req_id 재시도 → 첫 결과(세션) 그대로 반환
```

## 핵심 문장

- TOTP 서버는 **같은 시간 창의 코드를 한 번만** 받는다(재사용 거부 — 가로챈 코드 재사용 방지).
- 앱의 자동 재시도는 **이미 성공한 요청**을 다시 보내 401을 받았다.
- 오류 메시지가 '잘못된 코드'라 사용자는 입력 실수로 여겼다.
- 요청 ID로 **같은 요청의 재시도는 첫 결과를 재사용**하게 한다 — 재사용 거부는 다른 요청에만 적용.
