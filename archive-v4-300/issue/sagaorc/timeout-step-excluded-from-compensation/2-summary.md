# issue/sagaorc/timeout-step-excluded-from-compensation — 정리 (힌트)

태그: `compensation` · `partial-failure`

## 전체 흐름

```
주문 사가: ① 재고 예약 → ② 쿠폰 차감 → ③ 결제
② 쿠폰 서비스 응답 3초 타임아웃 (실제로는 3.4초에 차감 완료)
③ 결제 실패 → 보상 시작: "완료된 단계만 역순 보상" → ① 재고 해제만
② 는 상태 TIMEOUT → 보상 대상 아님 → 쿠폰은 사용됨으로 남음
```

## 핵심 문장

- 시간 초과는 **실패가 아니라 "모름"** 이다 — 상대 쪽에서 처리됐을 수 있다.
- `sagaorc`는 보상 대상을 상태 COMPLETED인 단계로만 골랐다.
- 쿠폰 서비스가 느렸던 행사 기간에 약 1,900건이 이렇게 남았다.
- 대처: TIMEOUT 단계도 보상에 포함(보상은 멱등 — 차감 기록이 없으면 아무것도 안 함), 보상 전에 상대 상태를 조회.
