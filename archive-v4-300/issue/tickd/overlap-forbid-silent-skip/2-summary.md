# issue/tickd/overlap-forbid-silent-skip — 정리 (힌트)

태그: `silent-failure` · `scheduling`

## 전체 흐름

```
job hourly-sales (매시 정각, overlap=FORBID)
  10:00 실행 → 블랙프라이데이 트래픽으로 74분 소요
  11:00 회차: 10:00 실행 중 → SKIPPED (DEBUG 로그만)
  12:00 회차: 정상 실행 — 집계 구간은 11:00~12:00 만
10:00 실행 = 09~10시 구간 / 11:00 회차(10~11시 구간) 건너뜀 → 10~11시 구간이 빈다
```

## 핵심 문장

- `overlap=FORBID`는 앞 실행이 진행 중이면 이번 회차를 **실행하지 않고 넘어간다** — 대기하거나 뒤에 붙이지 않는다.
- 각 회차가 "직전 한 시간" 구간을 집계하므로, 건너뛴 회차의 구간은 **영영 집계되지 않는다**.
- 건너뜀은 DEBUG 로그로만 남고 실행 이력 화면에 표시되지 않았다.
- 대처: 회차가 처리할 구간을 "마지막 성공 구간 끝 ~ 지금"으로 바꿔 건너뛰어도 다음 회차가 메우게 하고, SKIPPED를 경보로 올렸다.
