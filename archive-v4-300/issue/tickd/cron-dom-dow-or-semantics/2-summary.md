# issue/tickd/cron-dom-dow-or-semantics — 정리 (힌트)

태그: `config` · `semantics`

## 전체 흐름

```
의도: "매월 1~7일 중 월요일" (첫째 주 월요일)
식:   0 0 9 1-7 * MON
tickd(표준 cron 해석): 일(1-7) OR 요일(MON) → 매월 1~7일 매일 + 모든 월요일
```

## 핵심 문장

- 표준 cron은 **일과 요일이 둘 다 `*`가 아니면 OR**로 해석한다 — AND가 아니다.
- 그래서 첫째 주 월요일이 아니라 "1~7일 매일 + 매주 월요일"이 됐다.
- 대처: 식은 `0 0 9 * * MON`으로 두고, 코드에서 `dayOfMonth <= 7`을 확인해 아니면 종료. 또는 `MON#1` 확장 문법을 지원하는 표현 사용.
