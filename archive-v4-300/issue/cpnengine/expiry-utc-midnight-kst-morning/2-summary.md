# issue/cpnengine/expiry-utc-midnight-kst-morning — 정리 (힌트)

태그: `timezone` · `data-semantics` · `cs`

## 전체 흐름

```
운영자 입력 "만료일 2023-11-30" → 저장 "2023-11-30T23:59:59" (시간대 없음)
이전 전 DB: 세션 시간대 Asia/Seoul → 한국 23:59:59 로 해석
이전 후 DB: 세션 시간대 UTC → 관리자 API 가 "만료일 00:00 UTC + 1일" 로 변환 → 한국 11/30 09:00
목록 화면: 날짜 부분만 표시 → "11/30까지" 정상처럼 보임
```

## 핵심 문장

- 원인은 만료 시각을 **UTC 기준 자정(다음 날 00:00 UTC)** 으로 저장한 것 — 한국 시각 만료일 오전 9시다.
- DB 이전 때 **세션 시간대 기본값이 UTC로 바뀌며** 관리자 API의 날짜 변환이 달라졌다.
- 목록 화면은 **날짜만** 보여 줘 시각 차이를 숨겼다.
- 대처는 만료 시각을 시간대 포함으로 저장(한국 시각 23:59:59+09:00), 경계 시각 테스트, 오전 사용 불가 고객 쿠폰 재발급.
