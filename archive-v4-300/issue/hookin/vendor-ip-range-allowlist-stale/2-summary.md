# issue/hookin/vendor-ip-range-allowlist-stale — 정리 (힌트)

태그: `infra` · `allowlist`

## 전체 흐름

```
PG 공지(6주 전): 7/11부터 발신 대역 203.0.113.0/24 추가
공지 메일 수신자: 퇴직한 담당자 개인 메일
7/11 PG가 새 대역에서 통지 일부(약 30%) 발신 → 경계 방화벽 403
PG: 403 은 재전송 대상 → 6시간 재시도 후 포기
```

## 핵심 문장

- 외부 시스템 허용 목록은 **상대의 변경 공지**에 묶인다 — 공지를 받는 경로가 끊기면 반드시 깨진다.
- PG는 403을 받고 재전송했지만 6시간 뒤 포기했다 — 그 뒤 건은 수기 대사로 복구.
- 대처: 공지 수신을 공용 메일·티켓으로, 허용 목록에 상대가 제공하는 IP 목록 API를 주기 동기화, 403 비율 경보.
