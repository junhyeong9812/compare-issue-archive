# issue/hookin/reserialized-body-hmac-mismatch — 정리 (힌트)

태그: `auth` · `encoding`

## 전체 흐름

```
PG 원문:   {"amount":15000,"memo":"테스트\/환불","ts":1712020000}
프레임워크: 본문을 객체로 파싱 → 검증 필터가 객체를 다시 JSON 직렬화
재직렬화:  {"amount":15000,"memo":"테스트/환불","ts":1712020000}   (이스케이프·순서·공백 차이)
HMAC(재직렬화) ≠ 서명 → 401
```

## 핵심 문장

- 서명은 **전송된 바이트 그대로**에 대해 계산된다 — 의미가 같은 JSON이라도 바이트가 다르면 다른 서명이다.
- 이스케이프된 `\/`, 유니코드 이스케이프, 숫자 표기가 있는 통지에서만 실패해 "간헐적"이었다.
- 대처: 검증 필터가 원문 바이트를 캐시해 HMAC 계산, 비교는 상수 시간 비교.
