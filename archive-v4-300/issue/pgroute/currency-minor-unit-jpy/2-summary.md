# issue/pgroute/currency-minor-unit-jpy — 정리 (힌트)

태그: `data-meaning` · `contract-drift`

## 전체 흐름

```
주문: 1,200 JPY
pgroute → 해외 PG 전문 amount = 1200 × 100 = 120000   ← 모든 통화 소수 2자리 가정
      │
해외 PG: JPY 는 소수 0자리 → 120,000 JPY 로 해석
      ├─ 한도 초과 카드: 승인 거절
      └─ 승인된 건: 100배 승인 → 즉시 자동취소 후 재승인 (수동)
```

## 핵심 문장

- ISO 4217 통화마다 **소수 자리수(minor unit)가 다르다** — USD 2, JPY 0, KWD 3.
- `pgroute`는 2025-03 해외 PG 추가 때 USD·EUR만 시험했다 — 둘 다 2자리라 버그가 안 보였다.
- 금액 변환은 통화 표에서 자리수를 읽어 한다 — 상수 100 금지.
- 대사는 통화별로 나눠 본다 — 원화 환산 총액만 보면 통화 하나의 큰 오차가 다른 통화에 묻힌다.
