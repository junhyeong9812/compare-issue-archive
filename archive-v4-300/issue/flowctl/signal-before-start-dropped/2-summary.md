# issue/flowctl/signal-before-start-dropped — 정리 (힌트)

태그: `race` · `silent-failure`

## 전체 흐름

```
앱: 계좌개설 요청 → API 가 워크플로 시작 요청을 큐에 넣음(비동기)
고객: 인증 화면에서 빠르게 인증 완료 → 인증 서비스가 signal("verified") 전송
   이 시점 워크플로 미시작 → WorkflowNotFound → 인증 서비스가 경고 로그 후 무시
워크플로 시작 → 신호 대기(24시간) → 타임아웃 → '인증 대기 만료'
```

## 핵심 문장

- 신호는 **실행 중인 워크플로에만** 전달된다 — 시작 전 신호는 대상 없음 오류다.
- 시작 요청이 큐를 거쳐 비동기로 처리돼, 인증이 빠른 고객(약 1.8%)이 시작보다 먼저 신호를 보냈다.
- 인증 서비스는 실패를 경고 로그로만 남기고 재시도하지 않았다.
- 대처: 신호를 `signalWithStart`로 보내 없으면 시작하면서 신호 전달. 인증 결과는 워크플로가 시작 시 조회도 하도록 이중화.
