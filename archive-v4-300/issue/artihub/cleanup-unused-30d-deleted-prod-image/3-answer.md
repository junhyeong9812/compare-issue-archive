# issue/artihub/cleanup-unused-30d-deleted-prod-image — 정답

태그: `deploy` · `retention`

## 정답
<!-- 질문 1:1 대응 -->

1. **404로 기동 실패한다.**

2. **노드 로컬 캐시 덕에 넉 달간 레지스트리를 안 거쳤다.**

3. **같이 지워졌다.** 소스 태그로 다시 빌드해 올렸다(재현 빌드 확인 포함).

4. **클러스터 실행 이미지 + 각 서비스 최근 3개 릴리스는 보존.** 정리는 그 밖에서만.

## 문제 구조 (추상화 코드)

### 변형 A — 다운로드 기록만으로 미사용 판정
① 문제 코드
```yaml
cleanup:
  - match: "*"
    delete_if: { not_downloaded_days: 30 }
```
② 고친 코드
```yaml
cleanup:
  - match: "*"
    keep: { running_in_clusters: [prod, stage], latest_releases: 3 }
    delete_if: { not_downloaded_days: 30 }
```
무엇이 깨졌나: 사용 여부를 레지스트리 관점에서만 봤다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 실행 이미지 보존 | 클러스터 조회 연동 | 중간 | 연동 실패 시 과삭제 | 기본 |
| 릴리스 태그 영구 보존 | 저장 용량 | 중간 | 비용 | 함께 |
