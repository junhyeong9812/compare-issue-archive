# issue/billkey/card-reissue-billing-key-invalid — 정리 (힌트)

태그: `external-dependency` · `lifecycle`

## 전체 흐름

```
회원 카드 유효기간 만료 → 카드사 재발급 (번호 같거나 다름)
빌링키 → 옛 카드 정보 → 승인 거절 (유효기간 경과)
PG 자동 갱신(Account Updater) 미가입 → 갱신 정보 미반영
      ▼
billkey charge 실패 → 회원 안내 없이 재시도 3회 후 해지 대기
```

## 핵심 문장

- 빌링키는 **발급 당시 카드 정보**에 묶인다 — 재발급 카드에는 자동으로 따라가지 않는다.
- PG의 카드 자동 갱신 서비스는 **별도 신청**이었고 계약 때 빠졌다.
- 유효기간이 몰린 1~2월 발급 코호트에서 실패가 늘었다.
- 교정: 자동 갱신 가입, 실패 사유가 '유효기간'이면 즉시 회원에게 카드 재등록 안내.
