# issue/ptsctl/vendor-outage-window-batch-no-retry — 정리 (힌트)

태그: `vendor-notice` · `partial-failure` · `retry`

## 전체 흐름

```
2/25 18:00  벤더 공지: 2/26 02:30~03:10 긴급 DB 작업, API 오류 가능
            수신: 제휴팀 메일 → 배치 담당 전달 안 됨
2/26 02:00  이관 배치 시작
     02:30 ~ 03:10  ptsctl 요청 실패 (벤더 503) → 배치: 실패 로그 남기고 다음 회원
     04:30  배치 종료 "완료 (실패 11,204)"
2/27 회원 문의 → 실패 목록 재처리
```

## 핵심 문장

- 원인은 **벤더 긴급 작업 시간대의 요청 실패** — 배치는 실패 건을 로그만 남기고 재시도하지 않았다.
- 누락 회원은 **요청 시각이 한 구간(02:30~03:10)에 몰린다** — 회원 속성이 아니라 시간으로 갈린다.
- 배치 결과 요약에 "실패 11,204"가 찍혔지만 **종료 상태는 성공**이라 아무도 보지 않았다.
- 대처는 실패 건 자동 재시도 큐, 실패가 1건이라도 있으면 배치 종료 상태 경고, 벤더 공지 수신자에 배치 담당 추가.
