# issue/sanctlist/version-string-compare — 정답

태그: `silent-failure` · `data-semantics`

## 정답
<!-- 질문 1:1 대응 -->

1. **적재를 건너뛴다.** 문자열로는 `"2024.10" < "2024.9"`다.

2. **1~9월은 월이 한 자리라 사전순과 숫자순이 같았다.**

3. **적재된다.** 연도 부분이 커서 사전순으로도 크다. 연말까지 석 달간 갱신이 멈출 뻔했다.

4. **'새 버전 아님'은 정상 분기라 성공으로 끝났다.** 10월 2일~16일 신규 제재 대상 14명이 고객 대조에서 빠졌고, 감독기관 공지 대조에서 발견됐다.

5. **버전을 `(연, 월)` 숫자 튜플로 비교하고, 적재 후 현재 버전이 받은 파일 버전과 다르면 경보.** 신규 명단 파일을 받았는데 적재하지 않은 날이 이틀 이어지면 경보.

## 문제 구조 (추상화 코드)

### 변형 A — 문자열 버전 비교
① 문제 코드
```python
if new_ver > current_ver:          # 둘 다 str
    load(file)
```
② 고친 코드
```python
def v(s): return tuple(int(x) for x in s.split("."))
if v(new_ver) > v(current_ver):
    load(file)
if v(current_version()) != v(new_ver):
    alert("sanctlist not at latest", new_ver)
```
무엇이 깨졌나: 구조가 있는 값(연.월)을 문자열로 다뤄, 자릿수가 바뀌는 순간 순서가 뒤집혔다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 숫자 튜플 비교 | 코드 수정 | 작음 | 형식 바뀌면 예외 | 기본 |
| 적재 후 버전 확인 경보 | 조회 | 작음 | 없음 | 함께 |
| 항상 최신 파일 무조건 적재 | 멱등 적재 | 중간 | 구 파일 재적재 | 보조 |

**결론**: 버전은 숫자로 비교하고, 적재 결과를 받은 파일과 대조한다.
