# issue/sanctlist/nfd-name-unmatched — 정리 (힌트)

태그: `encoding` · `silent-failure`

## 전체 흐름

```
명단 파일 '홍길동' NFD: ᄒ ᅩ ᆼ ᄀ ᅵ ᆯ ᄃ ᅩ ᆼ (9 코드포인트)
고객 DB  '홍길동' NFC: 홍 길 동 (3 코드포인트)
화면상 동일 / 바이트 다름 → 완전일치 실패 → 미탐

2025-07 명단 담당 기관이 작성 도구를 macOS 로 교체 → NFD 저장
교정: 적재 시 NFC 정규화 · 고객 이름도 저장 시 NFC
```

## 핵심 문장

- 명단 파일의 한글이 **NFD(자모 분리)**로 바뀌어 NFC 고객 이름과 바이트가 달랐다.
- 화면에는 똑같이 보여 육안 검수로 못 잡는다.
- 영문 명단은 정규화 형태가 같아 영향이 없었다.
- 적재 시점과 고객 저장 시점 **양쪽에서 NFC 정규화**한다.
