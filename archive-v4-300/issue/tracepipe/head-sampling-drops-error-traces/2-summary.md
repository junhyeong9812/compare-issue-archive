# issue/tracepipe/head-sampling-drops-error-traces — 정리 (힌트)

태그: `observability` · `sampling`

## 전체 흐름

```
게이트웨이: 요청 시작 → 1% sampled 결정 (traceparent flags)
하위: 결정 따름
오류 1000건 → 약 10건만 기록
```

## 핵심 문장

- 헤드 샘플링은 **요청 시작 시점**에 결정해 결과(오류·지연)를 모른다.
- 하위만 100%로 바꾸면 상위 스팬이 없는 **조각난 트레이스**가 된다.
- **테일 샘플링**은 수집기가 트레이스를 모은 뒤 오류·지연 기준으로 남긴다.
- 테일 샘플링은 수집기 메모리와 같은 트레이스를 한 수집기로 모으는 라우팅이 필요하다.
