## 전체 흐름

```
8/27 야간: 2센터 로케이션 코드 A-01-03 → 2C-A01-L3 (WMS 마스터 갱신)
피킹 리스트 생성: wmsbridge 가 매일 07:00 로케이션 캐시 적재 → 8/27 18:00 캐시 사용
8/28 오전: 리스트에 옛 코드 → 피커가 새 표지판에서 위치 못 찾음
1센터: 개편 없음
```

## 핵심 문장

- 원인은 피킹 리스트가 **개편 전 로케이션 캐시**로 생성된 것 — 캐시는 매일 07:00 적재였다.
- 개편 일정이 **캐시 갱신 시각과 맞물리지 않아** 첫날 오전 리스트가 옛 코드였다.
- 1센터는 개편이 없어 정상이었다.
- 대처는 마스터 변경 시 캐시 즉시 무효화, 개편 첫날 리스트 샘플 사전 확인, 옛→새 코드 대조표 현장 비치.
