# issue/wmsbridge/wave-cutoff-queue-lag-next-day-ship — 정리 (힌트)

태그: `latency` · `cutoff` · `integration`

## 전체 흐름

```
주문 → wmsbridge 큐 → WMS 수신 → 웨이브 배정 (WMS 수신 시각 < 14:00 이면 당일)
12/16 13:40~  연말 주문 폭증 + 상품 정보 동기화 작업이 같은 큐 사용 → 지연 6~9분
13:50 ~ 14:00 주문: WMS 수신 14:00 이후 → 다음 날 웨이브
고객 화면: 주문 시각 기준 "오늘 출발"
```

## 핵심 문장

- 원인은 웨이브 마감 판정이 **WMS 수신 시각** 기준인데, 연동 큐가 **6~9분 밀린** 것이다.
- 그날 **상품 정보 동기화 작업이 같은 큐**를 써 주문 메시지가 뒤로 밀렸다.
- 고객 화면은 **주문 시각** 기준으로 약속해 두 시스템의 기준이 달랐다.
- 대처는 주문 전용 큐 분리, 마감 판정을 주문 시각으로(WMS에 주문 시각 전달), 마감 10분 전 큐 지연 경보.
