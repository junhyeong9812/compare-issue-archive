# issue/wmsbridge/asn-case-unit-inventory-understated — 정리 (힌트)

태그: `data-semantics` · `unit` · `reconciliation`

## 전체 흐름

```
ASN:  qty 300, unit CS (박스)          ← 신규 공급사
      qty 7200, unit EA (낱개)         ← 기존 공급사들
wmsbridge: unit 필드를 읽지 않고 qty 를 낱개로 적재
신규 공급사 → 판매 가능 300 EA (실물 7,200 EA)
9/03 300개 판매 → 품절 표시 → 창고에는 6,900개 남음
월말 재고 실사: 시스템 0 / 실물 6,900 → 대사 차이
```

## 핵심 문장

- 원인은 연동이 ASN의 **수량 단위 필드를 무시**한 것 — 신규 공급사는 박스 단위로 보냈다.
- 기존 공급사는 모두 **낱개 단위**라 같은 연동으로 문제가 없었다.
- 실물 검수는 **박스 수**를 세어 ASN 수량(300)과 일치해 통과했다.
- 대처는 단위 필드 필수 해석(포장 규격 마스터로 환산), 신규 공급사 첫 입고 샘플 대사, 입고 직후 품절 경보.
