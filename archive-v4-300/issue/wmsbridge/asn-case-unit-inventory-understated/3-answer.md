# issue/wmsbridge/asn-case-unit-inventory-understated — 정답

태그: `data-semantics` · `unit` · `reconciliation`

## 정답
<!-- 질문 1:1 대응 -->

1. **7,200개.**\
300박스 × 24개다. 시스템은 300을 낱개로 적재했다.

2. **기존 공급사는 낱개(EA) 단위로 보냈다.**\
연동 개발 당시 단위 필드는 항상 EA라 읽지 않았다.

3. **검수자는 박스 수를 세었고 ASN 수량 300과 맞았다.**

4. **입고 다음 날 품절 표시를 본 MD가 "방금 들어온 상품이 왜 품절이냐"고 문의했다.**\
창고에서 실물을 확인해 차이가 드러났다.

5. **단위 필드 해석(모르는 단위는 적재 거부), 신규 공급사 첫 입고 낱개 샘플 대사, 입고 24시간 내 품절 경보.**\
재고는 실사로 보정했다.

## 문제 구조 (추상화 코드)

### 변형 A — 단위 필드 무시
① 문제 코드
```java
inventory.add(asn.sku(), asn.qty());
```
② 고친 코드
```java
int eaPerUnit = packSpec.eaPer(asn.sku(), asn.unit());   // CS → 24, 모르면 예외
inventory.add(asn.sku(), asn.qty() * eaPerUnit);
```
무엇이 깨졌나: 수량을 단위 없이 숫자로만 다뤄 "항상 EA"라는 과거 관찰이 계약처럼 굳었다.
