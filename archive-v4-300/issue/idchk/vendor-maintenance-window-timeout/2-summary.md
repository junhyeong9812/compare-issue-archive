# issue/idchk/vendor-maintenance-window-timeout — 정리 (힌트)

태그: `vendor-notice` · `timeout` · `scheduling`

## 전체 흐름

```
01:00 배치 시작 (가맹점 약 3,200곳, 순차 요청)
02:00 ~ 04:00  벤더 점검 → 연결 타임아웃 (30초) → 래퍼: 1회 시도 후 "미완료" 기록
04:00 이후     정상
결과: 미완료 611곳 — 요청 시각이 전부 01:58 ~ 04:03
배치 일정: 2023-07 "트래픽 적은 일요일 새벽"으로 이동 (점검 일정 확인 없이)
```

## 핵심 문장

- 원인은 **벤더 정기 점검 시간과 배치 일정이 겹친 것** — 점검 중 요청은 타임아웃으로 끝났다.
- 미완료 건은 **요청 시각이 한 구간에 몰린다** — 가맹점 속성이 아니라 시간으로 갈린다.
- 래퍼는 타임아웃을 재시도하지 않고 "미완료"로 확정했다 — 일시 장애와 판정 결과를 구분하지 않았다.
- 대처는 배치를 점검 창 밖(토요일 22:00)으로 이동, 타임아웃 건은 30분 뒤 자동 재시도, 벤더 점검 일정을 팀 캘린더에 구독.
