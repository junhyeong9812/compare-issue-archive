# issue/idchk/daily-cap-overage-billing-spike — 정리 (힌트)

태그: `cost` · `resource-bounding` · `observability`

## 전체 흐름

```
5/01 ~ 5/14  가입 이벤트 (가입 1.8배)
  앱 가입 화면: 본인확인 결과 화면에서 뒤로 가기 → 재요청 (중복 호출)
  하루 호출 = 기본 건수의 2.3배 → 초과분은 기본 단가의 2.5배
청구 = 기본 고정 + 초과 건수 × 2.5배 단가  →  평소의 4.1배
사용량 확인: 벤더 포털 일별 사용량 (매일 보는 사람 없음)
```

## 핵심 문장

- 비용을 키운 것은 가입자 증가보다 **초과 단가**다 — 일 기본 건수를 넘는 순간 단가가 2.5배가 된다.
- 앱이 결과 화면에서 뒤로 가면 **본인확인을 다시 요청**해 한 회원당 평균 1.4회 호출됐다.
- 초과는 **일 단위**로 계산된다 — 월 합계가 기본 건수 × 일수 안이어도 특정 일 초과분은 과금된다.
- 대처는 회원별 확인 결과 15분 재사용, 일 사용량 80% 경보, 이벤트 기획 단계에 외부 API 비용 검토 항목 추가.
