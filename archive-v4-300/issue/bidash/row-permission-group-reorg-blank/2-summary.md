# issue/bidash/row-permission-group-reorg-blank — 정리 (힌트)

태그: `permission` · `operations` · `ux`

## 전체 흐름

```
행 수준 권한: 사용자 조직 그룹 → 허용 카테고리 목록 매핑
7/01 조직 개편: 인사 시스템 → 사용자 조직 그룹 "리빙카테고리팀" (신규)
bidash 매핑표: 신규 그룹 없음 → 허용 카테고리 = 빈 집합 → 모든 행 필터 → 빈 표
기존 팀: 매핑 존재 → 정상
```

## 핵심 문장

- 원인은 **신설 조직 그룹의 권한 매핑이 없어** 허용 범위가 빈 집합이 된 것이다.
- 행 수준 권한은 **허용되지 않은 행을 조용히 걸러** 오류 대신 빈 화면이 된다.
- 조직 개편 절차에 **BI 권한 매핑 갱신**이 없었다.
- 대처는 매핑 없는 그룹 사용자에게 "권한 없음" 안내 표시, 인사 조직 변경 이벤트로 매핑 누락 경보, 개편 체크리스트 추가.
