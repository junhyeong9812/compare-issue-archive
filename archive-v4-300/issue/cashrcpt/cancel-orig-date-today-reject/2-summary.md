# issue/cashrcpt/cancel-orig-date-today-reject — 정리 (힌트)

태그: `contract-drift` · `async-status`

## 전체 흐름

```
발급 11/02 승인번호 C1
환불 11/20 → cashrcpt cancel --orig C1 --orig-date 20241120   ← 오늘 날짜
      │  대행사 접수 OK, 국세청 전송 시 "원거래 없음" 반려
      ▼
반려 결과는 익일 결과 조회에만 → 사내는 접수로 취소 완료 처리
```

## 핵심 문장

- 취소 전문은 **원승인번호 + 원승인일자** 쌍으로 원거래를 찾는다 — 날짜가 틀리면 원거래가 없다.
- 같은 날 발급·취소한 건은 오늘 날짜가 곧 원승인일자라 정상이었다 — 다른 날 취소만 반려됐다.
- 대행사 접수 응답은 성공이고, 반려는 익일 결과 조회에만 나왔다.
- 교정: 원승인일자를 발급 기록에서 읽고, 익일 결과로 완료 판정.
