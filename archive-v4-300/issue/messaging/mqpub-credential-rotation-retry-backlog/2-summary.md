# issue/messaging/mqpub-credential-rotation-retry-backlog — 정리 (힌트)

태그: `credential` · `latency` · `silent-failure`

## 전체 흐름

```
09:00  브로커 운영사 정기 비밀번호 교체 (계정 settle-pub)
       비밀 저장소 갱신: 주문 발행 서버만 반영, 정산 발행 서버는 배포 대기열에 걸림
09:05~ 정산 래퍼 → mqpub → 인증 실패
       래퍼 정책: 모든 실패를 일시 장애로 보고 백오프 재시도 (1,2,4 … 최대 64분, 무한)
       메시지는 래퍼 로컬 큐에 쌓임 → 경보 없음 (경보는 "큐 > 10,000건" 하나)
13:50  배포 대기열 해소 → 새 비밀번호 적재 → 재시도 성공 → 적체분 일괄 발행
```

## 핵심 문장

- 원인은 **자격증명 교체가 정산 발행 서버에만 늦게 반영**된 것 — 배포 대기열에 걸려 다섯 시간을 놓쳤다.
- 래퍼는 인증 실패도 일시 장애로 보고 **무한 백오프**했다 — 영구 실패와 일시 실패를 구분하지 않았다.
- 적체는 래퍼 로컬 큐에만 있었고 경보 기준(1만 건)에 못 미쳤다 — **지연 시간 기준 경보**가 없었다.
- 누락형과의 차이: 이 사건은 **모든 가맹점이 같은 시간대에 늦게라도 받았다** — 일부만 영영 못 받는 것과 다르다.
