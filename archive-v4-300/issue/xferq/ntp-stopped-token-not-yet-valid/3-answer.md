# issue/xferq/ntp-stopped-token-not-yet-valid — 정답

태그: `environment-drift` · `time` · `credential`

## 정답
<!-- 질문 1:1 대응 -->

1. **토큰의 유효 시작 시각이 벤더 기준으로 미래였다.**\
서버 시계가 7분 빨라 토큰에 미래 시각이 찍혔고, 벤더는 허용 오차 5분을 넘는 미래 토큰을 거부했다.

2. **1월 3일 방화벽 정리에서 UDP 123 아웃바운드가 빠졌다.**\
시간 동기화 데몬은 오류를 로그에만 남겼다.

3. **5분을 넘는 순간부터다.**\
하루 약 1.4분씩 빨라져 4일째 밤에 경계를 넘었다.

4. **다른 작업은 시각이 들어간 서명이나 토큰을 쓰지 않았다.**\
로그 시각이 어긋난 것 외에는 표면 증상이 없었다.

5. **시각 오차 경보(1초 초과), 방화벽 변경 체크리스트에 NTP 포트, 토큰 오류 메시지에 서버·벤더 시각을 함께 기록.**

## 문제 구조 (추상화 코드)

### 변형 A — 시각 오차를 감시하지 않음
① 문제 코드
```sh
# 시간 동기화 데몬 상태만 확인
systemctl is-active chronyd
```
② 고친 코드
```sh
systemctl is-active chronyd
chronyc tracking | awk '/System time/ {if ($4 > 1.0) exit 1}'   # 1초 초과면 경보
```
무엇이 깨졌나: 데몬이 "살아 있음"과 시계가 "맞음"을 같은 것으로 봤다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 시각 오차 경보 | 모니터링 에이전트 | 작음 | 임계 너무 큼 | 기본 |
| 방화벽 변경 체크리스트 | 변경 절차 운영 | 절차 | 체크리스트 미사용 | 기본 |
