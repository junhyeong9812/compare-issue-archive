# issue/xferq/ntp-stopped-token-not-yet-valid — 정리 (힌트)

태그: `environment-drift` · `time` · `credential`

## 전체 흐름

```
1/03  배치 서버 방화벽 정책 정리 → UDP 123 아웃바운드 차단 → 시간 동기화 중단
      시계 하루 약 1.4분씩 빨라짐
1/08  02:00  서버 시각 = 실제 + 7분
      토큰 발급: iat/nbf = 서버 시각(미래)
      벤더 검증: nbf > 벤더 시각 + 허용 오차 5분 → "not yet valid" 거부
다른 작업: 시각 기반 서명 없음 → 영향 없음
```

## 핵심 문장

- 원인은 **배치 서버 시계가 7분 빨라진 것** — 토큰 유효 시작 시각이 미래라 벤더가 거부했다.
- 시간 동기화는 방화벽 정리 때 **UDP 123 아웃바운드가 막혀** 닷새 전에 멈췄다.
- 벤더 허용 오차는 **5분** — 그보다 작은 어긋남은 증상이 없어 닷새 동안 몰랐다.
- 대처는 시간 동기화 포트 복구, **시각 오차 경보(1초 초과)**, 방화벽 변경 체크리스트에 NTP 추가.
