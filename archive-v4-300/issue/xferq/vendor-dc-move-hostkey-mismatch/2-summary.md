# issue/xferq/vendor-dc-move-hostkey-mismatch — 정리 (힌트)

태그: `environment-drift` · `vendor-notice` · `security`

## 전체 흐름

```
2/05  카드사 공지: 2/19 수신 서버 데이터센터 이전, 새 호스트 키 지문 첨부
      수신자: 옛 담당자 메일 (2023-12 퇴사, 메일함 미전달)
2/19  xferq → 카드사 수신 서버 (같은 이름, 새 장비)
      호스트 키 불일치 → 연결 거부 → 배치 래퍼 재시도 (30분 간격)
      경보: "같은 파일 24시간 미전송" 하나 → 매일 새 파일이라 매번 리셋
2/21  카드사 문의 → 새 지문 확인 후 known_hosts 갱신 → 미전송분 재전송
```

## 핵심 문장

- 원인은 카드사 **수신 서버 이전으로 호스트 키가 바뀐 것** — 공지는 퇴사자 메일로 가서 아무도 못 봤다.
- 호스트 키 불일치는 **보안상 연결을 거부하는 것이 정상**이다 — 고칠 곳은 공지 수신 경로와 경보다.
- 경보 기준이 "같은 파일 24시간 미전송"이라 매일 새 파일이 생길 때마다 **카운터가 초기화**됐다.
- 새 지문은 반드시 **공지 원문(별도 경로)과 대조** 후 등록한다 — 키 검사를 끄는 우회는 금지.
