# issue/glsync/new-account-code-unregistered — 정리 (힌트)

태그: `config-drift` · `release-process`

## 전체 흐름

```
신규 결제수단 출시 → 분개 규칙에 계정 1135-07 (선수포인트) 추가
glsync push → ERP: "account not found 1135-07" → 전표 거부 (오류 반환)
      │  재시도 큐 적재, 알림 반복
      ▼
회계팀 계정 등록 → 재시도 큐 처리 → 정상
```

## 핵심 문장

- 이 연동은 거부를 **오류로 반환**했다 — 알림은 바로 울렸다. 문제는 출시 절차에 회계 마스터 등록이 없던 것이다.
- 재시도 큐가 있어 계정 등록 뒤 자동 회복됐다.
- 교정: 분개 규칙 배포 전 ERP 계정 존재 확인을 배포 점검에 넣었다.
