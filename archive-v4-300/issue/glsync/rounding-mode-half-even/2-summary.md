# issue/glsync/rounding-mode-half-even — 정리 (힌트)

태그: `data-meaning` · `rounding`

## 전체 흐름

```
정산: 수수료 = 매출 × 요율  → HALF_UP 원 단위
glsync: 건별 금액이 아니라 (매출, 요율) 을 보냄
ERP: 수수료 재계산 → HALF_EVEN 원 단위
      │  x.5 원 끝수 건만 1원 차이 (짝수 쪽으로)
      ▼
월 합계 37원 차이
```

## 핵심 문장

- 같은 식이라도 **반올림 모드**가 다르면 x.5 끝수에서 결과가 다르다.
- `glsync`가 계산 결과가 아니라 **계산 입력**을 보내 ERP가 다시 계산했다.
- 교정: 금액은 한 곳에서 계산하고 결과를 보낸다 — 받는 쪽은 재계산하지 않는다.
