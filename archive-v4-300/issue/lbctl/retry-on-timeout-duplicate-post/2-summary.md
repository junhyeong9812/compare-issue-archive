# issue/lbctl/retry-on-timeout-duplicate-post — 정리 (힌트)

태그: `duplicate` · `config`

## 전체 흐름

```
클라이언트 POST /payouts ─▶ LB ─▶ 백엔드 A (은행 호출 7초, 진행 중)
                               5초 타임아웃 → 재시도 ─▶ 백엔드 B (은행 호출)
A·B 둘 다 은행 송금 → 중복 지급
```

## 핵심 문장

- LB 재시도는 **첫 요청을 취소하지 않는다** — 첫 백엔드는 계속 처리한다.
- 월말 은행 응답 지연으로 5초를 넘는 요청만 중복됐다.
- 멱등 키가 있으면 두 번째 요청은 거부되거나 같은 결과를 받는다.
- LB 재시도는 **멱등 메서드(GET 등)·연결 실패**에만 두고 POST 타임아웃 재시도는 끈다.
