# issue/lbctl/sticky-session-draining-node — 정리 (힌트)

태그: `deploy` · `session`

## 전체 흐름

```
블루 draining (1h) ← 쿠키 lb=blue 사용자 계속 진입
그린 active        ← 새 사용자
옛 화면 + 새 API 스키마 → 일부 저장 실패
```

## 핵심 문장

- 드레이닝은 **고정된 세션을 계속 받는다** — 신규 연결만 막는다.
- 옛 프런트가 새 API와 섞이면 필드 불일치 오류가 난다.
- 쿠키 만료를 줄이면 로그인 세션이 백엔드 메모리에 있을 때 로그아웃된다.
- 세션을 공유 저장소로 옮기면 고정이 필요 없다.
