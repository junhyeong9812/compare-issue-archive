# issue/cipipe/cache-key-missing-lockfile — 정리 (힌트)

태그: `environment-drift` · `ci`

## 전체 흐름

```
CI 테스트 단계: cache deps-main 복원 → 2.15 존재 → 설치 건너뜀
이미지 빌드:  캐시 없음 → 잠금 파일대로 2.17
금액 10000000 직렬화: CI(2.15) "10000000" / 운영(2.17) "1E+7" → 파트너 E_FORMAT
```

## 핵심 문장

- 캐시 키에 잠금 파일 해시가 없으면 **의존성이 바뀌어도 옛 캐시를 복원**한다.
- 설치 단계가 '이미 있음'으로 건너뛰어 버전 불일치가 보이지 않았다.
- CI와 이미지 빌드가 다른 의존성 해석 경로를 탔다.
- 캐시 키에 `hashFiles(lockfile)`을 넣고, 설치는 잠금 파일 검증 모드로 돈다.
