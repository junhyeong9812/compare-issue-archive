# issue/hookout/fixed-retry-schedule-recovery-flood — 정리 (힌트)

태그: `retry-storm` · `performance`

## 전체 흐름

```
가맹점 장애 2시간 동안 웹훅 18만 건 실패 → 재시도 큐
재시도 간격 고정 10분 → 복구 직후 첫 10분 창에 18만 건 동시 전송
가맹점 처리 한도 초당 200건 → 다시 다운
```

## 핵심 문장

- 고정 간격 재시도는 실패 건들의 재시도 시각을 **같은 창에 모은다**.
- 가맹점 단위 발송 속도 제한이 없었다.
- 대처: 가맹점별 동시 연결·초당 건수 제한, 지수 백오프 + 지터, 연속 실패 시 가맹점 단위 회로 차단(반열림 상태에서 소량 시험).
