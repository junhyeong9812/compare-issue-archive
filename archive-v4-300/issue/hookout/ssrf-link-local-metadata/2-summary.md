# issue/hookout/ssrf-link-local-metadata — 정리 (힌트)

태그: `security` · `ssrf`

## 전체 흐름

```
가맹점 콘솔 → 웹훅 URL 등록: http://169.254.169.254/latest/meta-data/
검증: URL 형식 OK → 저장
테스트 발송 버튼 → hookout 이 호출 → 응답 본문 앞 500자를 콘솔에 "응답 미리보기"로 표시
→ 인스턴스 자격 정보 노출 경로
```

## 핵심 문장

- 웹훅 발송기는 **우리 네트워크 안에서** 가맹점이 지정한 주소로 요청한다 — 내부 주소를 막지 않으면 SSRF다.
- 응답 미리보기 기능이 노출을 키웠다.
- 등록 시점 검사만으로는 부족하다 — DNS가 나중에 내부 IP로 바뀔 수 있다(DNS 재바인딩).
- 대처: 발송 시점에 해석된 IP를 검사(사설·링크로컬·루프백 차단), 응답 미리보기 제거, 발송기를 메타데이터 접근이 막힌 서브넷으로 이동, 메타데이터는 토큰 필수 모드로.
