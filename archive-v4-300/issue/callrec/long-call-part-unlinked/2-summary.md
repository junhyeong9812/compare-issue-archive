# issue/callrec/long-call-part-unlinked — 정리 (힌트)

태그: `data-integrity` · `silent-failure`

## 전체 흐름

```
녹취 장비: 60분마다 분할  C-58812.wav (60분) · C-58812-p2.wav (23분)
callrec 수집: 통화 ID 로 메타 1건 생성 → 파일 경로 = <통화ID>.wav 하나
  -p2 파일 → 저장소에는 업로드, 메타에 연결 안 됨 → 재생 불가·검색 불가
120분 초과 → -p3 도 같은 처지
```

## 핵심 문장

- 녹취 장비는 **60분마다 파일을 나누고** `-p2`, `-p3`를 붙인다.
- callrec 수집은 통화 ID와 같은 이름의 **첫 파일만** 메타데이터에 연결했다.
- 나머지 파일은 저장소에 있지만 **재생·검색에서 안 보인다**.
- 연동은 **파일 목록**을 메타에 넣고, 녹취 길이 합과 통화 길이를 대조한다.
