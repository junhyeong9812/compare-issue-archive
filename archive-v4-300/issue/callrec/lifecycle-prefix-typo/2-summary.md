# issue/callrec/lifecycle-prefix-typo — 정리 (힌트)

태그: `irreversible` · `data-retention`

## 전체 흐름

```
규칙 1: prefix recording/legal/  → 3년 보관   ← 오타, 매칭 0건
규칙 2: (기본)                     → 90일 후 삭제
recordings/legal/* → 규칙 1 불일치 → 규칙 2 → 90일 후 삭제
2025-08-11 이전 + 90일 = 11-09 부터 삭제 시작
버전 관리 꺼짐 → 복구 불가
```

## 핵심 문장

- 접두어 오타로 장기 보관 규칙이 **아무 객체에도 매칭되지 않았다** — 오류가 아니다.
- 법정 보관 녹취(민원·분쟁 대상)가 기본 90일 규칙에 지워졌다.
- 버전 관리가 꺼져 있어 **복구 불가**였다.
- 규칙 변경은 dry-run(대상 객체 수)으로 확인하고, 법정 보관 경로는 객체 잠금(보존 모드)을 건다.
