# issue/callrec/stt-single-channel — 정리 (힌트)

태그: `environment-drift` · `silent-failure`

## 전체 흐름

```
1센터: L=상담원 R=고객   STT(L) → 상담원 발화 색인
2센터: L=고객   R=상담원 STT(L) → 고객 발화만 색인
품질 검색(상담원 고지 문구) → 2센터 거의 0건
교정: 장비별 채널 매핑 메타 · 두 채널 모두 인식 + 화자 표시
```

## 핵심 문장

- STT가 **왼쪽 채널만** 읽고, 2센터 장비는 **상담원을 오른쪽**에 녹음했다.
- 2센터는 고객 발화만 색인돼 **상담원 고지 문구 검색에서 빠졌다**.
- 품질팀은 처음에 '2센터 상담원이 고지를 안 한다'로 오해했다.
- 두 채널을 모두 인식하고 **장비별 채널 매핑**으로 화자를 붙인다.
