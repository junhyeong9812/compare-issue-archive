# issue/tokensvc/exp-millis-never-expire — 정리 (힌트)

태그: `security` · `contract-drift`

## 전체 흐름

```
exp = 1712563200000 → 초로 해석 → 약 54,000년 후 → 사실상 만료 없음
2024-04 파트너 SDK 4.0 업그레이드: exp 를 Date.now() (ms) 로 채움
검증: exp > now 만 확인 → 통과
교정: exp 상한 (now + 최대 수명) · iat 대비 수명 확인
```

## 핵심 문장

- JWT `exp`는 **초 단위**다 — 밀리초 값이 오면 수만 년 뒤로 읽힌다.
- 파트너 SDK 4.0이 **밀리초로 바꿨고**, 우리 검증은 '미래인가'만 봤다.
- 기능 시험은 '유효한 토큰이 통과하는가'만 봐서 못 잡았다.
- 검증은 **exp가 지금 + 최대 수명 이내**인지, `exp − iat`가 허용 수명인지 함께 본다.
