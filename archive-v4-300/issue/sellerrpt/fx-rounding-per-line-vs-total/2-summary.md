# issue/sellerrpt/fx-rounding-per-line-vs-total — 정리 (힌트)

태그: `rounding` · `reconciliation` · `data-semantics`

## 전체 흐름

```
리포트: 주문 줄마다 USD × 환율 → 원 단위 반올림 → 합계
정산(입금): 판매자별 USD 합계 × 환율 → 원 단위 반올림 1회
주문 수 n 이면 오차 최대 ±0.5n 원
국내 판매: 환산 없음 → 차이 없음
```

## 핵심 문장

- 원인은 **반올림 위치**의 차이 — 리포트는 줄마다, 정산은 합계에서 한 번 반올림했다.
- 차이는 **주문 수에 비례**해 커진다 — 큰 판매자일수록 수십 원.
- 환율은 같았다 — 환율 문제가 아니라 **계산 순서** 문제다.
- 대처는 리포트를 정산과 같은 방식(합계 후 반올림)으로, 줄별 표시는 참고값임을 명시, 반올림 규칙을 정산 정책 문서에 고정.
