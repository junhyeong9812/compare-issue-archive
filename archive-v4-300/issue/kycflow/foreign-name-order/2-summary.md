# issue/kycflow/foreign-name-order — 정리 (힌트)

태그: `contract-drift` · `identity`

## 전체 흐름

```
판독 영역  NGUYEN<<VAN<AN    (성 << 이름)
2.x  결합: 성 + 이름 → "NGUYEN VAN AN"
3.0  결합: 이름 + 성 → "VAN AN NGUYEN"     ← 릴리스 노트 "표시 형식 국제화"
비교: 공백 제거 대문자 → "VANANNGUYEN" ≠ "NGUYENVANAN" → 불일치 → 자동 거절
한국인: 신분증 OCR 경로(여권 아님) → 영향 없음
```

## 핵심 문장

- kycflow 3.0은 여권 이름을 **이름+성 순서**로 결합한다 — 2.x는 성+이름이었다.
- 실명확인 응답은 **성+이름** 순서의 공백 없는 대문자다 — 결합 순서가 바뀌면 전부 불일치.
- 비교는 표시용 문자열이 아니라 **구조화된 성·이름 칸**으로 한다.
- 자동 거절은 사람 검토 단계를 두고, 거절률 급변은 경보로 잡는다.
