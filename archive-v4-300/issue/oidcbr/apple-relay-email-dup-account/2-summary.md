# issue/oidcbr/apple-relay-email-dup-account — 정리 (힌트)

태그: `identity`

## 전체 흐름

```
애플 로그인 → id_token {sub: 0012…, email: x7f2…@privaterelay…}
oidcbr: email 로 기존 회원 조회 → 없음 → 신규 계정 생성
이메일 공유 선택 → 실제 이메일 → 기존 회원 연결 OK
교정: 이메일 불일치 시 '기존 계정 있으세요?' → 기존 로그인 후 sub 연결
```

## 핵심 문장

- '이메일 가리기'는 **앱별 릴레이 주소**를 줘서 이메일 기준 연결이 실패한다.
- 연결 실패 시 **자동 신규 가입**으로 이어져 포인트·이력이 없는 계정이 생겼다.
- 애플 `sub`는 앱 단위로 고정이라 **한 번 연결한 뒤의 키**로 쓴다.
- 첫 소셜 로그인에서 일치가 없으면 **기존 계정 로그인 후 연결** 단계를 둔다.
