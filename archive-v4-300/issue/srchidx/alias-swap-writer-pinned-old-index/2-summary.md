# issue/srchidx/alias-swap-writer-pinned-old-index — 정리 (힌트)

태그: `config` · `silent-failure`

## 전체 흐름

```
재색인: merchants_v7 → (복사) → merchants_v8
별칭 merchants: v7 → v8   (검색은 v8)
색인기: index=merchants_v7 (하드코딩) → 신규 문서는 v7 에만
검색(v8) → 재색인 이후 신규 가맹점 없음
```

## 핵심 문장

- 검색은 별칭을 따라가지만, 색인기가 **실제 인덱스 이름**에 쓰면 별칭 교체를 따라가지 않는다.
- 재색인 시점까지의 문서는 복사돼 있어 기존 가맹점은 정상이다 — **이후 쓰기만** 빠진다.
- 옛 인덱스를 지웠다면 색인기가 오류를 냈거나(자동 생성 꺼짐), 자동 생성 켜짐이면 새 v7을 만들어 조용히 계속 썼을 것이다.
- 완료 확인: 교체 후 신규 문서 1건을 써서 별칭으로 검색되는지 본다.
