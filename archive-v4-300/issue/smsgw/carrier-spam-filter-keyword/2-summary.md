# issue/smsgw/carrier-spam-filter-keyword — 정리 (힌트)

태그: `silent-failure` · `external-policy`

## 전체 흐름

```
이벤트 서비스 ──send "[한빛페이] 축하합니다! 당첨 ... 무료 ..."──▶ smsgw ──▶ 통신사 B
                                                        │ 스팸 필터(키워드·URL 단축)
                                                        ▼
                                          단말 스팸함 또는 차단, DLR=0000
통신사 A·C: 정상 수신 / 통신사 B: 대부분 미수신
```

## 핵심 문장

- 통신사 스팸 필터에 걸린 문자도 DLR은 **`0000`(성공)** 으로 온다 — 필터는 단말 앞에서 작동하고 리포트를 바꾸지 않는다.
- 통신사마다 필터 정책이 달라 **특정 통신사 고객만** 못 받는다.
- 이번 건은 "당첨", "무료"와 단축 URL 조합이 걸렸다 — 단축 URL을 자사 도메인 전체 URL로 바꾸고 문구를 고쳐 해결.
- 중요한 안내는 발송 전 통신사별 테스트 단말로 확인한다.
