# issue/smsgw/sender-number-dereg-dlr-3008 — 정리 (힌트)

태그: `silent-failure` · `contract-drift`

## 전체 흐름

```
결제 서비스 ──POST /v2/send (from=1588-xxxx)──▶ smsgw
                                      │ 형식 검사만 함
                                      ▼
                         HTTP 200 {"result":"0000","msgId":"S2502..."}   ← 서비스는 "발송 성공" 기록
                                      │
                         통신사 중계 ──▶ 발신번호 사전등록 조회
                                      │ 등록 해지된 번호
                                      ▼
                         DLR 콜백 {"report":"3008"}   ← 리포트 수신기가 미분류 코드로 버림

번호 교체: 새 번호 등록 전에 옛 번호부터 해지
```

## 핵심 문장

- `smsgw`의 접수 응답 `0000`은 **형식 검사 통과**일 뿐 통신사 전달이 아니다 — 결과는 DLR(리포트) 콜백으로만 온다.
- 발신번호 사전등록 여부는 **통신사 단계**에서 검사된다 — 미등록 번호는 접수 후 리포트 `3008`로 실패한다.
- 리포트 수신기가 모르는 코드를 로그 없이 버려, 실패가 "성공"으로 남았다.
- 번호 교체는 **새 번호 등록 완료 확인 → 발송 설정 전환 → 옛 번호 해지** 순서로 한다.
