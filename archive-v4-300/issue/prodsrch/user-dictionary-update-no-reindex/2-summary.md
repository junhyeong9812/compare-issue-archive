# issue/prodsrch/user-dictionary-update-no-reindex — 정리 (힌트)

태그: `deployment` · `search-quality` · `consistency`

## 전체 흐름

```
갱신 전: '무선이어폰' → 색인·검색 모두 [무선, 이어폰]
사전 추가 후 검색 분석기: '무선이어폰' → [무선이어폰]
기존 색인 문서: 여전히 [무선, 이어폰] 로 저장 → 질의 토큰 불일치 → 0건
신규 상품: 새 사전으로 색인 → 검색됨
```

## 핵심 문장

- 원인은 **검색 쪽 분석기만 새 사전을 쓰고 기존 색인 문서는 옛 사전 토큰**으로 남은 것이다.
- 사전 갱신은 **색인 재생성과 한 묶음**이어야 한다 — 절차서에 재색인 단계가 없었다.
- 신규 상품은 새 사전으로 색인돼 검색돼서 **"일부 상품만 나온다"**처럼 보였다.
- 대처는 사전 갱신 시 새 색인 생성 후 전환, 상위 검색어 결과 수 회귀 점검.
