## 정답
<!-- 질문 1:1 대응 -->

1. **"최대 폴링 간격 초과로 그룹 이탈"과 재조정 로그가 반복됐다.**

2. **묶음 처리가 끝나기 전에 그룹에서 빠져 같은 묶음을 계속 다시 시작했다.**\
처리량이 거의 0이었다.

3. **가격·재고 변경은 다른 토픽·다른 소비자 그룹이었다.**

4. **경보가 "소비자 인스턴스 다운" 기준이었다.**\
인스턴스는 살아 있어 울리지 않았고, 지연 건수 경보는 임계가 하루치라 늦었다.

5. **묶음 크기 축소, 외부 조회 병렬화·시간 제한, 소비 지연을 "가장 오래된 미처리 이벤트 나이"로 경보(10분).**

## 문제 구조 (추상화 코드)

### 변형 A — 처리 시간이 폴링 간격을 넘는 묶음
① 문제 코드
```java
props.put("max.poll.records", 500);          // 묶음당 이미지 메타 조회 500회
```
② 고친 코드
```java
props.put("max.poll.records", 50);
// 이미지 메타는 병렬 조회 + 건당 2초 제한
```
무엇이 깨졌나: 묶음 크기가 평시 부하에 맞춰져 대량 등록 때 폴링 간격을 넘었다.
