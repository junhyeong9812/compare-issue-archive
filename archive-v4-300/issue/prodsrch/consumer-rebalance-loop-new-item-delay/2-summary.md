# issue/prodsrch/consumer-rebalance-loop-new-item-delay — 정리 (힌트)

태그: `latency` · `streaming` · `capacity`

## 전체 흐름

```
상품 등록 이벤트 → 토픽 product.created → prodsrch 소비자 그룹 (6개)
대량 등록: 이벤트 한 묶음(500건)마다 이미지 메타 조회 → 묶음 처리 6분
소비자 최대 폴링 간격 5분 초과 → 그룹에서 제외 → 재조정 → 같은 묶음 처음부터
→ 재조정 반복, 오프셋 거의 전진 없음
가격·재고: 별도 토픽·별도 소비자 그룹 → 영향 없음
```

## 핵심 문장

- 원인은 **한 묶음 처리 시간이 최대 폴링 간격(5분)을 넘어** 소비자가 그룹에서 빠지고 재조정이 반복된 것이다.
- 재조정마다 **같은 묶음을 처음부터 다시** 처리해 오프셋이 거의 전진하지 않았다 — 살아 있지만 일하지 못하는 상태.
- 가격·재고는 **별도 토픽·소비자 그룹**이라 영향이 없었다.
- 대처는 묶음 크기 축소(500→50), 이미지 메타 조회 병렬화, 소비 지연(lag) 시간 기준 경보.
