# issue/splitab/bot-filter-arm-asymmetry-srm — 정리 (힌트)

태그: `data-quality` · `statistics` · `experimentation`

## 전체 흐름

```
배정: 사용자 ID 해시 → A/B 50:50 (배정 로그 기준 정확히 50.0:50.0)
노출 집계: 페이지 경로별 봇 필터 적용 후 집계
B안 새 랜딩 경로: 최근 추가된 봇 필터 규칙(헤드리스 브라우저 패턴) 이 정상 사용자 일부까지 제외
→ B 노출 -8% → 52.1 : 47.9 → 표본 비율 불일치(SRM) 경보
```

## 핵심 문장

- 원인은 **봇 필터가 B안 경로에만 적용**돼 정상 사용자 일부가 B에서만 빠진 것이다.
- 배정은 정확했다 — 비율 불일치는 **집계 단계 필터의 비대칭**에서 생겼다.
- 빠진 사용자는 특정 기기·브라우저에 몰려 있어 **전환율 비교가 편향**된다.
- 대처는 필터를 양쪽 동일 적용, 배정 로그 기준 분모로 판독, SRM 경보 시 판독 자동 중단 유지.
