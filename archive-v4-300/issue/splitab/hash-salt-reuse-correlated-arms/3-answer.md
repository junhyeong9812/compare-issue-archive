# issue/splitab/hash-salt-reuse-correlated-arms — 정답

태그: `statistics` · `experimentation` · `config`

## 정답
<!-- 질문 1:1 대응 -->

1. **`hash(솔트 + 사용자 ID)`였고 두 테스트의 솔트가 같았다.**

2. **테스트를 복제해 만들면서 솔트가 그대로 복사됐다.**\
화면에서 솔트 칸을 바꾸는 사람이 없었다.

3. **B군 사용자는 두 처치를 함께 받아 각 테스트 차이에 다른 처치 효과가 섞였다.**

4. **솔트 = 테스트 ID 자동 생성, 테스트 시작 시 진행 중 테스트와 배정 일치율 점검(50% 근처가 정상), 두 테스트 재실행.**

## 문제 구조 (추상화 코드)

### 변형 A — 사람이 정하는 배정 솔트
① 문제 코드
```java
String salt = form.salt();        // 복제 시 원본 값
```
② 고친 코드
```java
String salt = test.id().toString();     // 테스트마다 유일, 수정 불가
```
무엇이 깨졌나: 독립이어야 할 무작위 배정이 복제라는 운영 동작으로 상관됐다.
