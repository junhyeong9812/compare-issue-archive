# issue/splitab/hash-salt-reuse-correlated-arms — 정리 (힌트)

태그: `statistics` · `experimentation` · `config`

## 전체 흐름

```
배정 = hash(salt + user_id) % 100 < 50 → B
테스트 생성 화면: 솔트 기본값 = 생성 템플릿의 고정 문자열 (복제 시 그대로 복사)
장바구니 버튼 테스트 ← 배송비 문구 테스트를 복제해 생성 → 같은 솔트
→ 두 B군 동일 → 버튼 효과 + 문구 효과가 같은 사용자에게 합쳐짐
```

## 핵심 문장

- 원인은 **테스트 복제 시 솔트가 그대로 복사**돼 두 테스트의 배정이 같아진 것이다.
- 두 B군이 같으면 각 테스트의 B 효과에 **다른 테스트의 처치가 섞인다**.
- 결과가 둘 다 크게 나오고 **단독 재실행에서 재현되지 않는** 것이 단서다.
- 대처는 솔트를 테스트 ID로 자동 생성(입력 불가), 동시 진행 테스트 간 배정 상관 점검.
