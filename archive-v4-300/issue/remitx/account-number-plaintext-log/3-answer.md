# issue/remitx/account-number-plaintext-log — 정답

태그: `security` · `privacy`

## 정답
<!-- 질문 1:1 대응 -->

1. **은행 오류 응답이 요청 본문을 그대로 포함했다.**

2. **해당 기간 로그를 파기하고 파기 기록을 남겼다.**

3. **오류 코드·요청 ID만 남기고, 원문은 접근 통제된 감사 저장소에 암호화해 7일만 둔다.**

4. **로그 저장소 전체에 IBAN·카드번호·주민번호 패턴 검색을 돌려 응답 본문을 통째로 찍는 연동 3곳을 더 찾았다.** 모두 같은 방식으로 고쳤다.

## 문제 구조 (추상화 코드)

① 문제 코드
```java
log.warn("bank error: {}", responseBody);
```
② 고친 코드
```java
var e = BankError.parse(responseBody);
log.warn("bank error code={} reqId={}", e.code(), e.requestId());
```
무엇이 깨졌나: 외부 응답을 신뢰된 비민감 데이터로 다뤘다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| 필드 추출 기록 + 출력 필터 | 작음 | 없음 | 기본 |
| 응답 원문 기록 유지 | 없음 | 노출 | 선택하지 않음 |

**결론**: 외부 응답은 필요한 필드만 골라 기록한다.
