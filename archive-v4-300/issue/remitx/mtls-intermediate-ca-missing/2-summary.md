# issue/remitx/mtls-intermediate-ca-missing — 정리 (힌트)

태그: `tls` · `environment-drift`

## 전체 흐름

```
은행 서버 인증서 교체 → 새 중간 CA, 서버가 체인 일부만 제공
서버 4대: OS 신뢰 저장소에 새 중간 CA 있음 (최근 이미지)
서버 2대: 구 이미지 → 체인 구성 실패 → PKIX path building failed
```

## 핵심 문장

- 같은 서비스라도 **서버 이미지가 달라** 신뢰 저장소가 달랐다.
- 은행 서버가 중간 인증서를 체인에 넣지 않는 설정이었다.
- 교정: 앱 전용 신뢰 저장소에 은행 체인 명시, 서버 이미지 통일, 은행에 전체 체인 제공 요청.
