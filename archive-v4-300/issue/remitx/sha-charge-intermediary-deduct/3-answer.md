# issue/remitx/sha-charge-intermediary-deduct — 정답

태그: `contract-drift` · `fees`

## 정답
<!-- 질문 1:1 대응 -->

1. **중계·수취 은행 수수료를 뺀 금액이다.** 이번에는 1,975 USD.

2. **직거래 은행 관계가 없는 국가·통화만 중계은행을 거쳤다.**

3. **송금인(회사) 부담이 된다.** 건당 고정 수수료라 정산 원가에 반영했다.

4. **송금 전문(MT103)의 수수료 부담 필드(71A)와 은행 수수료 내역을 본다.**

## 문제 구조 (추상화 코드)

① 문제 코드
```python
remitx.send(amount=amt, ccy='USD', beneficiary=b)
```
② 고친 코드
```python
remitx.send(amount=amt, ccy='USD', beneficiary=b, charge='OUR')
```
무엇이 깨졌나: 계약상 전액 지급인데 벤더 기본 수수료 옵션을 그대로 썼다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| OUR 명시 | 건당 수수료 부담 | 없음 | 기본 |
| SHA 유지 + 셀러 안내 | 없음 | 계약 위반 | 선택하지 않음 |

**결론**: 돈의 흐름을 바꾸는 옵션은 계약에 맞춰 명시한다.
