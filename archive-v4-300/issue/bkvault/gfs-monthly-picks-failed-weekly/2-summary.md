# issue/bkvault/gfs-monthly-picks-failed-weekly — 정리 (힌트)

태그: `backup` · `retention`

## 전체 흐름

```
4/6(일) 주간 백업 실패 → 4/7(월) 수동 실행(일간 태그)
월간 승격 규칙: '첫 일요일 주간본' → 없음 → 4월 월간 없음
일간·주간은 기간 경과로 삭제 → 4월 시점 복구 수단 소멸
```

## 핵심 문장

- GFS 승격은 **특정 슬롯(첫 일요일)**에 묶여 있어 그 슬롯 실패가 상위 보관본 부재로 번진다.
- 수동 재실행은 **일간 태그**로 남아 승격 대상이 아니었다.
- 대체 승격(그 달 첫 성공 주간본)은 설정 옵션이었고 꺼져 있었다.
- 월간 보관본 존재를 매달 점검한다.
