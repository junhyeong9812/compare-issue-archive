# issue/bkvault/kms-key-version-disabled-restore — 정답

태그: `backup` · `key-management`

## 정답
<!-- 질문 1:1 대응 -->

1. **`KeyDisabled`로 실패한다.**

2. **연습은 늘 최근 7일 백업으로 했다.**

3. **삭제 기간이 지나면 그 백업은 영구 복구 불가다.** 이번엔 비활성이라 다시 켜서 복구했다.

4. **옛 버전 비활성화를 '그 버전을 쓰는 백업의 보관 만료 후'로 묶고**, 분기 연습에 가장 오래된 백업 1건을 넣는다.

## 문제 구조 (추상화 코드)

### 변형 A — 키 교체와 동시에 옛 버전 비활성
① 문제 코드
```sh
kms rotate backup-key
kms disable-version backup-key v3
```
② 고친 코드
```sh
kms rotate backup-key
# v3 비활성은 v3 로 암호화된 마지막 백업의 보관 만료일 이후
bkvault keys usage backup-key --version v3   # 남은 백업 수 확인
```
무엇이 깨졌나: 키 버전의 수명을 그 키로 보호한 데이터의 수명과 연결하지 않았다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 옛 버전 유지 + 사용량 확인 | 키 관리 절차 | 작음 | 보안 점검과 충돌 | 기본 |
| 교체 시 백업 재암호화 | 재암호화 작업 | 큼 | 작업 중 실패 | 규제상 필요 시 |
| 오래된 백업 복구 연습 | 연습 시간 | 중간 | 없음 | 함께 |

**결론**: 키 버전 비활성화는 사용량이 0일 때만 한다.
