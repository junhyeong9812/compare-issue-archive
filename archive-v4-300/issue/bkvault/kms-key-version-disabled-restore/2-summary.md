# issue/bkvault/kms-key-version-disabled-restore — 정리 (힌트)

태그: `backup` · `key-management`

## 전체 흐름

```
12월 백업: 데이터 키 ← KMS 키 v3 로 암호화
1월 교체: v4 활성, v3 비활성
복구: 데이터 키 복호화 요청(v3) → KeyDisabled → 복구 불가
최근 백업(v4) → 정상
```

## 핵심 문장

- 키 교체는 **새 암호화**만 새 버전으로 한다 — 옛 데이터는 옛 버전으로 풀어야 한다.
- 복구 연습이 **최근 백업만** 써서 옛 키 문제를 못 잡았다.
- 비활성은 다시 켤 수 있지만, 삭제 예약이 끝나면 데이터는 영구히 잃는다.
- 옛 버전은 보관 기간이 끝날 때까지 활성으로 두고, 연습은 가장 오래된 백업도 포함한다.
