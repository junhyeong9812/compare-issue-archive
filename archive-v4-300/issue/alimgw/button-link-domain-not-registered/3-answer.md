# issue/alimgw/button-link-domain-not-registered — 정답

태그: `contract-drift` · `deploy`

## 정답
<!-- 질문 1:1 대응 -->

1. **요청마다 `400 B220`으로 거절된다.** 대체발송 대상도 아니다 — 요청 자체가 거부됐기 때문이다.

2. **스테이징은 벤더 모의 서버를 썼고 모의 서버는 도메인을 검사하지 않는다.**

3. **허용된다.** 단 템플릿에 고정된 URL 부분이 바뀌면 템플릿 재승인이 필요하다.

## 문제 구조 (추상화 코드)

### 변형 A — 외부 등록 상태와 무관하게 링크 도메인 변경
① 문제 코드
```yaml
receipt:
  base-url: https://r.hbpay.kr        # 배포와 동시에 전환
```
② 고친 코드
```yaml
receipt:
  base-url: https://receipt.hanbitpay.co.kr
  next-base-url: https://r.hbpay.kr   # 채널 도메인 등록·템플릿 재승인 확인 후 플래그로 전환
  switch-flag: receipt.short-domain
```
무엇이 깨졌나: 외부 채널 설정(허용 도메인)에 묶인 값을 코드 배포만으로 바꿨다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 플래그 전환(등록 후) | 등록 상태 조회 | 작음 | 플래그 관리 | 기본 |
| 모의 서버에 도메인 검사 추가 | 모의 서버 수정 | 중간 | 규칙 동기화 | 함께 적용 |

**결론**: 외부 등록에 묶인 값은 등록 확인 뒤 플래그로 바꾼다.
