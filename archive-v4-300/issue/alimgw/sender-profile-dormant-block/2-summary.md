# issue/alimgw/sender-profile-dormant-block — 정리 (힌트)

태그: `credential-lifecycle` · `ops`

## 전체 흐름

```
발신 프로필 hb-remit : 마지막 발송 2023-01 → 2024-01 휴면 전환(벤더 공지 메일은 퇴사자 계정으로)
2024-02-06 재개 → alimgw send → 400 {"code":"P301","msg":"inactive sender profile"}
해제: 관리 콘솔에서 휴면 해제 요청 → 영업일 1일
```

## 핵심 문장

- 알림톡 발신 프로필은 **1년 미발송 시 휴면**으로 바뀐다 — 발송 키는 그대로지만 모든 요청이 `P301`로 거절된다.
- 벤더 안내는 프로필 관리자 메일로만 왔고, 그 계정은 퇴사로 정지돼 있었다.
- 대처: 프로필 관리자를 공용 메일로 바꾸고, 프로필별 마지막 발송일을 월간 점검 목록에 넣었다.
