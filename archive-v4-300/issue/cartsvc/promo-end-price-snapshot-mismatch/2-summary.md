# issue/cartsvc/promo-end-price-snapshot-mismatch — 정리 (힌트)

태그: `data-consistency` · `cache` · `ux`

## 전체 흐름

```
장바구니 담기: 그 시점 가격을 스냅샷으로 저장 → 장바구니 화면은 스냅샷 표시
결제 화면: 가격 서비스에서 현재 가격 조회
7/31 자정 프로모션 종료 → 장바구니 화면: 할인가 / 결제 화면: 정가
8/1 이탈률 3배 (특히 7월 말에 담아 둔 고객)
```

## 핵심 문장

- 원인은 장바구니 화면이 **담을 때의 가격 스냅샷**을 보여 주고, 결제는 **현재 가격**을 쓴 것이다.
- 결제 금액(현재 가격)이 맞다 — 틀린 것은 장바구니 표시였다.
- 스냅샷 저장 이유는 가격 서비스 부하 절감이었다 — 표시용 가격은 **짧은 캐시**로도 충분했다.
- 대처는 장바구니 화면에서 현재 가격 조회(5분 캐시), 가격 변동 시 "가격이 바뀌었어요" 표시.
