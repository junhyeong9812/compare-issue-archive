# issue/cartsvc/guest-merge-quantity-doubled — 정리 (힌트)

태그: `data-integrity` · `ux` · `merge`

## 전체 흐름

```
개편 전: 로그인 시 비로그인 장바구니를 로그인 장바구니로 병합 후 비로그인 장바구니 삭제
개편 후: 앱 자동 로그인 갱신마다 병합 호출 (비로그인 장바구니 삭제 누락)
병합 규칙: 같은 상품 → 수량 합산
→ 같은 상품이 두 장바구니에 다 있으면 로그인할 때마다 합산
```

## 핵심 문장

- 원인은 **병합 후 비로그인 장바구니를 지우지 않아** 로그인할 때마다 다시 합산된 것이다.
- 개편으로 **자동 로그인 갱신에도 병합이 호출**돼 반복이 생겼다.
- 합산 규칙 자체는 의도였지만 **병합이 한 번만 일어난다는 전제**가 깨졌다.
- 대처는 병합을 멱등하게(병합 완료 표시·비로그인 장바구니 삭제를 같은 트랜잭션), 같은 상품은 큰 수량으로.
