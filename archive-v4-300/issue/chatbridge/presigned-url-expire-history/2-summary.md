# issue/chatbridge/presigned-url-expire-history — 정리 (힌트)

태그: `design` · `storage`

## 전체 흐름

```
첨부 업로드 → 저장소 key = att/2025/01/…/a1.jpg
메시지 본문 = presigned URL (만료 15분)   ← URL 을 저장
이력 재열람 → 만료 URL → 403 → 깨진 이미지
교정: 메시지에는 key 저장 · 열람 시 권한 확인 후 그때 URL 발급
```

## 핵심 문장

- 메시지에 **만료되는 URL**을 저장해 15분 뒤엔 첨부가 403이다.
- 상담 중에는 15분 안에 보므로 문제가 안 보였다.
- 유효 시간을 늘리면 **URL이 유출됐을 때 오래 열린다** — 개인정보 첨부라 안 된다.
- 메시지에는 **객체 키**를 저장하고, 열람할 때 권한 확인 후 짧은 URL을 발급한다.
