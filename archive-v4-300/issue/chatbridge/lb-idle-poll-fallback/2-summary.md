# issue/chatbridge/lb-idle-poll-fallback — 정리 (힌트)

태그: `latency` · `environment-drift`

## 전체 흐름

```
상담원 화면 ──웹소켓──▶ LB(유휴 60s) ──▶ chatbridge   핑 90s
  60초 무통신 → LB 가 연결 종료
  화면: 재연결 실패 시 30초 폴링 폴백 (재연결은 지수 백오프)
  고객 메시지 → 다음 폴링까지 최대 30초 지연
구 LB 유휴 타임아웃 = 350s → 문제 없었음
교정: 핑 25s (< 유휴 타임아웃) · 폴백 중 재연결 계속 시도
```

## 핵심 문장

- 새 LB 유휴 타임아웃(60초)이 **웹소켓 핑 간격(90초)보다 짧아** 조용한 대화마다 연결이 끊겼다.
- 화면은 끊기면 **30초 폴링**으로 떨어져 메시지가 최대 30초 늦었다.
- 폴백은 오류가 아니라 정상 경로라 경보가 없었다.
- 핑 간격은 경로상 **가장 짧은 유휴 타임아웃보다 짧게** 둔다.
