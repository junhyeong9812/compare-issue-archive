# issue/wafedge/partner-callback-traversal-rule — 정리 (힌트)

태그: `silent-failure` · `false-positive`

## 전체 흐름

```
카드사 ──POST /settle/notify {file:"../2025/09/RCV0912.dat"}──▶ wafedge
  규칙 942-PT: 본문에 ../ → 403 (차단 로그만, 앱까지 안 감)
카드사: 403 → 3회 재시도 후 포기 (정산 담당 메일 보고만)

'../' 포함 = 월말 재전송 파일(이전 달 폴더 참조) → 월말·월초 통보만 막힘
교정: 이 경로·이 파트너 IP·이 필드에만 942-PT 예외, 나머지 규칙 유지
```

## 핵심 문장

- 관리 규칙 942-PT가 **본문의 `../`**를 경로 조작 공격으로 보고 차단했다.
- `../`는 **월말 재전송 통보**에만 들어 있어 일부만 막혔다.
- 차단은 WAF에서 끝나 **앱 수신 로그에 흔적이 없다** — WAF 차단 로그를 봐야 한다.
- 예외는 **경로·출발 IP·필드 단위**로 좁게 둔다 — 규칙 전체를 끄지 않는다.
