# issue/wafedge/partner-ip-allowlist-single — 정리 (힌트)

태그: `silent-failure` · `environment-drift`

## 전체 흐름

```
제휴사 출구 IP 풀 .10 .11 .12 .13 (라운드로빈)
wafedge 허용: .10 .11 → .12 .13 출발 요청 403
→ 통보 약 절반 차단, 재전송은 다른 IP 로 나가면 통과
송금 상태: 결과 통보 미수신 → '처리 중'
공지: 2주 전 메일, 수신자 = 퇴사한 담당자
```

## 핵심 문장

- 허용 목록이 **개별 /32 두 개**라 새로 추가된 출구 IP 두 개는 막혔다.
- 제휴사가 출구 IP를 라운드로빈으로 써서 **약 절반만** 막히고, 재전송은 운에 따라 통과했다.
- 변경 공지가 **퇴사자 메일**로 가서 아무도 못 봤다.
- 허용 목록은 파트너가 공식 제공한 대역으로 두고, 파트너 연락처는 팀 메일로 등록한다.
