# issue/wafedge/empty-ua-managed-rule — 정리 (힌트)

태그: `environment-drift` · `false-positive`

## 전체 흐름

```
정산 배치 (경량 HTTP 클라이언트, UA 미설정)
  ──▶ 내부 API 공용 도메인 ──▶ wafedge (외부·내부 공용 앞단)
        913-UA: UA 없음 → 403      ← 2026.01 규칙셋 신규, 기본 차단
다른 서비스: 표준 라이브러리 기본 UA 있음 → 통과
```

## 핵심 문장

- 관리 규칙셋 자동 갱신으로 **913-UA(빈 UA 차단)**가 기본 활성이 됐다.
- 정산 배치의 경량 HTTP 클라이언트만 **UA를 비워** 보내 막혔다.
- 내부 API가 외부와 같은 도메인·같은 WAF 앞단을 써서 영향을 받았다.
- 관리 규칙셋은 **탐지(로그) 모드로 먼저 받고** 며칠 관찰 후 차단으로 바꾼다.
