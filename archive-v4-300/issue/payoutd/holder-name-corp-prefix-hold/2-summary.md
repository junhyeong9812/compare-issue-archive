# issue/payoutd/holder-name-corp-prefix-hold — 정리 (힌트)

태그: `silent-failure` · `data-normalization`

## 전체 흐름

```
payoutd run --date 2024-03-15
   ├─ 예금주 조회 (은행)  "주식회사 한빛상사"
   ├─ 등록 예금주         "(주)한빛상사"
   │   대조: 공백 제거 후 완전 일치 → 불일치
   ▼
상태 HOLD_NAME, 실행 요약 "executed 3,912 / ok" ← 보류 건은 실행 대상에서 빠진 수
```

## 핵심 문장

- `payoutd`의 예금주 대조는 **공백만 제거한 완전 일치**다 — `(주)`·`주식회사`·`㈜`를 같은 것으로 보지 않는다.
- 보류 건은 실행 요약의 실패 수에 들어가지 않는다 — 실행 대상에서 빠진 것으로 집계된다.
- 2024-03 은행 예금주 조회 API가 법인명 표기를 `주식회사 …`로 바꾼 뒤 시작됐다.
- 교정: 법인 접두 표기를 정규화해 비교하고, HOLD 건수를 실행 요약과 경보에 넣는다.
