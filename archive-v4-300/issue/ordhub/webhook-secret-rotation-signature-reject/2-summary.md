# issue/ordhub/webhook-secret-rotation-signature-reject — 정리 (힌트)

태그: `credential` · `partial-failure` · `integration`

## 전체 흐름

```
14:00  허브 설정: 서명 비밀 = 새 값 (옛 값 즉시 폐기)
14:00  마켓 판매자 센터: 새 비밀 저장 → 마켓 발송 서버들에 전파 (최대 40분)
14:00~14:40  아직 옛 비밀로 서명한 웹훅 → 허브 검증 실패 → 401
             마켓 재시도: 1·5·15·30·60·120분, 6회 후 포기
             옛 비밀 웹훅의 재시도도 같은 서버가 옛 비밀로 서명 → 일부 6회 모두 실패
결과: 교체 창 주문 1,930건 중 214건 미수집
```

## 핵심 문장

- 원인은 **허브가 교체 즉시 옛 비밀을 폐기**한 것 — 마켓의 새 비밀 전파에는 최대 40분이 걸린다.
- 일부만 누락된 것은 **옛 비밀이 남은 발송 서버를 탄 웹훅**만 실패했기 때문이다.
- 마켓 재시도가 같은 서버에서 나가 **재시도도 실패**한 건이 있었다 — 6회 후 포기.
- 대처는 교체 기간 **두 비밀 동시 허용**(24시간), 서명 실패 경보, 마켓 주문 목록 API로 시간대별 대사.
