# issue/ordhub/deploy-pool-size-default-p99 — 정리 (힌트)

태그: `config` · `deployment` · `latency`

## 전체 흐름

```
배포 6/12 10:00: 환경별 설정 파일 통합 → 운영 전용 pool.max=60 줄 누락 → 기본값 10
12:00 피크: 동시 요청 > 10 → 커넥션 대기 → p99 8초
스테이징 부하 시험: 동시 8 → 기본값 10 으로도 충분
```

## 핵심 문장

- 원인은 **커넥션 풀 최대 크기 설정 누락** — 기본값 10으로 돌았다.
- 오전에는 동시 요청이 10을 넘지 않아 **피크에야** 드러났다.
- 스테이징 부하 시험이 **운영 피크보다 훨씬 낮은 동시성**으로 돌아 차이를 못 봤다.
- 대처는 핵심 설정 값 시작 시 로그·검증, 풀 대기 시간 지표, 부하 시험을 운영 피크 기준으로.
