# issue/tokvault/key-rotation-old-key-disabled-early — 정리 (힌트)

태그: `security` · `key-management`

## 전체 흐름

```
키 회전: 새 키 K2 로 신규 암호화, 기존 데이터 재암호화 배치 (K1 → K2)
재암호화 진행률 72% 시점에 보안 점검 일정 맞추려 K1 비활성화
      │  남은 28% (가입 오래된 회원) 복호화 불가
      ▼
K1 재활성화 → 재암호화 완료 → K1 비활성화
```

## 핵심 문장

- 구 키 비활성화는 **재암호화 완료(남은 건수 0) 확인 후**에만 해야 한다.
- 재암호화 배치가 최신 행부터 돌아 가입이 오래된 회원의 토큰이 구 키로 남았다.
- 교정: 키 비활성화 명령이 구 키로 암호화된 행 수를 확인하고 0이 아니면 거부.
