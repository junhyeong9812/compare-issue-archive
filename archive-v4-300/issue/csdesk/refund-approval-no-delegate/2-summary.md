# issue/csdesk/refund-approval-no-delegate — 정리 (힌트)

태그: `workflow` · `silent-failure`

## 전체 흐름

```
상담원 승인 ──▶ 금액 ≥ 300,000 ? ── 아니오 → 즉시 환불 요청
                        │ 예
                        ▼
                 2차 결재 대기 (팀장 A)
                   A 부재 + 위임 미설정 → 무기한 대기 (타임아웃 없음)
상담원 화면 상태 = '승인 완료' (1차 기준 표시)
05-02 ~ 05-06 대기 63건 → 05-07 A 복귀 후 일괄 결재
```

## 핵심 문장

- 2차 결재는 **지정 결재자 한 명**에게만 가고, 부재 시 자동 위임이 없다.
- 상담원 화면의 '승인 완료'는 **1차 승인**이다 — 환불 요청 여부가 아니다.
- 30만 원 미만은 1차로 끝나 영향이 없었다 — 고액 환불만 늦었다.
- 결재 대기 시간 상한(예: 4시간)과 상한 초과 시 대체 결재자 자동 배정을 둔다.
