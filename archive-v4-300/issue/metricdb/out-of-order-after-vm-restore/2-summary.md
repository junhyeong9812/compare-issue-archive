# issue/metricdb/out-of-order-after-vm-restore — 정리 (힌트)

태그: `silent-failure` · `time`

## 전체 흐름

```
기존 시계열 마지막 샘플: 14:00
복구 VM 시계 11:00 → 샘플 타임스탬프 11:00~ → out_of_order → 거부(카운터만 증가)
시간 동기화 늦게 동작 → 14:00 이후 정상
```

## 핵심 문장

- 시계열 DB는 기본으로 **마지막 샘플보다 이른 타임스탬프**를 거부한다.
- 거부는 원격 쓰기 응답의 일부 오류로만 오고 에이전트는 배치 성공으로 기록했다.
- 시간 동기화가 맞춰지면 회복된다 — 공백 구간은 복구되지 않는다.
- 복구 절차에 '시간 동기화 확인 후 에이전트 시작'을 넣는다.
