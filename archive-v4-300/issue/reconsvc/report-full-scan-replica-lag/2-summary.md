# issue/reconsvc/report-full-scan-replica-lag — 정리 (힌트)

태그: `performance` · `replication`

## 전체 흐름

```
월간 대사 리포트 → 공용 읽기 복제본에서 실행
쿼리: 날짜 함수로 감싼 조건 → 인덱스 미사용 → 2억 행 풀스캔
      │  복제본 I/O 포화 → 복제 적용 지연
      ▼
같은 복제본을 쓰는 가맹점 화면이 7분 전 데이터 표시
```

## 핵심 문장

- `DATE(created_at) = ?`처럼 **컬럼을 함수로 감싸면** 인덱스를 못 쓴다.
- 분석 쿼리와 서비스 조회가 같은 복제본을 썼다.
- 교정: 범위 조건으로 재작성, 분석 전용 복제본 분리.
