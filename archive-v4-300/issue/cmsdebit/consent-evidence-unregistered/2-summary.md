# issue/cmsdebit/consent-evidence-unregistered — 정리 (힌트)

태그: `async-status` · `contract-drift`

## 전체 흐름

```
회원 가입 → 출금 계좌 등록 (cmsdebit member add)
          → 동의 증빙(녹취/전자서명) 등록 (cmsdebit evidence put)  ← 별도 호출
출금 신청 (D-1) → 접수 OK
결과 (D+1) → 증빙 미등록 회원: 코드 '증빙 미제출' 불능
```

## 핵심 문장

- 회원 등록과 **동의 증빙 등록은 별개 호출**이고, 증빙 없이도 회원 등록·출금 접수는 성공한다.
- 2023-09 가입 화면 개편 때 전자서명 단계 뒤 증빙 업로드 호출이 빠졌다.
- 결과는 출금일 다음 날 파일로 와서 "늦게 불능"으로 보였다.
- 교정: 증빙 등록 확인 전에는 출금 대상에서 제외하고 회원에게 재동의 안내.
