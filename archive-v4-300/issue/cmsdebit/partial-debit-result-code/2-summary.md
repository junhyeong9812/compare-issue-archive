# issue/cmsdebit/partial-debit-result-code — 정리 (힌트)

태그: `data-meaning` · `silent-failure`

## 전체 흐름

```
기관 설정: 부분출금 허용 (2024-08 영업팀 요청으로 변경)
출금 신청 30,000 / 잔액 12,000
결과 파일: 코드 0000, 출금액 12,000           ← 부분출금도 0000
사내: 코드 0000 → 신청액 30,000 완납 처리
      ▼
월 대사: 사내 수납 > 은행 입금
```

## 핵심 문장

- 결과 코드 `0000`은 **출금이 일어났다**는 뜻이지 **신청액 전액**이 아니다 — 부분출금 허용 기관에서는 출금액 필드가 다르다.
- 부분출금 허용은 8월 기관 설정 변경이었고 수납 처리 코드는 그대로였다.
- 잔액이 부족한 회원만 해당돼 일부 건만 어긋났다.
- 교정: 수납액 = 결과 출금액, 미납 잔액은 다음 회차 재청구.
