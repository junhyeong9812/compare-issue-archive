# issue/vacct/account-pool-exhausted — 정리 (힌트)

태그: `capacity` · `monitoring`

## 전체 흐름

```
벤더: 은행별 번호 풀 (NH 20만 개), 만료 계좌 회수 주기 30일
설 연휴 주문 급증 + 입금 기한 7일 → 미입금 계좌가 풀을 점유
      │  풀 잔량 0 → E-POOL
      ▼
사내: 은행 선택 화면에 NH 계속 노출 → 선택 고객만 실패
```

## 핵심 문장

- 번호는 **입금 기한이 끝나고 회수 주기가 지나야** 풀로 돌아온다.
- 풀 잔량을 조회하는 API가 있었지만 감시하지 않았다.
- 교정: 잔량 20% 미만 경보, 잔량 0이면 은행 선택지에서 자동 제외, 벤더에 풀 증설 요청.
