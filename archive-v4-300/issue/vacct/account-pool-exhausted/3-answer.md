# issue/vacct/account-pool-exhausted — 정답

태그: `capacity` · `monitoring`

## 정답
<!-- 질문 1:1 대응 -->

1. **NH 선택 비율이 높아 그 은행 풀이 먼저 비었다.**

2. **늦게 입금하는 고객의 입금이 만료 계좌로 들어가 반환 처리가 늘어난다.** 기한은 유지했다.

3. **잔량 0인 은행은 선택지에서 빼고 안내 문구를 띄운다.**

## 문제 구조 (추상화 코드)

① 문제 코드
```python
banks = ALL_BANKS
```
② 고친 코드
```python
banks = [b for b in ALL_BANKS if vacct.pool_remaining(b) > 0]
# 경보: pool_remaining / pool_size < 0.2
```
무엇이 깨졌나: 소모 자원의 잔량을 감시하지 않았다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| 잔량 경보 + 선택지 자동 제외 | 작음 | 없음 | 기본 |
| 풀 증설만 | 비용 | 다음 피크 | 병행 |

**결론**: 소모성 외부 자원은 잔량을 감시하고 고객 경로에서 우회한다.
