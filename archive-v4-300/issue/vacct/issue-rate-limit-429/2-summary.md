# issue/vacct/issue-rate-limit-429 — 정리 (힌트)

태그: `performance` · `rate-limit`

## 전체 흐름

```
벤더 한도: 가맹점당 초당 50건
행사 오픈 순간 발급 요청 초당 180건
      │  초과분 429 Too Many Requests
      ▼
사내: 429 를 일반 실패로 처리 → 결제 실패 화면
```

## 핵심 문장

- 429는 **잠시 후 다시** 신호다 — 응답 헤더 Retry-After를 따라야 한다.
- 주문 화면에서 동기로 발급해 대기 없이 바로 실패했다.
- 교정: 토큰 버킷으로 초당 45건 이하로 평탄화, 429는 짧은 백오프 재시도, 행사 전 한도 상향 요청.
