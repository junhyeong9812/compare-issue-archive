# issue/vacct/notify-new-source-ip-blocked — 정리 (힌트)

태그: `environment-drift` · `network`

## 전체 흐름

```
벤더 통지 발신 IP: 기존 2개 + 신규 1개 (센터 증설, 공지 메일)
사내 방화벽: 기존 2개만 허용
      │  신규 IP 에서 나간 통지 → 연결 거부
      ▼
벤더 재시도: 10분·30분·60분, 재시도는 기존 IP 로 나갈 수도 있음 → 늦게 성공
```

## 핵심 문장

- 벤더 발신 IP가 **라운드로빈**이라 약 1/3만 막혔다 — 전부 실패가 아니어서 경보 임계에 안 걸렸다.
- 재시도가 다른 IP로 나가면 성공해 "지연"으로만 보였다.
- 교정: 신규 IP 허용, 벤더 IP 목록을 공지 체크리스트로 관리, 통지 지연(입금 시각 vs 수신 시각) 지표 추가.
