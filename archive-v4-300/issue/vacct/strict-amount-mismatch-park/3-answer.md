# issue/vacct/strict-amount-mismatch-park — 정답

태그: `silent-failure` · `contract-drift`

## 정답
<!-- 질문 1:1 대응 -->

1. **아무것도 오지 않는다.** 입금은 MISMATCH로 벤더에 보관된다. `vacct show <계좌>`에서만 보인다.

2. **벤더 기본 모드가 ANY였다.** 사내 코드는 모드를 지정하지 않았다.

3. **금액 차액 처리다.** 과입금은 환불, 부족 입금은 추가 입금 안내가 필요하다 — ANY에서는 이 판단이 사내 몫이 된다.

4. **벤더 쪽 입금 상태를 계좌 단위로 조회한다.** 통지 로그만 보면 "입금 없음"으로 오판한다.

## 문제 구조 (추상화 코드)

① 문제 코드
```python
vacct.issue(amount=order.total)            # 모드 미지정 → 벤더 기본값
```
② 고친 코드
```python
vacct.issue(amount=order.total, mode='RANGE', tolerance=0)   # 명시
# 매시: vacct.list(st='MISMATCH') → 차액 처리 큐
```
무엇이 깨졌나: 벤더 기본값에 계약을 맡겨, 기본값 변경이 조용한 통지 보류가 됐다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| 모드 명시 + MISMATCH 조회 | 작음 | 조회 주기만큼 지연 | 기본 |
| ANY 모드 + 사내 차액 처리 | 중간 | 차액 처리 누락 | 보조 |

**결론**: 외부 동작을 바꾸는 옵션은 명시하고, 보관 상태를 주기적으로 조회한다.
