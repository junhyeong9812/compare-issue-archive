# issue/etaxbr/api-key-rotation-grace-end — 정리 (힌트)

태그: `auth` · `credential-rotation`

## 전체 흐름

```
12-02 중계사 키 회전: 새 키 발급, 구 키 30일 유예
      │  운영 비밀 저장소에는 스테이징만 갱신
01-01 유예 종료
01-02 03:00 발행 배치 → 401 invalid_key × 5,200건
```

## 핵심 문장

- 키 회전 공지에 유예 기간이 있었지만 운영 반영 담당이 지정되지 않았다.
- 401은 재시도해도 안 되는 오류다 — 배치가 5,200번 재시도하며 중계사 rate limit도 건드렸다.
- 교정: 인증 오류는 첫 건에서 배치를 멈추고 경보, 키 만료일을 비밀 저장소 메타데이터로 관리.
