# issue/etaxbr/amend-original-ntsno-missing — 정리 (힌트)

태그: `contract-drift` · `silent-failure`

## 전체 흐름

```
수정발행 요청  etaxbr amend --orig <원본키> --reason 환입
      │  원본키 = 사내 문서번호 (INV-2025-0001234)
      ▼
중계사: 사내 문서번호로 당초분 조회 → 자기 발행분이면 국세청 승인번호로 바꿔 전송
      │  타 중계사로 발행했던 당초분(2024년 이전)은 조회 실패
      ▼
국세청: 당초 승인번호 없음 → 반려 (nts=REJECTED)
```

## 핵심 문장

- `etaxbr amend`의 `--orig`는 **국세청 승인번호(24자리)**가 정식 값이다 — 사내 문서번호는 중계사 편의 기능으로만 해석된다.
- 편의 해석은 **이 중계사로 발행한 당초분**에만 된다 — 2024년 중계사 전환 이전 당초분은 실패한다.
- 그래서 환급 대상 중 오래된 계약 거래처만 반려됐다.
- 당초분 승인번호를 발행 시점에 저장하고, 수정발행은 그 값으로 한다.
