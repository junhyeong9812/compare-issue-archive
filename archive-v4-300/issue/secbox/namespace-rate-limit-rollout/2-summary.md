# issue/secbox/namespace-rate-limit-rollout — 정리 (힌트)

태그: `capacity` · `rollout`

## 전체 흐름

```
200 파드 × 6 비밀 = 1,200 요청 거의 동시 → 한도 50/s → 429
init 컨테이너: 429 를 실패로 종료 → 파드 재시작 → 또 요청 (백오프 없음)
평소: maxSurge 25% (50 파드) → 300 요청, 분산되어 통과
11월: 긴급 패치로 maxSurge 100%
교정: 한 번에 묶음 조회 · 429 지수 백오프 · maxSurge 25%
```

## 핵심 문장

- 파드 200개가 동시에 비밀 1,200건을 요청해 **네임스페이스 한도(50/s)**에 걸렸다.
- init 컨테이너가 429에 **백오프 없이 실패**해 재시작이 요청을 더 늘렸다.
- 평소에는 롤아웃 단위가 25%라 통과했다 — 긴급 패치 때 100%로 바꿨다.
- 비밀은 **묶음 조회 한 번**으로 받고, 429는 지수 백오프로 재시도한다.
