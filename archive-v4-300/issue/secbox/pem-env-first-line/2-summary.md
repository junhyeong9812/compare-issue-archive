# issue/secbox/pem-env-first-line — 정리 (힌트)

태그: `environment-drift` · `config`

## 전체 흐름

```
secbox 값 = "-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----"
운영: 사이드카 env 주입 → 개행에서 잘림 → "-----BEGIN PRIVATE KEY-----"
스테이징: 파일 마운트 → 전체
이전 키: base64 한 줄 형식 → 잘림 없음
앱: 키 로딩 실패 시 '서명 비활성' 경고 후 계속 실행 → 검증 측 401
```

## 핵심 문장

- 사이드카의 환경 변수 주입은 **첫 개행에서 값을 자른다** — 여러 줄 PEM은 헤더 한 줄만 남는다.
- 이전 키는 **한 줄 base64**라 문제가 없었다.
- 스테이징은 파일 마운트라 같은 키가 정상이었다 — **환경별 주입 방식 차이**가 원인을 가렸다.
- 비밀은 **파일 마운트로 통일**하고, 앱은 키 로딩 실패 시 기동을 멈춘다.
