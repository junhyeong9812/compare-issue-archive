# issue/botguard/distributed-stuffing-missed — 정리 (힌트)

태그: `security` · `detection`

## 전체 흐름

```
IP 4,000 × 10분 3회 → IP 기준 임계 20 미만 → 탐지 없음
전체: 새벽 3시 로그인 시도 평소의 12배, 실패율 평소 4% → 93%
계정당: 대부분 1회 시도(유출 비밀번호 1개) → 계정 잠금도 안 걸림
교정: 전역 실패율·시도량 이상 탐지 + 유출 비밀번호 대조 + 성공 직후 새 기기 추가 인증
```

## 핵심 문장

- IP별 임계는 **IP를 흩는 공격**에 무력하다.
- 계정당 1회 시도라 계정 잠금도 안 걸렸다.
- **전역 실패율**(새벽 4%→93%)이 가장 강한 신호였지만 보지 않았다.
- 전역 이상 탐지 + 유출 비밀번호 대조 + 새 기기 로그인 성공 시 추가 인증.
