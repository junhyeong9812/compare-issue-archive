# issue/botguard/captcha-cookie-subdomain — 정리 (힌트)

태그: `browser` · `config`

## 전체 흐름

```
캡차 위젯은 www 에서 로드 → 통과 쿠키 www 전용
pay 서브도메인 요청 → bg_pass 없음 → 다시 캡차 → 반복
위험도 점수 높은 고객(해외 IP, 새 기기)만 캡차 대상 → 일부만 반복
교정: pay 에서 자체 검증 엔드포인트로 쿠키 발급 (호스트 한정)
```

## 핵심 문장

- 통과 쿠키가 **www 호스트 전용**이라 pay 서브도메인 요청에 실리지 않았다.
- 캡차 검증 엔드포인트가 www에 있어 결제 화면에서 풀어도 쿠키는 www에 생겼다.
- 상위 도메인으로 넓히면 **다른 서브도메인(제휴 페이지 등)**에도 통과 쿠키가 퍼진다.
- 서브도메인마다 **자체 검증 엔드포인트**에서 호스트 한정 쿠키를 발급한다.
