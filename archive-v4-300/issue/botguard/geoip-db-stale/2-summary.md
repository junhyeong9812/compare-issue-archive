# issue/botguard/geoip-db-stale — 정리 (힌트)

태그: `environment-drift` · `silent-failure`

## 전체 흐름

```
GeoIP 갱신 작업: 라이선스 키 만료(2025-03) → 다운로드 401 → 작업은 '이전 DB 유지'로 성공 처리
통신사 C 새 대역(04월) → DB 에 없음 → 국가 미상 → '해외'로 취급 → +40 → 추가 인증
교정: 키 갱신 · DB 나이 경보(14일) · 국가 미상은 해외와 구분
```

## 핵심 문장

- GeoIP 갱신이 **라이선스 만료로 실패**했지만 작업은 이전 DB를 유지하며 성공으로 끝났다.
- DB에 없는 새 대역은 **국가 미상**이 됐고, 점수 로직이 미상을 해외로 취급했다.
- 새 대역 고객만 추가 인증을 매번 받았다.
- **DB 나이**를 감시하고, 미상과 해외를 구분한다.
