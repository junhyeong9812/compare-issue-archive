# issue/chgback/portal-crawler-mfa-login — 정리 (힌트)

태그: `auth` · `external-dependency`

## 전체 흐름

```
chgback fetch --card C  (포털 화면 수집, ID/PW 로그인)
카드사 C: 2026-04 가맹점 포털 MFA 의무화
      │  로그인 후 OTP 화면 → 수집기 파싱 실패
      ▼
차지백 접수 4일 미수집 → 이의제기 기한 단축
```

## 핵심 문장

- 화면 수집은 **상대 화면 변경에 계약 보장이 없다** — MFA는 예고됐지만 수집기는 대상 밖이었다.
- 카드사 C는 같은 데이터를 SFTP 파일로도 제공하고 있었다.
- 교정: 파일 연동으로 전환, 수집 실패 시 당일 경보.
- 포털 계정은 공용 계정이었다 — MFA 도입 뒤에는 개인 계정 + 개인 OTP만 허용돼 공용 수집 계정 자체가 정책 위반이 됐다.
