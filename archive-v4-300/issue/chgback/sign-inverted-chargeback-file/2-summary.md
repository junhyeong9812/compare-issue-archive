# issue/chgback/sign-inverted-chargeback-file — 정리 (힌트)

태그: `data-meaning` · `contract-drift`

## 전체 흐름

```
카드사 A 차지백 파일: 금액 -50,000 (가맹점에서 환수할 금액, 음수 표기)
카드사 B 차지백 파일: 금액 50,000 + 구분 'D'(debit)
chgback import: 카드사 B 규칙(양수=환수)으로 공통 처리 → A 의 -50,000 을 '환수 -50,000' = 지급
      ▼
가맹점 정산: 환수 대신 +50,000 → 대사 차이 100,000 (두 배)
```

## 핵심 문장

- 차지백 금액 표기는 카드사마다 다르다 — **부호로 방향을 표시**하는 곳과 **구분 코드로 표시**하는 곳이 있다.
- `chgback import`가 2024-05 카드사 A 연동 추가 때 B의 규칙을 그대로 썼다.
- 차이가 정확히 두 배라는 것이 부호 문제의 신호였다.
- 교정: 카드사별 방향 해석 규칙 + 가져오기 후 카드사 합계와 부호 포함 대조.
