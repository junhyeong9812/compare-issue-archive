# issue/unsubreg/consent-date-string-compare — 정리 (힌트)

태그: `compliance` · `data-type`

## 전체 흐름

```
consent_date 컬럼: VARCHAR, 형식 "2021-3-7" (자릿수 맞춤 없음, 레거시 이관)
만료 판정: consent_date <= '2021-04-18'  (문자열 비교)
  "2021-3-7"  vs "2021-04-18" → '3' > '0' → 만료 아님으로 판정 (실제로는 만료)
  "2021-10-2" vs "2021-04-18" → '1' > '0' → 만료 아님 (맞음, 우연)
```

## 핵심 문장

- 자릿수를 맞추지 않은 날짜 문자열은 **사전순과 시간순이 다르다**.
- 레거시 이관에서 날짜가 문자열로 들어왔고, 신규 데이터만 `YYYY-MM-DD`였다.
- 1~9월 동의 고객 중 한 자리 월 표기 건이 재확인 대상에서 빠졌다.
- 대처: 컬럼을 DATE 타입으로 이관(파싱 실패 행은 별도 검토), 판정은 날짜 연산으로.
