# issue/pwreset/reset-keeps-refresh-tokens — 정리 (힌트)

태그: `security` · `session`

## 전체 흐름

```
비밀번호 변경(로그인 상태) → tokensvc.revokeAll(user, except=현재 세션)
비밀번호 재설정(메일 링크) → users.setPassword() 만 호출   ← 폐기 없음
공격자 리프레시 토큰 30일 → 계속 액세스 토큰 발급
```

## 핵심 문장

- 재설정 경로는 **비밀번호만 바꾸고 세션을 폐기하지 않았다**.
- 로그인 상태 변경 경로에는 폐기가 있었다 — **두 경로가 다른 코드**였다.
- 도용 의심 고객이 주로 쓰는 경로가 바로 재설정이다.
- 비밀번호 변경·재설정 모두 **공통 함수**에서 전체 세션을 폐기한다.
