# issue/tlsrenew/dns01-cname-stale-renew-fail — 정답

태그: `tls` · `silent-failure`

## 정답
<!-- 질문 1:1 대응 -->

1. **매번 검증 실패한다.**

2. **실패가 로그에만 남았다.**

3. **7일 전 경보가 있었지만 주말 저우선 채널로 갔다.**

4. **갱신 작업 실패, 남은 유효 기간 21일 미만** 두 가지를 호출 등급으로.

## 문제 구조 (추상화 코드)

### 변형 A — 갱신 실패를 로그로만
① 문제 코드
```yaml
job: renew-pay
on_failure: log
```
② 고친 코드
```yaml
job: renew-pay
on_failure: alert(page)
precheck: dig _acme-challenge.pay.hanbitpay.example CNAME  # 위임 대상이 현재 존인지
```
무엇이 깨졌나: 자동화가 실패해도 사람이 알 길이 없었다.

## 방안 비교

| 방안 | 전제 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|---|
| 실패 즉시 경보 | 경보 연동 | 작음 | 없음 | 기본 |
| 만료 21일 전 경보 | 외부 점검 | 작음 | 없음 | 함께 |
| HTTP-01 전환 | 공개 경로 | 중간 | 와일드카드 불가 | 선택하지 않은 방법 |

**결론**: 자동 갱신은 실패 경보와 만료 경보 두 겹으로 감시한다.
