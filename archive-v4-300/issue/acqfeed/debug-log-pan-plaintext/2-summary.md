# issue/acqfeed/debug-log-pan-plaintext — 정리 (힌트)

태그: `security` · `deploy`

## 전체 흐름

```
배포 2025-11-03: logback.xml 이 스테이징 설정(DEBUG)으로 패키징
      │
acqfeed parse → DEBUG "raw record: ..."  ← 마스킹 전 원문 레코드
      │
로그 수집 → 로그 저장소 (보관 90일)
      ▼
11-20 점검: 로그 검색에서 16자리 숫자 패턴 다수 발견
```

## 핵심 문장

- 마스킹은 **파서 다음 단계**에서 한다 — DEBUG 로그는 그 앞에서 원문을 찍는다.
- 설정 파일이 프로파일별로 분리돼 있었지만 빌드 스크립트가 잘못된 프로파일을 복사했다.
- 원문을 찍는 로그 문장 자체를 없애야 한다 — 레벨 설정에 기대는 방어는 배포 실수 하나로 뚫린다.
- 노출 로그는 보관 정책과 별개로 즉시 파기하고 파기 기록을 남긴다.
