# issue/acqfeed/sftp-hostkey-rotation-fail — 정답

태그: `environment-drift` · `fail-closed`

## 정답
<!-- 질문 1:1 대응 -->

1. **exit 3으로 실패하고 경보가 울린다.** 이 사건은 실패가 바로 보였다 — 문제는 대응 지연이었다.

2. **검증을 끄면 같은 IP에 있는 아무 서버나 매입 파일을 줄 수 있게 된다.** 매입 파일은 지급액을 결정하므로 위조 위험이 크다. 지문 대조 후 추가가 정답이다.

3. **받을 수 있다.** KB카드는 원격에 7일치를 보관한다. 키 반영 후 `acqfeed pull --card KB --since 2025-02-11`로 받았다. 7일을 넘기면 카드사 재전송 요청이 필요하다.

4. **카드사 공지 수신함을 팀 공용 채널로 두고, 접속 정보 변경 공지는 체크리스트 항목(키 지문·IP·계정)으로 처리한다.** 지문은 전화 등 다른 경로로 한 번 더 확인한다.

## 문제 구조 (추상화 코드)

① 문제 코드
```sh
acqfeed pull --card KB -o StrictHostKeyChecking=no   # 제안된 임시 조치
```
② 고친 코드
```sh
acqfeed hostkey show --card KB --remote              # 새 지문 확인
acqfeed hostkey add --card KB --fp SHA256:Qe7v...    # 공지 지문과 대조 후 추가
acqfeed pull --card KB --since 2025-02-11
```
무엇이 깨졌나: 상대 인프라 변경 공지가 운영 절차로 이어지지 않았다 — 방어 동작은 정상이었다.

## 방안 비교

| 방안 | 비용 | 실패 모드 | 맞는 조건 |
|---|---|---|---|
| 지문 대조 후 키 추가 | 확인 시간 | 공지 지연 시 수집 지연 | 기본 |
| 호스트 키 검증 끄기 | 없음 | 중간자 공격 | 선택하지 않음 |

**결론**: 검증은 유지하고, 상대 접속 정보 변경을 체크리스트로 받는다.
