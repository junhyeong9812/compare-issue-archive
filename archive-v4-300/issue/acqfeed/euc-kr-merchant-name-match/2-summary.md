# issue/acqfeed/euc-kr-merchant-name-match — 정리 (힌트)

태그: `encoding` · `contract-drift`

## 전체 흐름

```
HN카드 매입 파일 (EUC-KR, 가맹점명 40바이트 고정폭)
      │
acqfeed parse --encoding utf-8      ← 전 카드사 공통 설정
      │  한글 가맹점명 → U+FFFD(�) 섞인 문자열
      ▼
매칭: 대표 가맹점번호 + 가맹점명  → 하위 가맹점(같은 번호, 이름만 다름) 구분 실패
      → 대표 번호 하나에 여러 이름이 걸린 가맹점만 '매칭 실패'
```

## 핵심 문장

- `acqfeed parse`의 인코딩은 **카드사별 설정**이 아니라 전역 하나다 — HN카드만 EUC-KR을 쓴다.
- 디코딩 오류는 예외가 아니라 대체 문자(�)로 처리돼 파싱은 성공한다.
- 대부분의 가맹점은 가맹점번호만으로 매칭돼 증상이 없고, **대표 번호를 공유하는 하위 가맹점**만 이름 보조 매칭에 기대다가 실패한다.
- 교정은 카드사별 인코딩 설정 + 대체 문자 발생 시 파싱 실패 처리다.
