# issue/acqfeed/correction-file-glob-miss — 정리 (힌트)

태그: `silent-failure` · `contract-drift`

## 전체 흐름

```
카드사 SFTP  /out/ACQ_20240514.DAT        ← 정상 매입
             /out/ACQ_20240514.R01        ← 정정 매입 (같은 날짜, 접미 R01~R09)
      │
      ▼
acqfeed pull --card SL --pattern '*.DAT'   ← 설정 기본값
      │  .R01 은 패턴 밖 → 목록에서 아예 안 보임, 로그 없음
      ▼
정산 DB: 정정 전 금액 유지 → 가맹점 지급액 과다/과소
```

## 핵심 문장

- `acqfeed pull`은 설정한 파일 패턴(`*.DAT`)에 맞는 파일만 목록에 올린다 — 패턴 밖 파일은 "건너뜀" 로그조차 남지 않는다.
- SL카드는 2024-04 전문 개정부터 정정분을 같은 날짜의 **`.R01`~`.R09` 접미 파일**로 보낸다 — 이전에는 다음 날 `.DAT`에 합쳐 보냈다.
- 수집 완료 판정은 "받은 파일 수"가 아니라 **카드사 원격 목록과 수집 이력의 차집합**으로 한다.
- 정정분은 원매입 키(매입일·승인번호)로 덮어써야 한다 — 새 매입으로 넣으면 이중 매입이 된다.
