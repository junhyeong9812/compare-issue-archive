### 변형 A — 재설치마다 새 ID
① 문제 코드
```swift
let deviceId = UIDevice.current.identifierForVendor!.uuidString
```
② 고친 코드
```swift
let deviceId = Keychain.get("devbind.id") ?? {
    let id = UUID().uuidString; Keychain.set("devbind.id", id); return id }()
```
무엇이 깨졌나: 기기 식별자의 수명을 앱 설치 단위로 잡아, 기기 단위 정책과 어긋났다.
