# issue/devbind/reinstall-device-cap — 정리 (힌트)

태그: `identity` · `lifecycle`

## 전체 흐름

```
재설치마다 기기 ID 변경 → 새 바인딩 추가, 옛 바인딩 남음
5개 → 6번째 등록: E-LIMIT "등록 가능한 기기 수 초과"
교정: 키체인에 설치 간 유지되는 기기 키 저장 → 재설치에도 같은 ID
      + 90일 미사용 바인딩 자동 해제 · 등록 화면에서 기존 기기 목록 정리
```

## 핵심 문장

- iOS 벤더 ID는 **재설치 시 바뀐다** — 같은 폰이 매번 새 기기가 됐다.
- 옛 바인딩이 남아 **계정당 5대 한도**를 채웠다.
- 오류 메시지가 '기기 수 초과'뿐이라 고객은 폰이 한 대인데 왜인지 몰랐다.
- **키체인에 기기 키를 저장**해 재설치에도 유지하고, 미사용 바인딩을 정리한다.
