# issue/devbind/biometric-key-invalidated — 정리 (힌트)

태그: `platform` · `error-handling`

## 전체 흐름

```
지문 추가 → 키스토어 키 영구 무효 (KeyPermanentlyInvalidatedException)
앱: 서명 실패 → 빈 서명으로 요청 → 서버: 서명 검증 실패 → '미등록 기기'
교정: 앱이 예외를 잡아 '생체 정보가 바뀌어 다시 등록해야 합니다' + PIN 확인 후 재등록
```

## 핵심 문장

- 새 지문 등록 시 키가 **영구 무효화**된다 — 보안상 의도된 설정이다.
- 앱이 예외를 처리하지 않고 요청을 보내 서버가 **엉뚱한 메시지**를 냈다.
- 설정을 끄면 새로 추가된 지문(타인 지문일 수 있음)으로도 인증된다.
- 앱이 무효화를 감지해 **PIN 확인 후 재등록**으로 안내한다.
