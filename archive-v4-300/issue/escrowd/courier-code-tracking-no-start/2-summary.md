# issue/escrowd/courier-code-tracking-no-start — 정리 (힌트)

태그: `silent-failure` · `data-quality`

## 전체 흐름

```
판매자 송장 등록 (택배사 코드 + 송장번호)
escrowd: 배송 추적 시작 → 배송 완료 이벤트 → +7일 자동 구매확정
      │  신규 택배사 'HJ2' 코드 오입력(구 코드 'HJ' 선택) → 추적 조회 결과 없음
      ▼
배송 완료 이벤트가 영영 없음 → 타이머 미시작 → 구매확정 대기 무기한
```

## 핵심 문장

- 자동 구매확정은 **배송 완료 이벤트**를 기점으로 한다 — 추적이 실패하면 기점이 없다.
- 추적 조회 '결과 없음'은 오류가 아니라 "아직 집하 전"과 같은 응답이었다.
- 택배사 통합으로 코드가 바뀐 업체를 쓰는 판매자만 걸렸다.
- 교정: 송장 등록 후 72시간 추적 결과 없음이면 판매자 확인 요청, 송장 등록 기준 최대 기한 둠.
