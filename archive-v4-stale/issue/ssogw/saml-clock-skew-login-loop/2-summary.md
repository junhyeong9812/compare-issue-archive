# issue/ssogw/saml-clock-skew-login-loop — 정리 (힌트)

태그: `environment-drift` · `fail-closed`

## 전체 흐름

```
브라우저 ──▶ IdP (시각 T) ── 어서션 NotBefore=T, NotOnOrAfter=T+5m ──▶ LB ──▶ ssogw 노드
                                                                         │
             노드 1~3 (시각 ≈ T)        → NotBefore ≤ now+60s → 세션 발급 → 로그인 성공
             노드 4  (시각 T-95s)      → T > now+60s → "아직 유효하지 않음" → 로그인 화면으로
                                                                         │
                                       재시도 시 LB 가 다른 노드로 보내면 성공 → "몇 번 하면 됨"

원인: 노드 4 chrony 의 서버 목록이 폐기된 사내 NTP 주소 → 동기화 대상 없음, 자유 진행(drift)
교정: NTP 서버 목록 정정 + 노드별 시각 오프셋 경보 (> 5s)
```

## 핵심 문장

- SAML 어서션은 **노드의 현재 시각**으로 유효 구간을 검사한다 — 노드 시계가 IdP보다 허용 오차 넘게 늦으면 `NotBefore` 위반으로 거절된다.
- LB 뒤 노드 하나만 밀리면 **간헐적·재시도하면 성공**하는 모양이 된다.
- 동기화 데몬이 "active"여도 **동기화 대상이 없으면** 시계는 자유롭게 흘러간다 — 상태가 아니라 오프셋을 본다.
- 허용 오차를 늘리면 증상만 가리고 재전송(replay) 창을 넓힌다.
- 인증 실패 로그에 **노드 이름과 노드 시각·어서션 시각 차이**를 남기면 바로 가려진다.
