# issue/vanrelay/partial-cancel-vat-zero — 정리 (힌트)

태그: `contract-drift` · `silent-failure`

## 전체 흐름

```
원거래   amount 33,000  vat 3,000   (승인 A8812)

부분취소 요청 (환불 서비스)
  cancel --orig A8812 --amount 11000            ← --vat 없음
      │
      ▼
vanrelay ──전문──▶ 카드사
  vat 필드 = 요청값 그대로 (없으면 0)            ← 자동 안분 없음
  응답 "OK C55102", exit 0

카드사 매입:  취소 11,000 / vat 0       → 부가세 신고 자료(취소 vat 1,000)와 1,000 차이
고객 환불:    11,000 정상               → 고객·매출 합계로는 안 보인다

전액취소: vanrelay 가 원거래 vat 를 그대로 복사 → 문제 없음
교정: 부분취소마다 vat = 원거래 vat × 취소액 / 원거래액 (마지막 취소는 잔여)
```

## 핵심 문장

- `vanrelay cancel`은 **부분취소**일 때 부가세를 원거래 비율로 나누지 않는다 — `--vat`가 없으면 **0**으로 보낸다. 응답은 정상이다.
- 전액취소는 원거래 부가세를 복사하므로 문제가 없다 — 그래서 부분취소가 드문 가맹점에서는 안 드러난다.
- 금액 합계는 맞고 **부가세 합계만** 어긋난다 — 금액 대사만으로는 보이지 않는다.
- 끝수는 각 취소에서 내림으로 나누고, **잔여 부가세를 마지막 취소에 몰아** 합계를 원거래와 맞춘다.
- 환불 대사는 공급가·부가세를 나눠 보고, 건 수·승인번호 매핑을 먼저 확인해 병합·누락형 원인과 가른다.
