# 마켓 재고 동기화 운영 런북

## 스케줄
| 시각 | 작업 | 호출 |
|---|---|---|
| 매일 06:00 | 전체 동기화 — 모든 상품의 공지 수량을 다시 보낸다 | `POST /market/sync?full=1` |
| 10분마다 | 증분 동기화 — 바뀐 상품만 | `POST /market/sync` |
| 매일 06:20 | 대사 리포트 확인 | `GET /reports/market-drift` |

- 06:00은 오픈마켓 판매자센터의 집계일 경계다(06:00~다음 날 06:00이 하루).
- 전체 동기화가 실패하면 증분 동기화만으로는 복구되지 않는 상품이 있다. 06:30까지 재실행한다.

## 판매자센터 점검 (매주 월요일)
- 판매자 등급, 출고 지연, 판매자 귀책 취소율을 확인한다.
- 경고 내역을 확인한다. 경고 3건이 쌓이면 마켓 판매가 7일 정지된다(전 상품).
  - 출고 지연: 결제 후 3영업일 안에 출고하지 않은 주문 1건마다
  - 재입고 알림 반복: 같은 상품의 재입고 알림이 집계일 하루에 두 번 이상 나가면 1건
  - 판매자 귀책 취소: 주간 취소율 2% 초과 시 1건
- 2025-06-12 경고 2건(MKT-118). 재발하면 판매 정지까지 1건 남는 상태였다.

## 연락처
- 마켓 연동 벤더(stockpush): 벤더 포털 티켓
- 창고 실사: 물류팀 실사 담당
