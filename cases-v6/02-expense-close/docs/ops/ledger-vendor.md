# 원장 벤더(ledgerctl) 운영 메모

재무시스템팀 · 마지막 갱신 2025-05

## 연락처
- 벤더 기술지원: 평일 09–18시, 장애는 핫라인(사내 위키 "원장 벤더" 페이지).
- 사내 담당: 재무시스템팀 원장 파트.

## 저널 위치
- 운영: `LEDGERCTL_HOME=/data/ledger` (서비스 계정만 쓰기).
- 개발·테스트: 임시 디렉터리.

## 월 정산서 항목 (계약서 부속 2 기준)
| 항목 | 단위 |
|---|---|
| 기본료 | 월 고정 — post, list 포함 |
| 단건 열람 | 호출 1회당 25원 |
| 저널 보관 초과 | 10GB 단위 |

## 정산서 이력
- 2025-02분: 단건 열람 412,300회.
- 2025-03분: 단건 열람 768,140회(1,920만 원). 발생 시스템 대부분 경비 포털. 재무 원장 파트 문의 → EXP-412.
- 2025-04분 이후: 단건 열람 월 1천 회 안팎(대사 데스크).

## 메모 길이
- 메모 상한 UTF-8 48바이트(넘으면 보류). 2026-10 경비 정산 마감 건 참고.
