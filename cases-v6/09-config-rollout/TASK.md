# `rollout show`에서 서버가 이번 배포를 받았는지 알 수 있게 해 주세요

## 배경
운영자들은 배포가 끝나면 `bin/rollout show <서버>`로 서버 설정을 확인합니다.
그런데 출력 맨 윗줄(`# generated by rollout for web-01 (pool web, release r2026.10.01) …`)의 릴리스가 방금 끝난 배포와 다른 서버가 늘 섞여 있습니다.

- 예: `r2026.10.01` 다음 `r2026.10.08`을 배포한 뒤 `rollout show web-01`을 보면 `release r2026.10.01`이 찍혀 있습니다.
- 그래서 "web 서버들이 이번 배포에서 빠졌다"는 문의가 장애 대응 채널에 매번 올라오고, 확인하느라 시간이 듭니다.
- 지난주에는 야간 당직자가 web 서버만 다시 배포하려고 롤백 절차를 시작했다가 멈춘 일도 있었습니다.

## 요청
- 배포(`bin/rollout apply <릴리스>`)가 끝나면, 모든 활성 서버에 대해 `bin/rollout show <서버>` 출력에 **방금 끝난 배포의 릴리스 id**가 보이게 해 주세요.
- 서버별 설정 값(`app.conf`의 각 항목)은 지금과 같아야 합니다.
- 빠진 서버(상태 D)는 지금처럼 `show`가 실패해야 합니다.

환경: Ubuntu 24.04, bash 5.2, GNU coreutils/sed. 설정 서비스 CLI는 `vendor/bin/cfgsvc`(벤더 제공 바이너리, 수정 불가)입니다.
