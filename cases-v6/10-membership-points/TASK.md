# 고객센터 보상 포인트를 배치 백엔드에서 지급할 수 있게 해 주세요

## 배경
고객센터는 결제 오류·이벤트 누락·배송 지연 같은 건에 보상 포인트를 줍니다. 지금은 상담원이 포인트 벤더 콘솔에 직접 들어가 수기로 넣고 있습니다.

- 지난달 수기 입력 실수로 다른 회원에게 보상이 들어간 건이 3건 있었습니다(회원번호 앞자리 0 누락 등).
- 같은 상담 건에 상담원 두 명이 각각 보상을 넣어 이중 지급된 건도 있었습니다.
- 콘솔 계정을 상담원마다 나눠 주기 어려워, 상담 시스템에서 우리 백엔드를 호출해 지급하려고 합니다.

## 요청
- `PointsApi`에 보상 지급 기능을 추가해 주세요: `compensate(String memberNo, long points, String ticketNo)` (반환값: 벤더 적립 번호).
  - `memberNo`는 발급된 회원번호 그대로, `ticketNo`는 상담 티켓 번호(예: `CS-20261007-0012`)입니다.
- 지급한 포인트는 회원 앱의 포인트 잔액과 적립 건수에 바로 보여야 합니다.
- 같은 상담 티켓으로는 한 번만 지급되어야 합니다(두 번째 요청은 예외로 거절해도 됩니다).
- 없는 회원번호나 0 이하 포인트는 예외로 거절하고 아무것도 지급하지 않습니다.
- 기존 적립 배치와 회원 포인트 화면은 지금과 같아야 합니다.

환경: Ubuntu 24.04, JDK 21. 포인트 벤더 연동은 벤더 제공 CLI `vendor/bin/ptsctl`(수정 불가)입니다.
