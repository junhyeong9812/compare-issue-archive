# 월말 포인트 마감 런북

담당: 멤버십 운영. 매월 마지막 영업일 다음 날 오전.

1. 마지막 날 적립 배치 결과 확인 — `RunResult`의 `unknownMembers`가 있으면 회원팀에 넘긴다.
2. 포인트 충당부채 대사 자료 작성(회계법인 제출).
   - 벤더 `hist` 전체 덤프에서 참조가 `E-`로 시작하는 행을 매입사 결제 내보내기(승인 건)와 결제 ID로 1:1 맞춘다.
   - 짝이 없는 `E-` 행은 '근거 없는 적립'으로 분류되어 회계법인에 건별로 소명한다. 2025 기말감사 때 37건을 소명했고 추가 표본 요청을 받았다.
3. 고객센터 보상·수기 조정분은 `A-<상담 티켓>` 참조로 들어간다. 2번 대사 대상이 아니다. 금액만 별도 집계표에 옮긴다.
4. 경품: 마케팅 '이달 적립 상위' 리포트 → 감사실 확인(AUD-25-07) → 상품권 발송. 감사실은 상위권 회원의 벤더 이력에 `A-` 행이 있으면 따로 본다.
5. 마감 메일: 적립 합계, 보상 합계, 소명 대상 건수.
