# CHANGELOG — 자동이체 알림 서비스

## 2.1.0 (2026-08-18)
- 푸시 예약 시각을 직전 5분 경계로 내림(pushq 2.8.0 예약 슬롯).
- 출금일 리포트에 `대기` 건수 추가.

## 2.0.0 (2026-02-02)
- 푸시 벤더를 pushq 2.x로 교체. 기기 토큰 정규화(구버전 앱의 대문자 접두·공백) 추가.
- 알림 시점 선택지에 1440분(하루 전) 추가.

## 1.9.0 (2025-04-14)
- 재출금 안내 키를 출금 예정 알림과 같은 형식(계약·날짜)으로 변경. CS-2291 후속.
- 실패 통보 수신 API가 같은 키를 이미 예약했으면 새로 예약하지 않고 200을 돌려준다.

## 1.8.2 (2025-03-27)
- 야간 방해 금지(22:00~07:00)에 걸린 알림을 전날 21:00으로 당김. 이전에는 07:00으로 미뤄 출금 뒤에 도착하는 건이 있었다.

## 1.8.0 (2025-01-20)
- 계약 해지 시 아직 나가지 않은 알림 예약 취소.
- 수신 거부 고객 건수를 계획 결과에 포함.
