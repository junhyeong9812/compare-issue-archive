# 만 14세 이상 청소년도 가입할 수 있게 해 주세요

## 배경
11월 '스쿨 캐시백' 이벤트(학용품·문구점 결제 시 포인트 적립)를 앞두고 중·고등학생 고객의 가입 문의가 늘고 있습니다.

- 지금 가입(`POST /members`)은 만 19세 미만이면 400으로 거절합니다. 앱에는 "만 19세 이상만 가입할 수 있습니다"로 보입니다.
- 고객센터에 "고등학생인데 가입이 안 된다", "이벤트 광고를 보고 왔는데 가입부터 막힌다"는 문의가 하루 수십 건 들어옵니다.
- 이벤트 제휴처(문구 프랜차이즈)도 청소년 회원 가입이 열리는지 확인을 요청했습니다.

## 요청
- 만 14세 이상이면 가입 신청을 받아 주세요. 만 14세 미만은 지금처럼 거절합니다(법정대리인 동의 절차가 아직 없습니다).
- 청소년 회원도 성인과 같이 본인확인 실행(`POST /kyc/run`) 한 번으로 결과를 받아야 합니다. 결과 문자도 한 통 받아야 합니다.
- 청소년 회원이 '확인 대기'나 '담당자 확인 중'으로 남으면 같은 문의가 다시 들어옵니다. 운영 콘솔 대기 현황(`GET /reports/kyc-backlog`)에도 남지 않아야 합니다.
- 성인 회원의 가입·본인확인 흐름은 지금과 같아야 합니다.

환경: Ubuntu 24.04, Python 3.12. 본인확인 벤더 CLI는 `vendor/bin/idchk`(벤더 제공 바이너리, 수정 불가)입니다.
