# 문자 대행사 계약 메모

계약: 문자 발송 대행 기본계약 + 부속서(서비스 수준·응답 코드). 원문은 계약관리 시스템, 이 메모는 개발에 필요한 부분만 옮긴다.
개정 이력: 2024-11 최초 정리 · 2025-08-05 INC-0719 회신 반영(3장).

## 1장 발신 번호·본문
- 발신 번호 1588-0000(사전 등록). 본문 90바이트 이하 단문, 넘으면 장문 과금.

## 2장 처리량
- 계정당 초당 30건. 넘는 요청은 E-THROTTLE로 즉시 돌려준다.

## 3장 실패 응답 처리 (2025-08-05 대행사 회신 반영)
| 코드 | 대행사 처리 | 과금 |
|---|---|---|
| E-THROTTLE | 요청을 받지 않은 것으로 처리(대기열에 넣지 않음). | 없음 |
| E-CARRIER | 대행사 대기열에 남겨 두었다가 통신사 반려가 풀리면 대행사가 같은 메시지를 다시 넣는다(30분 안, 1회). 이 결과는 발송 요청자에게 따로 통보하지 않는다. | 발송 성공 시 1건 |
| E-SPAM | 수신자 단말·통신사 차단. 대행사 처리 없음. | 없음 |

## 4장 정산
- 월 1회 발송 내역(건별)과 청구서 대사. 차이 0.5% 넘으면 재대사 요청.
