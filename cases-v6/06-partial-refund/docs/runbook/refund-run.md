# 야간 환불 실행 — 운영 런북

스케줄: 매일 22:30 (`RefundDeskApi.runRefunds(오늘)`).

## 실패했을 때 재실행
- 같은 날짜로 다시 돌리면 새 회차 번호가 붙는다. 회차·배치 번호를 손으로 재사용하지 말 것 — PG는 이미 받은 배치 번호를 다시 받으면 아무것도 하지 않고 `accepted N`만 돌려준다.
- 재실행은 PG 매입 마감(매일 03:00, 전날 결제분 매입) 뒤에 한다. 매입 전 결제 건에 부분취소가 들어가면 페이링크는 카드사에 원승인 전액 취소 + 남은 금액 재승인, 두 건으로 보낸다(페이링크 가맹 계약 부속서 3).
- 재실행 후 `pgsim status --batch <배치 번호>` 건수와 보낸 줄 수를 대사한다.

## 자주 오는 문의
- "환불 처리 중"이 다음 날 오전까지 남음 → 해당 배치 status 확인, 빠진 줄은 새 회차로.
- "환불 접수"에서 하루 넘게 안 바뀜 → 접수 일자와 결제 일자 확인.
