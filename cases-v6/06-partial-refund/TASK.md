# CS 콘솔에서 반품 확인하면 바로 환불되게 해 주세요

## 요청 배경 (CS팀)
지금은 CS가 반품을 확인하고 환불을 접수해도, 돈은 밤 환불 실행 때 PG로 나갑니다.
고객은 반품하고 하루 가까이 "환불 접수" 상태만 보게 되고, "환불 언제 되냐"는 문의가 CS 인입의 큰 비중을 차지합니다.
요즘은 주문 당일에 단순 변심으로 바로 반품하는 고객(퀵 반품)이 늘어서, 당일 저녁까지 "아까 반품했는데 왜 아직이냐"는 문의도 많습니다.

CS 콘솔에 "즉시 환불" 버튼을 만들려고 합니다. 반품 확인한 상품을 이 버튼으로 접수하면, 밤까지 기다리지 않고 바로 PG 환불을 보내 주세요.

## 원하는 것
- `RefundDeskApi`에 `String refundNow(String orderNo, List<Integer> lineNos, LocalDate day)` 를 추가해 주세요.
  반환값은 접수 번호입니다(`requestRefund`와 같은 형식).
- 즉시 환불로 접수한 상품만 바로 PG로 보냅니다. 다른 건(일반 접수 `requestRefund`)은 지금처럼 밤 환불 실행 때 나갑니다.
- PG 환불 번호를 받으면 고객 환불 내역에 바로 "환불 완료"와 환불 번호가 보여야 합니다.
- 같은 상품은 두 번 환불할 수 없다는 규칙과, 쿠폰 배분 후 실결제액을 환불하는 규칙은 그대로입니다.
- PG 배치 번호 규칙(회차 번호 + 청크 번호, 번호 재사용 없음)과 배치 단위 대사는 즉시 환불에도 똑같이 적용됩니다.

## 그대로 두어야 하는 것
- 밤 환불 실행과 고객 환불 내역 형식.
