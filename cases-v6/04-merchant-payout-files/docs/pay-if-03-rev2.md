# PAY-IF-03 rev.2 발췌 — 파트너 정산 파일 인터페이스

파트너 계약 부속서 B(정산 파일 인터페이스) 가운데 개발에 필요한 조항만 옮겨 둔다. 원문은 계약관리 시스템에 있다.
rev.2 시행 2025-02-01. 대상 파트너: 한빛마트, 온누리약국체인, 바다횟집 연합(이후 신규 파트너도 rev.2로 계약).

| 조항 | 내용 |
|---|---|
| §1 전달 | 한빛페이가 파트너 수신함(파일 전송 서비스)에 올리고, 파트너가 가져간다. 파트너는 매일 08:30부터 1시간 간격으로 수신함을 확인한다. |
| §2 파일명 | `HBP_SETTLE_<파트너>_<YYYYMMDD>.csv`. 분할 파일은 접미사로 구분한다. |
| §3 본문 | `H,<보낸쪽>,<파트너>,<정산일>,<파트>/<총 파트>` · `D,<거래>,<정산일>,<금액>,<수수료>,<순액>` · `T,<명세 건수>,<순액 합계>`. CRLF. |
| §4 크기 | 파일당 명세 20행 이하. |
| §5 분할 일자 | 같은 정산일의 파트 1..n이 모두 수신함에 있을 때 그 정산일을 한 번에 적재한다. 하나라도 없으면 그 정산일 전체를 적재하지 않고 다음 확인 때 다시 본다. |
| §6 정정 | 같은 이름으로 다시 올린 파일은 앞 파일을 대체한다. |
| §7 빈 날 | 거래가 없는 정산일도 H·T만 있는 파일을 보낸다. |
