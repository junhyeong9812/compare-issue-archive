# 수신 확인에서 "일부만 도착한 날"을 구분해 주세요

정산운영팀 요청입니다.

## 상황
- 당직은 매일 아침 `bin/payout receipts <파트너> <시작일> <종료일>`로 파트너 수신함에 무엇이 들어갔는지 확인합니다.
- 명세가 많아 한 날짜가 여러 파일로 나뉘어 나가는 날, 전송 중 일부 파일만 실패하면 그 날 줄이 `-`로만 나옵니다.
  파일이 하나도 안 간 날과 똑같이 보여서, 당직이 매번 전송 CLI로 수신함을 열어 어느 파일이 갔는지 직접 세고 있습니다.
- 지난달에만 이런 날이 여섯 번 있었고, 확인에 한 번에 20~30분씩 걸렸습니다. 파트너 문의가 오면 "몇 건이 가 있는지" 바로 답하기도 어렵습니다.

## 요청
- 일부 파일만 도착한 날은 그 날 줄에 몇 개 파일 중 몇 개가 도착했는지(예: `1/2`)를 보여 주세요.
- 그 날 도착한 파일에 든 명세 건수와 순액 합계도 함께 보여 주세요. 도착한 만큼은 숫자로 보이면 좋겠습니다.
- 파일이 하나도 없는 날, 전부 도착한 날의 표시는 지금 그대로 두세요.

환경: Ubuntu 24.04, bash 5.2, GNU coreutils. 파일 전송 벤더 CLI는 `vendor/bin/xferq`(벤더 제공 바이너리, 수정 불가)입니다.

## 확인
```
bash test.sh
```

test.sh가 통과하도록 구현해 주세요. 테스트 파일은 수정하지 마세요.
