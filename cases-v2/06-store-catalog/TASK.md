# 업데이트가 거절된 지점 카탈로그에 다른 지점 상품이 나타납니다

## 증상
- 서울점 관리자가 가격 일괄 수정을 올렸고, 잘못된 가격(0원)이 섞여 있어 정상적으로 거절(422)되었습니다.
- 그런데 거절 직후 서울점 상품 목록(`GET /stores/seoul/products`)에 부산점에서만 파는 상품(예: `FSH-03` Fish Cake Box)이 보입니다. 서울점에는 그런 상품을 등록한 적이 없습니다.
- 거절되었으니 서울점 목록은 수정 전과 같아야 하는데, 수정 전과 달라졌습니다.

## 빈도·환경
- 항상은 아니고, 같은 날 다른 지점이 카탈로그를 수정한 뒤에 거절이 나면 생기는 것 같습니다. 지점이 하나뿐인 테스트 서버에서는 본 적이 없습니다.
- 서비스는 Python 3.12, 카탈로그는 서버 로컬 디스크(`data_root`)에 저장됩니다.

## 재현

```
bash test.sh
```
