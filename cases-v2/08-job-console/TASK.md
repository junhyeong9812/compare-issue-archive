# 작업 콘솔: 빨리 끝난 작업의 마지막 출력이 안 보임

빌드·배포 작업 콘솔 운영 문의입니다. 콘솔은 작업을 띄우고(`POST /jobs`), 작업 상세(`GET /jobs/:id`)에서 출력 로그와 상태(running / succeeded / failed)를 보여 줍니다. 다른 호스트의 원격 러너가 보낸 이벤트(`POST /events`)도 같은 화면에 반영됩니다.

## 기대한 것
- 작업이 끝나면 상세 화면에 그 작업이 찍은 출력이 마지막 줄까지 전부 보이고, 상태는 종료 코드대로 succeeded/failed 로 남는다.
- 한번 끝난 작업이 다시 running 으로 돌아가는 일은 없어야 한다.

## 실제로 일어난 것
- 1초 안쪽에 끝나는 짧은 작업(린트, 단위 빌드 등)에서 상세 화면 로그가 앞부분 몇 줄에서 멈춰 있다. 상태는 succeeded 로 정상 표시된다. 같은 작업을 터미널에서 직접 돌리면 출력은 끝까지 나온다.
- 오래 걸리는 작업, 특히 끝나기 전에 한동안 조용했던 작업은 정상이다.
- 원격 러너 작업 중 일부는 failed 로 표시됐다가 잠시 뒤 running 으로 바뀌어, 그대로 계속 실행 중으로 남는다는 제보가 있다.
- 오류 로그는 없다. 빈도: 짧은 작업에서는 거의 매번. 환경: 운영·스테이징 동일.
