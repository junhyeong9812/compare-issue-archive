# 현장 점검 메모의 최신 내용이 사라집니다

## 기대
점검원들은 통신이 안 되는 현장에서 모바일 앱으로 메모를 고치고, 연결되면 업로드합니다(`POST /sync/push`). 같은 메모를 여러 명이 고쳤다면 **가장 나중에 고친 내용**이 서버(`GET /notes/{id}`)에 남아야 합니다.

## 실제
3월 2일 펌프실 메모를 태블릿 점검원(서울 시간 기준 기기)이 18:00(UTC 09:00)에, 휴대폰 점검원이 UTC 10:00에 각각 오프라인으로 고쳤습니다. 업로드는 태블릿이 UTC 11:00, 휴대폰이 UTC 11:30에 했습니다. 그런데 서버에는 태블릿 내용("valve 3 leaking")이 남아 있고, 휴대폰의 더 새 내용("valve 3 replaced, no leak")은 사라졌습니다. 업로드 응답은 둘 다 `synced` 였고 에러 로그도 없습니다.
업로드 지연이 짧을 때는 대체로 잘 맞고, 지연이 길수록 자주 생긴다는 느낌입니다.

환경: JDK 21, 기기마다 타임존이 다릅니다(오프셋 포함 시각 또는 `X-Device-Zone` 헤더 + 로컬 시각).
