# 백오피스 주문 목록·대시보드에서 신규 주문 표시가 이상함

운영팀 문의입니다. 백오피스 주문 화면(`GET /orders`, `GET /orders/:id`)과 대시보드(`GET /dashboard`)의 응답을 그대로 화면에 그립니다.

## 기대한 것
- 막 들어온 주문은 주문 상태 칸에 "접수 대기"(주황색 경고 톤)로 보여야 한다.
- 결제 칸·배송 칸은 각자의 문구로 보여야 한다.
- 대시보드의 "확인 필요" 건수에는 아직 접수되지 않은 주문이 들어가야 한다.

## 실제로 일어난 것
- 신규 주문의 주문 상태 칸이 "결제 대기"(회색)로 나온다. 결제 기록이 아직 하나도 없는 주문도 마찬가지다.
- 대시보드의 "확인 필요" 건수에서 신규 주문이 빠져서, 아침마다 접수 처리가 늦어지고 있다.
- 빈도: 신규 주문 전부. 환경: 운영·스테이징 동일.
