# 예전에 쓰던 비밀번호로 다시 바꿀 수 있습니다

## 기대
보안 정책상 비밀번호를 변경할 때 **최근 5개** 안에 쓴 비밀번호는 다시 쓸 수 없어야 합니다. 예를 들어 A → B로 바꾼 뒤 다시 A로 바꾸려 하면 `422`와 함께 거절돼야 합니다. (정책 값은 `config/app.properties` 에 있고, 운영에서는 `-D` 옵션으로 덮어쓰기도 합니다.)

## 실제
내부 감사에서 한 직원 계정이 비밀번호를 두 개만 번갈아 쓰고 있는 것이 발견됐습니다. 직접 해 보니 A → B → A 변경이 전부 `200`으로 성공합니다. 지금 쓰고 있는 비밀번호와 똑같은 값으로 "변경"해도 성공합니다.
최소 길이·숫자 포함 같은 다른 규칙은 정상적으로 거절됩니다. 가입·로그인·프로필 기능도 문제없습니다. 에러 로그는 없습니다.

환경: JDK 21, 단일 인스턴스. 설정 파일 값은 배포 전후로 바뀐 적이 없습니다.

## 재현

