# 메뉴 순서를 바꿔 놓으면 가끔 원래대로 돌아갑니다

## 기대
직원 태블릿에서 메뉴 항목을 끌어서 순서를 바꾸면(`POST /admin/items/{id}/move`), 손님 화면(`GET /menus/{category}`)에 바뀐 순서가 그대로 유지돼야 합니다. 이름·가격·노출 여부 수정도 각각 반영돼야 합니다.

## 실제
점심 준비 시간처럼 직원 여러 명이 동시에 메뉴를 손볼 때, 일주일에 몇 번씩 "분명히 맨 위로 올렸는데 손님 화면에선 원래 자리에 있다"는 제보가 옵니다. 그 항목의 이름 변경은 반영돼 있습니다. 두 요청 모두 성공 응답을 받았고 에러 로그는 없습니다. 혼자서 하나씩 해 보면 재현되지 않습니다.

환경: JDK 21, 서버 1대, 요청은 여러 스레드에서 동시에 처리됩니다.

## 재현
```
bash test.sh
```
테스트는 한 직원이 음료 이름을 바꾸는 동안 다른 직원이 그 음료를 맨 위로 옮기는 타이밍을 고정해서 재현합니다.

test.sh가 통과하도록 고쳐 주세요. 테스트 파일은 수정하지 마세요.
