# 연도별 검색·통계에서 일부 자료가 빠집니다

## 증상
- 도서관 카탈로그 서비스(libcat)에서 `GET /search?year=2021` 로 2021년 출간 자료를 찾으면 일부 자료가 결과에 없습니다.
- 대시보드의 연도별 통계(`GET /stats/years`)도 실제 소장 자료 수보다 적게 나옵니다.
- 빠진 자료도 제목·저자 검색(`q=`)이나 상세 조회(`GET /items/<id>`)에서는 정상으로 보입니다.
- 예: Harbor Books 월간 피드를 받은 뒤 `B-1004`(Salt and Iron), `B-1008`(Knots, Splices and Rigging)이 2021년 검색에 안 나옵니다.

## 빈도·환경
- 같은 피드를 넣으면 매번 똑같이 재현됩니다. 대부분의 자료는 정상입니다.
- 출판사 피드를 그대로 수집(`POST /harvest`)하는 운영 환경, Python 3.12.
