# 야간 정산 동기화에서 정상 주문이 가끔 빠집니다

## 증상
- 회계 도구는 매일 밤 `orderfeed.client.FeedClient.fetch_all()` 로 유효(취소되지 않은) 주문 전체를 받아 정산합니다.
- 어떤 날은 정산 결과에 주문 한두 건이 빠져 있습니다. 빠진 주문은 취소된 적이 없고, 다음 날 다시 돌리면 정상으로 들어옵니다.
- 동기화는 오류 없이 "완료"로 끝나서, 다음 달 대사(대조) 때에야 발견됩니다.
- 운영팀 관찰: 동기화가 도는 시간에 고객센터가 주문 취소를 처리한 날에 주로 생깁니다.

## 기대
- 동기화 결과는 동기화가 끝난 시점의 유효 주문과 정확히 같아야 합니다(빠짐·중복 없음).

## 환경
- 서비스·클라이언트 모두 Python 3.12. 주문은 많을 때 하루 수천 건, 페이지 크기는 설정값.
